# 逐项核对与实施

## 明确迁移

官方弃用消息明确给出替代名称或用法时，按项目当前依赖版本迁移。图标采用 AutoMirrored，LifecycleOwner 使用 lifecycle-runtime-compose。异步剪贴板通过组合生命周期内的协程访问。Material 标签页保留原有指示器语义，下拉锚点按只读、可编辑和次级图标选择类型。

以 AndroidX 官方源码的弃用说明和签名核对实现，避免仅改名称导致重载或作用域不匹配。

## 保留条件

仅提示 Deprecated in Java、未检查转换、空值风险、常量条件、delicate 或 preview API，以及仅建议添加 Deprecated 或抑制诊断的条目不批量改写。没有明确步骤时保留既有行为。

第三方库出现明确迁移步骤时单独记录来源，不将其称作 Google API。不能以关闭告警代替调用迁移。

## 验证

按原日志逐项记录处理状态，区分已迁移、基线已解决和保留。检查 Kotlin 语法、依赖 API 签名、UTF-8、差异空白、资源与 Markdown 链接，并登记 CI。不会用静态检查替代构建通过结论。
