# 思考配置完整保存与档位一致性

当前编辑器会重新构造规则 JSON，丢失 required、复合匹配、unsupported 和高级动作字段；模型切换和连接测试也未统一处理已失效档位。

本次保留现有规则顺序与首个匹配语义，不识别专用规则，不自动排序。兼容已有配置 JSON。

1. 完整保存：保留未编辑字段，完善规则与档位校验。
2. 档位一致性：切换模型、保存规则和连接测试使用同一规则解析；连接测试使用配置第一档。
3. 编辑体验：增加内置预设选择、复制、置顶和当前模型命中预览。新增及复制规则保持显式手动排序。
4. 交付：补充回归用例、用户说明和静态检查；未授权运行构建、测试或真实模型请求。
