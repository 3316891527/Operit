# 实现与验收记录

本轮在统一集成 PR #236 中继续迭代子代理预览版。使用维护者提供的四张截图调用图像工具生成一版视觉参考；代码采用原生 Compose，不依赖生成图中的文字或示例数值。维护者随后明确确认喜欢该设计，本轮以它为视觉基准对齐路径行、状态胶囊、边框和卡内分段按钮；耗时没有可用记录时不显示示例数值。

## 窗口与子会话

任务窗口从最大高度限制改为屏幕高度 82% 的固定框架，管理列表与详情正文使用填满剩余空间的内容区，标题、页签与底部操作区保持在正文之外。输入法和屏幕配置仍参与可用尺寸约束。

子会话使用独立 LazyColumn，普通文字沿用 Markdown；详情标题下直接显示路径、状态胶囊和执行次数；工具调用与结果通过只读协议投影合成紧凑工具卡，思考放入默认收起的区域，协议元数据不显示。参数和输出通过卡内分段按钮切换，完整内容可复制；长内容使用最大 220 dp 的内部滚动视口，不截断原文。

卡片的展开状态以消息时间戳和片段位置持有，正文追加、结果到达和任务收尾不会改变其身份。历史助手消息分别缓存，流式更新只重新解析当前消息。参数与工具结果中的空格、换行和 Unicode 在展示投影中保留；保存和请求链路继续使用原解析入口及原始协议。

## 工具名称与收尾

工具执行前的调用回调使用现有的目标名称解析，与批次状态保持一致。`package_proxy` 和 `proxy` 一旦携带 `tool_name`，界面即显示真实目标；真实工具调用、权限和参数没有改写。旧任务的事件列表按历史调用投影名称，旧事件记录不修改。

缺失或未闭合结果不会标为完成；无状态的历史结果仅显示已返回。模型停在未闭合的工具调用或结果上时，报告提取不会把残缺标签当作最终答复，因此不能据此标记任务成功。

报告正文在投递时原样保留。主、子代理提示增加逐字引用、指标口径、哈希与转述准确性区分，以及差异回看源输出的要求。提示调整适用于后续模型请求，不会修复已保存报告，也不能代替真实模型的质量验收。
