# 1.13.0 累积更新日志

状态：持续维护草稿，供后续 1.13.0 发布整理使用。当前覆盖个人发行线从正式 `1.12.2` 到 `1.12.2+19` 的实际变化，不代表已经发布 1.13.0。

这一阶段主要重做了聊天、模型、主题、记忆、语音与文件工作区，补齐对话批量管理、原生动态卡片、主题分享和主题工作室，并持续改进长记录、工具结果、终端及增量更新的稳定性。下面按截至 `+19` 的最终行为合并描述，同一功能的多轮修复不重复列为新功能。

详细依据见[来源与归并说明](sources.md)、[补丁版时间线](patches.md)和[全部 488 条提交](commits.md)。

## 聊天界面与对话管理

- 重组聊天主界面、侧边栏和设置入口，将对话目录、角色选择、工作区和终端集中到更一致的导航中；嵌套文件夹支持拖拽整理，减少重复入口。
- 新增对话归档与已归档筛选。归档后可查看和恢复，保留消息、角色绑定、文件夹、锁定与置顶信息，备份中也保留归档状态。
- 支持批量总结标题、归档、锁定、删除及移动到文件夹，展示执行进度和结果；批量删除继续检查锁定状态并要求确认。
- 对话标题可按首条使用者消息生成，生成期间的手动改名不会被旧结果覆盖；空记录和已删除目标不会误写标题。
- 附件菜单提供“继续生成”，沿现有历史续写而不新增使用者消息，也不清空当前草稿、附件和回复目标。语音通话统一从附件菜单进入。
- 为新建空对话和删除操作增加短动画，改善历史侧栏混合高度条目的绘制与滚动；系统关闭动画时跳过对应效果。
- 没有正文及附件时禁用空白发送。生成中取消、消息排队、切换会话与删除当前对话的状态衔接得到修正，避免未锁定对话被误报为锁定。

- 插件页面离开时保存聊天草稿，重新进入后恢复，修正页面加载与状态生命周期。

## 消息渲染与生成控制

- 聊天消息和回答候选改用结构化片段持久化，分别处理正文、思考、工具调用和结果；复制、搜索、历史回放与模型上下文使用对应内容，减少协议标记混入正文。
- 修复行内反引号误触发代码围栏、Markdown 表格横向拖动失效，以及 Waifu 流式分句截断列表、插件 XML 和后续文字的问题；显示清理与朗读内容分别处理。
- 统一长回复的滚动和可见内容分块，修复末尾工具卡片不能点击、空白气泡、首尾断层和重试后卡片累积，减少已完成长卡片的重复解析。
- 消息复制预览分别保留纯文本、Markdown 和 XML 的选区及滚动位置；插件列表、设置页签和世界书编辑对象保留各自浏览位置。
- 思考控制改为常驻动态滑块，完善档位、拖动高光和主题颜色；修复超长思考引导线的尺寸约束崩溃。
- 调整长历史读取、上下文准备与请求构建，减少主线程等待和重复处理；超长消息按块回填，避免整段正文进入 CursorWindow 引发异常。
- 修复纯思考回复续写时丢失助手历史和未完成工具上下文的问题，区分缺少可见正文与达到生成上限，并延长慢速模型首字等待期限。
- 拆分发送任务与取消收尾，保留取消前已生成内容；流式重试清理旧的重复前缀，重新收到正文后恢复接收状态。
- 对已经确认协议完成的 OpenAI 响应及时结束读取，避免尾部连接异常触发整段回答重试和撤回；完成前的真实中断仍正常报告。

- 消息翻译接入原生功能模型服务，保留本地缓存和未配置翻译模型的提示；重试时清理旧翻译前缀，避免重复内容。
- Waifu 首句生成时即可预览正文，并在同一气泡定稿；后续分句保留模拟打字，减少历史内容反复解析。

## 主题、角色与外观

- 主题设置整合基础、聊天、输入、界面与布局，集中管理草稿、实时预览、保存和放弃；语言选择、全局聊天布局及各区域玻璃效果可以在统一入口调整。
- 使用者与 AI 可分别选择对话框或命令框样式，支持双方不同外观，并在正式聊天、预览和分享链路中保持一致；已有单一样式配置继续迁移。
- 完善气泡和输入背景的百分比透明度、字体、头像与区域配色。图片气泡提供装饰大小、文字留白和边框预设，平铺改用纹理填充，减少窄切片的大量重复绘制。
- 新增离线主题分享码和包含素材的 `.oktheme` 完整主题包。接收方可以先预览，再选择目标角色并确认覆盖；完整包自动携带关联图片、视频与字体，分享码保留接收方的媒体设置。
- 支持将当前角色的主题应用到全部角色卡。角色编辑集中提供基础、内容、发言与绑定，Waifu 发言、表情和自拍配置按正在编辑的角色保存。
- 新增角色级 JavaScript 外观接口，使原生界面的背景、颜色、排版、形状、描边和图标能够由主题脚本控制。脚本在受限环境中运行，只处理外观，不向其开放聊天正文或系统工具。
- 新增原生主题工作室，提供可视化属性编辑、图层与素材管理、目录资源工程和源码编辑；预览直接使用原生聊天组件，便于对照双方消息、输入区和真实界面效果。
- 工作室按各部件实际支持的能力显示属性，补齐正式聊天中的外观消费、内侧描边、交互状态和输入区域形状；源码编辑增加轻量 JSON／JavaScript 高亮。
- 修复导入稳定版数据后进入气泡预览的字段读取崩溃，以及脚本背景被主内容实色遮住、应用后只露出顶部的问题；补充完整作者手册和验收场景。
- 统一普通设置页、工作区、终端、角色名和编辑器工具栏的主题配色，改善深浅模式、大字体及系统栏图标显示。替换图片、视频或字体后，回收已无引用的旧素材。
- 自定义表情改用已保存或自行导入的内容，移除应用自带默认图片、自动导入和恢复默认入口；已有角色私有表情及分组继续保留和管理。

## 模型配置与密钥池

- 模型与参数配置整合连接、参数、功能分配、上下文总结四个页签，支持配置分组、排序、筛选及组内编辑状态保留，减少设置入口之间来回切换。
- 每份模型配置独立保存流式输出选择；旧配置首次迁移时继承原全局选择，新配置默认开启工具调用与流式输出，已保存的关闭状态不会被重置。
- 请求能力改为可整行切换的列表，保留各类功能绑定、测试、思考覆盖、参数和并发限制。配置预览展示保存后的实际内容，并遮罩密钥与认证请求头。
- 密钥池提供评分与粘性路由、配额错误换钥、状态检测、批量管理、冷却倒计时和手动恢复；缩短常见错误冷却，并在配置修改后更新可用状态。
- 请求重试区分无效参数、无效密钥、余额不足、限流和临时故障。换钥与等待时保留具体原因，没有可用候选时停止无效重发。
- 修复单密钥、空池与空白池失败被误报为“密钥池耗尽”的问题，保留原始 HTTP 状态、请求错误和异常链。
- 模型列表获取提供更明确的超时、DNS 和服务端错误反馈；切换配置时取消旧请求，保留已保存模型与排序。
- 接入 Antigravity 账号认证；DeepSeek 图片请求接入 Files API 并复用上传结果，续写兼容不同思考分片字段，移除已停用的内置联网搜索字段；Codex 复用会话标识和缓存键，改善缓存亲和。

## 上下文总结与用量统计

- 上下文总结接入统一模型工作区，可以独立配置思考开关和档位，并选择是否在新摘要中再次压缩上一轮摘要。
- 新模型配置的默认日常与最大上下文调整为 200K 和 1000K；实际可发送量仍受所选模型及其服务限制，已有自定义配置继续读取。
- 总结内部每次重试通过进度与 OKToast 实时反馈，正确区分并行会话、取消和切换会话，避免把另一会话的失败提示带到当前页面。
- 当前上下文和累计用量按用途展示。累计统计覆盖使用者消息、AI 消息、工具结果、系统提示词、常驻工具、模型上下文协议与包工具、技能目录、压缩摘要和其他九类，并随聊天及备份保存。
- 增加月度、年度活动视图与独立活动日历，按当前周期刷新，改善密集图表的宽度和逐柱时间标注。
- 增加峰谷、周末／节假日和长上下文差异化定价；修复旧会话累计用量归零或被旧快照覆盖，并完善删除配置后统计保留与失效记录清理。
- 恢复用量重置入口并加入延时确认，避免误操作立即清空统计。

## 语音、图片与媒体

- 新增独立语音条录制、波形反馈、试听与发送；原录音和识别文字同时保留，支持转写后按文字继续请求。
- 将转写原话、声音观察与附加请求上下文分开处理，避免背景描述混入原话；已转写语音在历史和手动重试中直接使用文字。
- 语音服务改为原生工作区，集中配置语音识别、语音合成、服务档案和试听。普通聊天自动朗读移到语音设置，语音通话使用独立的朗读状态与播放实例。
- 云端朗读预取后续句子并按原文顺序播放，取消旧轮次请求和临时音频；离线朗读播放当前句时预合成下一句，减少逐句串行等待。
- 修复 Sherpa 离线语音回调引发的原生崩溃，提供实际有效的说话人选择，并按引擎能力显示语速、音调；试听和服务释放移到后台，减少设置切换等待。
- 按硅基流动接口要求修正 Qwen3-Omni 的音频内容格式。明确不支持的内容不再反复换钥发送，采用已有转写路径成功后，不留下已放弃音频尝试的临时错误卡片。
- 图片附件使用应用内相册选择器，支持相册切换、多选、连续划选、重复检测和预览；全屏预览提供翻页、双指缩放、双击复位与放大后拖动。
- 已发送图片按组叠放，过期图片合并为紧凑标签并显示数量，无法解码的图片明确提示。图片、音频和视频只随当前使用者轮次发送，后续对话不重复携带历史媒体。
- 屏幕内容可以作为图片附件发送；修复部分厂商图片选择器临时 URI 失效、语音请求丢失录音引用和工具结果误提取源码示例图片的问题。
- 内置画图包增加图生图能力，完善 SpaceXAI 与提示词输入，并将 OpenAI URL 参考图按编辑接口要求上传为 multipart。

## 记忆空间与检索

- 新增记忆空间总览与图谱工作台，集中浏览条目、关系、文档和导入操作，改进编辑、选择、搜索及默认空间的删除状态。
- 向量模型统一通过功能模型绑定，角色资料入口可以定位其实际绑定的记忆空间，减少角色、资料与记忆配置之间的割裂。
- 收紧语义候选与最小相似度筛选，补齐查询评分诊断和范围检索，减少无关结果混入；大字体下保留图谱与列表的可用空间。
- 数据与备份中的聊天管理可按完整记录或指定日期范围构建记忆，保留消息窗口配置、进度和取消。

## 文件工作区与终端

- 统一文件浏览、预览与编辑入口，工作区与终端共用工作台；关闭文件后保留浏览路径，聊天文件链接可以直接进入对应预览或编辑器。
- 完善文本注释规则、Markdown 预览链接和大文本读取限制，保留附加仓库的嵌套子目录，修复 Linux 文本搜索路径映射。
- 文件浏览支持多选、批量复制、剪切和删除。复制与移动使用流式传输，显示粘贴与删除进度，减少整份大文件驻留内存。
- 文件长按菜单新增属性，可查看和复制路径、统计递归大小及时间；无权限或统计不完整时显示未知，Linux 快捷入口仅在 Ubuntu 安装后出现。
- 终端工作台提供会话标签、快捷键栏及统一输入组件，入口先检查所需资源；修正安装依赖顺序、资源删除竞态和中断清理后的状态。
- 改善软键盘、实体回车、中文组合输入、光标、窗口尺寸变化和后台恢复，保留命令完成与当前目录同步，减少画面被键盘整体抬起或输入绑定丢失。
- 终端内置 `apply_patch`，已有 Ubuntu 环境在会话启动时也可安装更新，支持帮助与版本查询、文件输入、内存检查、差异预览、禁止覆盖、静默及 JSON 结果。
- 终端命令的所有非零退出码统一返回失败，保留原始输出、退出码和会话诊断；隐藏执行设置时长限制并回收异常 Shell，修复 Shizuku 管道阻塞与读取取消。

## 工具、插件与权限

- 新增原生 A2UI 动态卡片与组件目录，支持编译展示、修订和实时数据更新；修复编译成功却未显示卡片及 live 输入校验，生成与宿主投递职责更清晰。
- 重组插件、沙盒包、技能、模型上下文协议的统一管理界面，修正四标签等宽、大字体和完整名称显示；GitHub 账号的登录与退出集中到插件市场。
- 市场下载显示实际字节数、速度、耗时和预计剩余时间，未知总量明确标示；各条目隔离临时下载，失败后清理，扩展删除按当前应用的真实安装来源核实结果。
- 工具权限统一到标准、管理员、Root 三档实现，按实际授权路由；规则页支持默认策略、单项允许／询问／禁止、搜索筛选、批量管理和撤销上次修改。
- `operit_editor` 增加全局工具权限模式和性能指标查询；修正包工具、MCP 与 JavaScript 参数转换，并为 JSON 格式错误提供更具体的位置说明。
- 工具调用保留交错输出及 Responses 最终参数快照，统一结构化失败来源，避免同一错误在摘要和正文中重复展示；独立命令输出和补丁详情继续保留。
- 工具卡片新增可保存的实际执行耗时，亚秒显示毫秒，并行工具按执行区间合并计算；计时不混入回答正文、复制或后续模型请求。
- 减少大工具结果在 JSON 编解码、脚本拼接、事件投递和日志中的中间副本；按界面版本回收旧 Compose DSL 回调，减少重绘后的回调积累。
- 普通包、技能和模型上下文协议激活失败统一返回明确的失败状态，包不存在不再被包装成成功；图片理解、解码和 OCR 失败不再伪装为成功的文件正文。
- 模型上下文协议改为手动启动，移除应用开屏自动部署与启动；修复作者字段为空时列表刷新和复制异常。QQ Bot 修正监听开关、超时及停机状态保存。
- 内置浏览器限制重复自动开窗与外部应用确认，ref 点击在主线程读取 WebView 尺寸；UIAutomator 读取前后保存和恢复旋转设置，PC Agent 配置接口补齐鉴权与凭据保护。

- 脚本最终结果与运行日志分开展示，日志可以折叠；普通、流式和隐藏终端、浏览器动作等待及 BLE 读取超时统一按失败返回。

## 工作流

- 重做工作流浏览与编辑，支持复制、JSON 导入导出和统一配置入口，保留既有执行能力。
- 增加节点执行报告，展示节点名称、实际动作、状态、耗时、结果摘要和具体失败原因，支持选择复制，历史运行时间稳定保存。

## 数据、备份与诊断

- “数据与备份”集中概览、备份恢复、聊天管理和诊断日志，常用操作使用抽屉；保留已有统计入口、聊天搜索、关联管理、锁定保护和批量操作。
- 文件快照自动收集并恢复主题媒体引用，可选择是否包含日志；聊天 JSON／CSV 按页读写，携带结构化消息、文件夹、归档和累计统计，降低大记录导入导出的内存占用。
- 数据占用管理提供分类统计与清理，区分聊天、记忆、扩展、Linux、语音识别、语音合成、OCR 和运行引擎，改善头像、空状态、确认和删除进度。
- 日志导出支持排除调试、排除系统、仅错误上下文、隐藏敏感内容及不保留时间；新增当天有效的“写入日志”开关，跨天自动恢复。
- 重做崩溃报告的摘要、堆栈、行号、复制、保存及日志入口，报告与导出共用过滤设置，并提供异常特征分类。

## 更新与离线资源

- 个人发行线建立固定签名、完整 APK、增量 ZIP、补丁元数据与发行摘要，签名密钥通过独立配置注入，清理发行包中的内置签名密钥库。更新器按实际已安装 APK 的哈希选择可连接到目标的补丁链，并逐步校验基础包、补丁和还原结果。
- 增量下载核对 HTTP 字节范围、响应长度和分段偏移，改善不支持分段的下载来源处理；Release 正文使用可读更新说明，机器元数据独立为附件。
- Beta 计划控制 `+n` 补丁版本的发现，关闭时只选择无加号正式版；切换渠道清理旧检查结果，退出 Beta 不将已安装版本降级。
- 应用发行统一存放于 `Operit-Kong-patch`，固定离线资源存放于 `Operit-Kong-resources`，源码仓库负责开发协作；历史应用、资源和补丁链按分仓记录迁移。
- 离线资源工作区提供本地语音模型、OCR、九种工程模板及按需下载的内置扩展，显示下载进度、速度、剩余时间和存放位置，减少 APK 中的预置大资源。
- 升级保留通过身份、文件集合、大小和哈希核验的已下载扩展，区分“已安装”与“有新版可更新”；内容未变化时不要求重复下载。
- 使用中的扩展禁用删除并提示先关闭。新版本完整校验后清理同一扩展的已知冗余版本，保留仍占用、唯一可用或来源不明的目录；中断的终端资源清理可继续完成。
