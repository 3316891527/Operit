# 市场与角色卡页面主题文字和菜单统一

## 问题与目标

市场“我的”页在透明背景上显示的“发布到市场”“我的发布”和加载提示没有明确采用主题前景色，深色主题下会继承黑色文字。人设卡生成页顶部的说明文字与清空聊天记录图标存在相同问题。

角色卡管理页的导入、排序菜单仍使用默认菜单样式，需要与现有角色卡操作菜单统一：圆角面板、细描边、阴影和带底色的图标。

## 修改范围

- 为截图中的标题、加载提示和清空图标指定对应主题前景色
- 提取角色卡操作菜单已有的容器与条目样式，供导入、排序菜单复用
- 保留原有导入入口、排序选项及点击后的收起行为
