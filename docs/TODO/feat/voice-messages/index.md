# 单独发送的语音条与 STT 输入

从当前联调修复版本接入语音条：空文字且没有附件时显示麦克风；点击进入底部录音界面，展示真实音量波形、计时、关闭和“说完了”。连续三秒未检测到人声结束录音，没有人声时不发送。第一版使用确认页，支持试听、重录、查看转写与发送。

语音条只能单独发送。消息保留录音和 XML 语音条，模型请求使用现有 STT 配置得到的转写文字。第一版面向普通话，不增加语言选择和任意模型导入，也不接入原生音频模型或多路音频理解。

## 实施步骤

- 独立录音与语音条模块：持久化 WAV、VAD 静音结束、当前 STT 配置转写、资源释放
- XML 数据与模型输入分离：历史与当前请求只使用转写，录音继续由消息附件机制管理
- 经典与 Agent 输入样式接入麦克风，底部录音与确认界面接入权限和生命周期
- 语音条播放与转写展示，补齐状态、标记与请求转换的单元测试和完整设备验收清单
- 静态检查后提交，派发仓库 Debug 构建和 Android Tests；不在本地编译、构建或运行测试
