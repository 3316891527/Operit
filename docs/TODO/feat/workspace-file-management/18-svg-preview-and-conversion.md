# SVG 预览、编辑与格式转换

[返回计划](index.md)

## 现状与目标

SVG 已按图片 MIME 路由到预览页，但当前 Coil 图片预览没有 SVG 解码器，因此显示无法打开。列表缩略图也尚未包含 SVG。用户选择点击直接预览、长按显示编辑、转 XML、转 PNG 三项操作，界面沿用现有面板风格。

XML 指 Android VectorDrawable XML；PNG 保留透明度和原始宽高比例，转换结果由用户确定名称与输出位置，同名文件不静默覆盖。

## 实施范围

- [x] 在通用图片资源层复用 SVG 解析与等比例渲染，接入工作区预览和 SVG 缩略图
- [x] 预览展示透明背景并保留现有缩放手势，避免黑色图案消失在纯黑画布上
- [x] 单个 SVG 长按显示编辑、转 XML、转 PNG，编辑复用文本编辑器
- [x] PNG 导出提供尺寸与文件名，XML 导出生成可加载的 Android VectorDrawable
- [x] 转换保留源文件，通过现有文件访问能力覆盖 Android、Linux、授权目录
- [x] 补充转换与解码的回归源码、九语言字符串、静态检查和文档
- [x] 准备原 PR 提交上传与远程 Build、Android Tests 的交付流程

## 转换约定

转换在后台执行。对 Android VectorDrawable 无法表达的 SVG 特性报告具体原因，不生成伪装成功或静默丢失内容的结果。导出发生失败时不报告成功，不覆盖既有文件。

## 验证边界

本地只进行源码语法、接口、资源、文档、许可和差异静态核对。新增回归交由远程流程执行，确认运行记录建立后停止查询进度。

## 实现与交互

`SvgImageAsset` 统一 SVG 解析、自然宽高、透明位图和正方形标识渲染；`SvgImageAssetDecoder` 显式接入 Coil 2.5 的单次请求。图片预览和 SVG 缩略图复用该入口，分别限制输出长边为 2048 像素和列表图标尺寸，没有新增依赖。

普通文件列表点击 SVG 进入图片预览，透明区域使用中性棋盘格，保留双击与双指缩放。单个 SVG 长按使用项目现有圆角操作面板，只显示编辑源码、转 XML、转 PNG。已有预览标签可以切到源码，已保存的源码也可以重新进入预览；存在未保存编辑内容时保留编辑状态。批量操作和归档原有菜单继续使用通用文件菜单，共同图片预览入口的 SVG 解码也适用于归档提取内容。

转换对话框提供名称、后缀和输出目录；PNG 提供宽高输入及保持比例开关，宽高范围为 1–4096 px，保留透明度。读取与转换在后台执行，关闭对话框会取消任务。转换先写独立暂存目录，完成后使用已有跨环境传输发布，同名目标拒绝覆盖，失败清理暂存内容。

XML 输出是 Android VectorDrawable。支持路径、圆、椭圆、直线、矩形和圆角矩形、多边形、局部 use 引用、继承颜色与描边、平移缩放旋转及无倾斜的仿射矩阵、线性渐变和可表达的径向渐变。viewBox 偏移与宽高比例保持一致；包围盒渐变的方向按非等比坐标变换换算。SVG 滤镜、蒙版、裁剪、文字、图片、外部样式、倾斜、组透明度和其他不能准确表达的特性会报告原因，不静默丢失图形。
