# 聊天 UI 重构

当前消息底部逐行展示 Token、耗时、速率和时间，长按消息信息缺少速率，数字没有千位分隔符。第一节把统计收进默认折叠的生成详情，并统一两处数字和速率的展示规则。

## 第一节范围

- 折叠标题使用无小数的 K/M/B 总用量，展开显示精确总计、输入、输出、缓存命中、命中率、首包等待、生成耗时和 Speed
- 完成时间由已有开关控制，显示在整条消息右下角
- 长按消息信息增加 Speed 和完成时间，完整数字使用逗号千位分隔符
- 保留已有主题配置键和统计口径，不增加数字格式选项
