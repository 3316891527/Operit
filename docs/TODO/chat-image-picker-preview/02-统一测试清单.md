# 统一测试清单

统一测试分支：`feat/kong-chat-experience-integration`。安装该分支的 `assembleDebug` 产物即可覆盖 PR #7、#8、#9 与本次第 21 条图片功能。

第 6 条全局 Toast 和第 22.2 条删除动画待定，第 23 条聊天列表修复不在本次实现范围。下列预期均待验证；需要特定 Android 版本、API 故障或存储故障条件的项目可单独标记未具备条件。

构建与 JVM 结果以统一分支的仓库工作流为准：

## A 工作区、归档、账号与资料

- A01：浅色和深色主题打开选择工作区、创建工作区界面；预期：状态栏、页面取色正常，背景不透出原窗口标题
- A02：在聊天、工作区与终端页面之间切换；预期：标题与当前页面一致，工作区背景完整遮挡聊天控件
- A03：归档聊天后切换常规与已归档列表，再恢复；预期：常规列表隐藏归档项，归档列表可查看和恢复，文件夹路径正确
- A04：归档后退出重进应用，再触发自动选择最近会话；预期：归档状态保留，自动选择排除归档会话
- A05：导出导入 JSON 和 CSV，并导入不含归档字段的旧备份；预期：新备份保留归档状态，旧备份按未归档处理
- A06：检查设置和插件市场管理中的 GitHub 入口；预期：设置不再显示账号板块，市场管理保留登录与账号管理
- A07：从角色卡点击资料入口并修改保存；预期：入口容易点击，保存后有提示，资料与记忆空间管理可进入
- A08：展开资料弹窗的长内容并打开键盘；预期：内容可滚动，弹窗不被截成半截，操作可触及
- A09：修改资料但不保存，尝试进入管理页面；预期：先处理未保存确认，取消跳转仍可保留当前编辑

## B 聊天删除状态

- B01：删除当前未锁定聊天；预期：允许删除并切换会话，不误报已锁定
- B02：删除非当前未锁定聊天；预期：目标被删除，当前会话不变
- B03：尝试删除锁定聊天；预期：拒绝删除并明确提示锁定
- B04：目标已被移除后再次执行删除；预期：提示目标不存在，不误报锁定
- B05：分别清空未锁定与锁定的当前聊天；预期：前者清空消息并保留会话，后者拒绝并提示锁定
- B06：在可控条件下令删除或清空落盘失败；预期：显示对应失败提示，不统一误报为锁定

## C 请求错误与重试

- C01：单密钥返回 401；预期：首次失败后停止，只提示一次终止错误，不发送完成通知
- C02：密钥池候选依次鉴权失败；预期：逐把排除失败密钥，最后一把不重选，最终提示一次
- C03：参数校验返回 400 或 422；预期：不重试、不换钥，显示服务端参数原因
- C04：单密钥返回余额或配额不足，覆盖 400、402、403 和通用错误类型；预期：保留首次请求加最多五次重试，耗尽后提示一次
- C05：单密钥持续返回 429、503、连接超时或首 token 超时；预期：完整使用重试预算，期间保持处理中，最终提示一次
- C06：暂时故障后重试成功；预期：正常完成，没有终止错误弹窗
- C07：已输出文字后连接失败并耗尽重试；预期：保留部分输出，退出加载，不发送成功完成通知
- C08：重新生成返回参数错误或无效密钥；预期：不发布完成变体，仅由重新生成调用边界提示一次
- C09：重新生成成功；预期：生成并切换变体，退出加载
- C10：请求或重试过程中点击停止；预期：按取消处理，不显示终止错误，不发送完成通知
- C11：连续两个回合分别失败；预期：每回合独立提示一次，旧错误不在新回合重放
- C12：普通发送成功并触发异步总结；预期：回复、总结与完成通知沿用原流程

## D 图片选择与全屏预览

- D01：经典输入布局点击图片附件入口；预期：打开应用内 Compose 图片选择器
- D02：Agent 输入布局点击图片附件入口；预期：打开同一套选择器，弹出层可正常关闭
- D03：跨相册选择多张图片，再取消其中一张并确认；预期：选择数量准确，只添加最终选中的图片
- D04：选择图片后点击关闭或系统返回；预期：不添加任何未确认图片
- D05：点击已添加图片缩略图，再点右上角 X 或系统返回；预期：全屏显示图片，关闭只退出预览，附件仍保留
- D06：对横图、竖图、方图双指缩放并拖动；预期：支持一至六倍缩放，拖动不会把图片完全移出视口
- D07：双击图片局部，再次双击；预期：围绕触点放大至三倍，再回到适配居中
- D08：放大后关闭并重新打开预览；预期：从适配大小开始，不沿用上次缩放和偏移
- D09：在选择器长按图片，或选择后点击预览；预期：打开同一全屏预览，关闭后保留选择状态
- D10：Android 8 至 12 分别授予和拒绝读取权限；预期：授权后显示可访问图片，拒绝时显示授权及设置入口
- D11：Android 13 分别授予和拒绝照片权限；预期：按 READ_MEDIA_IMAGES 授权结果展示，不把拒绝显示为空相册
- D12：Android 14 起只授权部分照片，再管理可访问图片；预期：只显示已授权内容，授权范围调整后列表与选择同步更新
- D13：从系统设置撤销照片访问后返回；预期：重新检查授权并移除失效选择，无权限时显示授权界面
- D14：空相册、读取失败和点击刷新分别验证；预期：空列表与错误状态区分，刷新可重新读取
- D15：在图片较多的相册持续滚动、切换相册和刷新；预期：按可见项加载缩略图，网格使用稳定 URI 标识，不出现索引越界
- D16：重复添加同一图片，另用改名副本或不同来源 URI 添加；预期：提示图片已添加，待发送列表不新增相同内容
- D17：添加同名不同内容的图片，移除旧图后重新添加旧内容；预期：不同内容可同时存在，移除后允许重新添加
- D18：相机和截屏生成图片附件后点击缩略图；预期：已有添加方式正常，图片可以全屏预览
- D19：通过文件入口添加非图片附件；预期：原文件添加行为正常
- D20：选择图片并发送给已配置的识图模型；预期：继续通过原附件副本与多模态链路发送
- D21：键盘已打开时进入选择器，并在横竖屏、浅深主题下检查；预期：关闭和确认按钮可触及，背景与文字可辨识
