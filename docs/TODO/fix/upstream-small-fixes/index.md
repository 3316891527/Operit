## 玻璃排查结论

水玻璃与磨砂玻璃保留独立渲染实现。输入框材质选择器分别写入 chat_input_water_glass 与 chat_input_liquid_glass，互斥规则、读取入口和渲染调用一致，未发现选项对调或合并。

正式主题及工作台预览都为两种材质建立背景采样。水玻璃使用 Liquid 曲面折射，磨砂玻璃使用 Backdrop 模糊；正式输入框的磨砂效果还包含透镜。二者使用同一区域的模糊、染色等参数，背景不透明度还会影响染色强度，背景本身缺少细节时不容易区分。

两种材质均要求 Android 13。输入框背景不透明度为零时效果关闭；不透明度为一时按不透明区域处理。材质选择会清除已有的一值以启用透明绘制，不会改变用户保存的零值。

确定的代码差异是预览未启用磨砂透镜，本次补齐。未进行设备视觉复现，不认定已经定位或修复“两种看起来一样”的真机原因，不调整水玻璃折射强度与默认模糊参数。
