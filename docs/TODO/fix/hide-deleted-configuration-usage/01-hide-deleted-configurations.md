# 配置详情清理

## 范围

从真实配置摘要获取名称和 ID，不使用名称是否像 UUID 来判断。点击后读取全部历史用量涉及的配置 ID，隐藏其中已从真实配置列表删除的 ID，跨日期和模型筛选生效。旧版明确标记已删除的配置同样可清理；未指定配置的历史统计保留。


隐藏记录保存在既有统计 Preferences 中，不删除或重写 Room 用量和定价数据。配置详情只过滤待显示的行，数量使用过滤后的行数；同 ID 配置恢复后可再次显示。清理期间禁用重复操作，保存失败使用现有操作错误提示。

## 验收

- 入口位于配置数量左侧，清理后数量与可见条目一致
- 有效配置即使命名为 UUID 也保留，未指定配置保留
- 清理结果跨重新进入、重启、日期切换和模型筛选保留
- 原始请求、token、费用、模型累计及趋势继续包含被隐藏条目的用量
- 再次点击不改变已有隐藏结果，新删除的配置可继续清理
