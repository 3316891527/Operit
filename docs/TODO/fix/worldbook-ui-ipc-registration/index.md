# 世界书管理界面 IPC 生命周期修复

[返回修复计划](../README.md)

PR #160 将管理界面改为向 main 运行时请求存储服务，但通道仅在元数据收集阶段的 registerToolPkg 中注册。实际 IPC 请求在独立 main 上下文加载入口后直接分发，不调用元数据注册函数，导致条目、分组和角色列表报通道未注册。

- 将 IPC 服务注册移到主入口模块加载阶段，继续共用主运行时的串行存储服务
- 移除测试辅助函数中手动注册服务的行为，增加独立注册阶段与冷启动、重复调用、重启后的 UI IPC 回归
- 同步编译产物和插件补丁版本，生成可直接导入的修复包
- 验证现有存储故障回归、生成文件一致性以及本修复的构建和测试；保留 open PR 等待合并许可

## 当前验证记录

旧入口在三个冷启动用例中均复现 worldbook.storage.listEntries 未注册。修复后 TypeScript 源码与测试编译通过，全部 27 项世界书集成、存储故障与生命周期回归通过，0 跳过；合成六条已有条目的读取不会改写原 JSON。

测试辅助层不再手动注册 IPC 服务，避免掩盖入口生命周期错误。管理端仍通过主运行时服务访问数据，条目格式、配置目录及原存储保护不变，插件补丁版本为 1.2.2。

构建交付沿用已有 Build 的 assembleDebug 与 Android Tests 工作流；本修复未修改 CI 工作流。生成的 .toolpkg 用于更新已安装插件，APK 不等同于替换插件。代码保持 open PR，设备界面验收仍待维护者反馈。
