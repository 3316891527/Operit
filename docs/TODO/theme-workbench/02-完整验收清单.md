# 主题工作区完整验收清单

本轮共 221 个场景，全部为待执行。场景定义与填写结果分开，不将静态核对或 HTML 验证算作 Android 验收。

同分支上一批模型、更新、工作流与附件的 [490 项完整清单](../config-workflow-attachments/02-完整验收清单.md) 保持原内容和历史结果，仍需一起使用。
