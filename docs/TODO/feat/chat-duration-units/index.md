# 聊天耗时单位进位

## 目标

将首包等待、生成耗时、消息信息、回复过程标题及工具执行标题的耗时显示统一到 `ms`、`s`、`m`、`h`、`d`，最长单位为天。

## 规则

- 不足一秒显示整数毫秒，例如 `999ms`
- 一秒起保留两位小数，例如 `4.00s`、`1m51.32s`、`1h1m1.32s`、`1d1h1m1.32s`
- 秒始终显示，数值为零的天、时、分省略；整数分钟显示为 `1m0.00s`
- 先按百分之一秒四舍五入，再进行单位进位，避免出现 `60.00s`
- 消息信息保留括号内的原始毫秒数；时间戳、Token 数量和 tokens/s 计算保持原有含义
- 工具运行中、完成、停止和组合工具标题共用同一规则，历史记录从已有毫秒耗时格式化

## 范围

- 新增无 Android 依赖的共用 UI 耗时格式化函数
- 接入消息统计、消息信息、回复过程标题及工具耗时标题
- 同步现有本地化文案的参数类型，删除不再使用的秒/毫秒专用文案
- 更新现有格式化用例，补充分钟、小时、天及舍入边界的回归用例
