# 资源与并发

头像、背景、消息图片和自定义字体接受可读 Android 文件或已授权 content URI。复制到现有资源清理机制管理的应用私有文件目录，并校验真实内容。字体保存路径，图片与视频保存文件 URI。资源导入不进行网络下载。

失败只清理本次独占创建的副本；成功持久化后完成资源提交标记，再允许取消传播。旧资源沿既有引用清理释放，不删除调用方提供的原始文件。

主题页原本持有独立草稿并整份保存；新增命令后，旧草稿可能覆盖较新偏好。通过基线、草稿和当前持久值三方合并保留各自未冲突的修改；同一字段的不同修改明确报告冲突并保留草稿。

保存事务和会话确认由不可取消边界保护，完成后立即移交已保存素材归属，后续传播或全局保存失败不会删除已持久引用。会话以实际合并值推进基线，并保留保存期间继续编辑的内容。全局名称在自己的偏好事务中三方合并，只改名称并保留当前头像。

重置将默认值草稿合并后写入，保留角色头像与标题，不清除全部 override。“应用到所有角色”先对当前角色检查冲突并保存，再执行原有的强力视觉覆盖；后续失败保留已经完成的保存状态。
