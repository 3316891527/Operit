# 聊天历史加载与分块渲染性能

用户在 Android 个人发行版中反馈：快速滚动历史消息短暂降至约 20 FPS，启动到消息显示由旧版约 1 秒增加到约 4–5 秒，加载更早消息也变慢。这些数值来自用户的版本对照，尚无本次修复的设备测量。

保留结构化消息及工具、思考卡片的展示能力，缩短数据库加载和静态消息进入分块列表时的处理路径。另移除资源访问层主动打开下载页的行为，使后台语音初始化不会打断启动。

作用域包括 sections JSON 解码、历史回填事务、聊天时间线的静态解析入口、两种消息样式的分块复用，以及离线资源缺失时的导航。数据库格式、协议保存、消息编辑、流式消息和设置中的资源管理入口继续遵循既有接口。资源下载页视觉设计和终端视觉差异另行处理。

本轮直接提交个人集成分支，暂不创建上游 PR。
