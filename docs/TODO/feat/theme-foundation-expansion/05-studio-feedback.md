# 工作室入口与背景跟随

本轮按设备反馈收拢页面背景并简化文字编辑，不删除任何页面目标或渐变能力。

- 顶层部件目录只保留全局背景入口，内部用可搜索选择器编辑全局背景和 66 个页面背景；单页继续保存独立的明暗模式渐变、图片和图层
- 页面没有独立背景时跟随聊天主界面；聊天没有单独背景时使用全局背景。单页可恢复跟随，批量操作清除所有非聊天页的明暗模式覆盖，并沿用一次撤销
- 字重使用连续滑条和数值输入；删除字重枚举与文字描边宽度快捷预设。描边用开关区分继承和独立配置，滑条零宽度可显式关闭局部描边
- 页面预览按实际路由分类绘制静态内容，共用背景和原生主题部件；不发起业务请求或执行终端命令
