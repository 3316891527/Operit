# 1.12.2+26

本次更新重点完善工作区文件管理、文本编辑和文件变更审阅，并修复聊天动画与主题显示问题。

## 工作区与文件管理

- 工作台集中展示工作区文件、当前对话产出和终端、浏览器会话；没有文件产出的对话不再显示空区域。
- 完善路径跳转、收藏、首页、隐藏目录、递归名称与内容搜索，支持文件类型、大小、时间和选中范围筛选。
- 支持横滑多选、区间补选、批量操作、汇总属性与多文件分享，改进复制、剪切、删除和解压进度。
- 完善归档浏览、压缩解压与 ZIP 包内操作，增加图片缩略图、APK 信息，以及 SVG 预览和 PNG、Android XML 转换。

## 编辑器与变更审阅

- 完善软换行、撤销重做、查找替换、跳行、缩进、只读模式、另存为与文件外部变化检测。
- 接入离线 TextMate 多语言高亮，统一文件识别与编辑器配色，支持轻量 JSON 自定义高亮规则。
- 空文档、空行和文字右侧空白处支持长按定位、全选与粘贴。
- 提供 Git 变更、分支对比、上一轮变更和完整操作历史，支持紧凑单双栏差异、行内强调、折叠与改动块导航。
- 编辑器新增“代码溯源”，查看当前行的作者、时间、来源提交及历史差异；未提交内容和缺少历史会显示对应状态。
- 操作记录支持“删除此次记录”和“清除此文件全部记录”，不改变实际文件；无引用的历史快照同步清理。
- 打开当前文件前先校验并读取，文件不存在、权限不足、连接变化、类型不支持等失败原因直接显示在当前页。

## 打包与体验修复

- HTML 项目改为在终端使用 build html 打包为 Android APK 或 Windows 程序，持续显示实际阶段与耗时。
- 统一耗时单位和舍入显示，改善长时间操作的可读性。
- 修复新建聊天动画在请求清空、替换或离页时可能崩溃的问题。
- 修复市场和角色卡的主题文字、图标颜色与菜单样式。
- 整理插件、模块和 WebChat 源码目录，同步构建与资源路径，保留既有离线资源兼容性。

沿用 Kong 包名和固定签名，版本号为 82。支持从 1.12.2+25 使用增量包更新，也可下载安装完整 APK。
