# 搜索反馈与文档预览打磨

## 原有行为与本轮目标

查找开关只有缩写，点击后没有说明。零匹配与正常计数同色，上下查找立即跳转。Markdown 预览额外包裹圆角阴影卡片，没有章节目录。HTML 文件预览在每次重组时重新加载全文，也没有可见文本查找入口。

本轮增加三个开关的 OKToast 信息提示，在有效查询完成且零匹配时将结果标红，保留零结果导航禁用。搜索定位复用编辑器主线程滚动器提供短动画。Markdown 去除外层卡片，正文直接使用可用区域，目录复用现有渲染 AST 中的标题和实测位置，支持层级折叠与动画定位。HTML 文件查找使用 WebView 原生可见文本搜索，并只在文件内容变化时重新加载页面。

## 范围与决策

- Markdown 章节目录使用已有渲染节点，不另建 Markdown 解析器，不把围栏代码中的井号当作标题
- HTML 查找不搜源码，不加入正则或大小写开关；完整 F12 面板留待独立工作，现有服务器 Eruda 注入依赖在线 CDN，需要另行处理离线资源和生命周期
- 保留原有 Markdown 链接、媒体和语法渲染能力，不根据调试版本的主观卡顿推断性能根因
- 延续同一 PR，补齐九语言资源、必要的回归源码和静态核对，再建立远程验证记录

## 实施清单

2. [x] Markdown 正文去卡片、章节提取、折叠与滚动定位
3. [x] HTML 原生查找、稳定加载及离页清理
4. [x] 回归源码、九语言与静态核对、同一 PR 交付

## 验证边界

本地不执行编译、构建或测试。静态检查与回归源码分开记录，远程工作流建立后停止查询进度。实际设备滚动效果、WebView 查找行为和多主题视觉仍待验收。

## 实现记录

编辑器查找开关使用现有 OKToast.info，提示本次切换后的“区分大小写／全词匹配／正则表达式：开／关”，同时提供无障碍状态说明。查询为空、仍在计算或正则错误时不显示红色零匹配；已完成的有效查询零匹配使用主题错误色，导航继续禁用。

上下查找复用主线程 OverScroller 和原帧回调，定位时间为 220 毫秒。连续查找、触摸和切换编辑会话会中断旧定位；系统关闭动画时直接定位。真实光标、选区搜索范围与文件内容沿用现有行为。

Markdown 移除外层圆角、阴影、固定最大宽度与双层内边距，正文保留适量页边距。可选的目录观察器仅由工作区预览启用，从现有顶层 HEADER 节点取得标题，按实际布局位置定位。目录保留 H1 到 H6 的父子层级、重复标题和跨级标题，支持折叠、当前章节高亮和 220 毫秒平滑定位，代码块及嵌套渲染器不会覆盖目录。

HTML 预览使用独立 WebViewHandler 和原生 findAllAsync／findNext。查询只匹配渲染文本，输入期间显示等待状态，关闭后清理高亮。文件路径及内容没有变化时不重新加载页面，更新文件内容后会重新查找当前关键词。触摸拦截与 WebView 释放提取到共同文件，既有工作区网页预览继续复用。

预览顶部操作与源码工具分开显示：Markdown 提供目录和返回源码，HTML 提供页面查找和返回源码。切换预览会关闭编辑器源码查找，避免同时出现两套搜索入口。

## 静态核对与回归源码

本轮 24 个文件，包含 13 个 Kotlin 文件、九语言的七个新增字符串键和实现记录。Tree-sitter Kotlin 语法、新增项目内引用、字符串引用及占位符、文档相对链接和差异空白核对通过，没有新增依赖。

新增七项设备回归源码，覆盖真实 Markdown 解析的六级标题及围栏排除、跨级和重复标题、折叠后保留兄弟章节、实际标题布局位置与移除清理、HTML 渲染文本及隐藏源码排除、内容更新后的计数，以及搜索反向定位后保持文档和范围。回归源码尚未本地执行，不能视为通过结论。

代码实施完成。远程构建和 Android Tests 的运行记录及仓库卫生、增量翻译检查由同一 PR 的交付记录维护；建立远程运行记录后停止查询进度，设备视觉与实际动画效果待验收。
