# 单层滚动实现记录

原实现把长消息放进一个有高度上限的内部列表，外层聊天仍使用普通滚动列，形成两层滚动。

主聊天现在使用标准 Compose LazyColumn。短回复作为完整条目显示；长回复的分组标题、工具调用、执行结果和 Markdown 内容块作为外层列表条目显示，不创建整条回复的内部滚动区域。超长纯文本保留完整内容并按块拆分，复杂内联内容保持原有解析语义。

Markdown 的流式收集和静态解析由消息持有，离屏条目只停止布局与绘制。分组展开选择以及工具、思考和 details 卡片状态保存在消息之外的可保存状态中。内容身份使用节点类型及同类型序号，协议元数据的过滤不改变工具和思考卡片的身份。

气泡标题和头像只显示在首块，统计与版本切换只显示在末块；各块保持相同宽度和缩进，仅消息首尾保留外侧圆角和边距。图片背景的顶底装饰只在首尾绘制，位图使用 12 MiB 缓存，避免逐块重复解码。玻璃气泡的分块内部不叠加边框和阴影，具体视觉效果仍需实机核对。

历史定位按消息对应的首个内容块跳转，加载历史依靠稳定条目键保留当前位置。流式跟随由消息与输出推进触发，向上阅读时由现有导航器暂停跟随。长按菜单、复制、多选、收藏及操作索引仍使用完整消息。完整消息预览和图片导出使用独立的完整渲染入口。

作用域：common/markdown/lazy、chat/components/timeline、主聊天滚动入口、消息外观和卡片展开状态。旧 ThinkToolsViewport 及其接口已清理，未启用仓库内的自定义 RecyclerLazyColumn。
