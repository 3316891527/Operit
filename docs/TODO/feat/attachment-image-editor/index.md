# 发送前图片标注编辑

## 需求与范围

待发送图片预览左下角提供编辑入口。编辑支持画笔、矩形、圆形、箭头、马赛克、文字、裁剪、橡皮擦及撤销重做；首版不提供动画、贴纸和高光笔。编辑器右下角完成，其上方撤销一步；右上角关闭、系统返回及边缘返回统一检查未保存更改，保存后替换附件，选择不保存才丢弃编辑。

不改相册原图，不写入相册。合成结果保存到 cleanOnExit，以原位替换方式更新一个待发送附件，绝不把原图和编辑图追加为两张图片。继续沿用发送时的图片池流程。

## 实施顺序

1. [DONE] 编辑文档、坐标与撤销记录
2. [DONE] 图片解码、标注合成、裁剪与临时 PNG 导出
3. [DONE] 编辑画布、工具栏、文字编辑与未保存确认
4. [DONE] 主聊天和悬浮窗附件原位替换及预览编辑入口
5. [DONE] Kotlin 语法、XML、资源引用与差异静态核查

## 验收重点

- 不同缩放比例下落笔、形状、马赛克及裁剪坐标一致
- 橡皮擦仅擦除标注；撤销重做恢复包含裁剪在内的完整编辑状态
- 完成、关闭及系统返回保存路径只提交一次；取消确认继续编辑
- 修改后附件数量、顺序不变，未发送原图及其他会话草稿不受影响
- 编辑结果不进相册，实际发给模型的是合成后的单张图片
