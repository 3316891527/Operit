# 独立发行增量更新

原更新检查从关于页面字符串推导上游完整包仓库，内测增量源固定为 `AAswordman/OperitNightlyRelease`。本轮将独立发行版的更新查询统一到 `3316891527/Operit`，应用内无需启用上游内测计划即可发现同基础版本的增量更新。

客户端选择独立发行的 `app-kong.apk`，按数字版本而不是 API 返回顺序选择正式 Release，忽略草稿、预发布、无效标签与其他包名的 APK。同基础版本有成对补丁资源时显示增量更新，跨基础版本提供完整 APK。发布 JSON 正文中的元数据用于补丁链索引，界面只展示发布说明。

Android Build 新增发布开关、可选基础标签和发布说明。发布脚本校验固定签名与包名、递增 versionCode，生成已有 apkraw 协议的补丁并逐字节还原校验。完整产物上传到草稿后再公开，避免更新检查读取未上传完毕的版本。完整使用方法见 ci/distribution/updates/README.md。

首次接入仍需完整安装一次本轮 APK；旧包不会因个人仓库出现标签而改变上游更新源。首次正式 Release 建立完整 APK 基线，后续同基础版本发布才能生成补丁。当前保持用户指定的 `1.12.2+1`、versionCode 53，后续正式发行继续同时递增版本名与 versionCode。

## 验证与边界

新增 9 项客户端 JVM 用例和 6 项发布脚本用例，交给仓库工作流执行。本地完成 Python 语法、YAML、更新源引用和 diff 检查，没有运行本地测试或 Android 编译。尚未创建真实 Release，未验证真实增量安装或给出补丁体积承诺。
