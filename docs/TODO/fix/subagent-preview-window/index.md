# 子代理预览版窗口与工具展示修复

预览版验收发现：流式内容改变任务窗口高度；子会话使用默认 Markdown XML 展示，工具调用、工具结果和思考以原始标签呈现；执行事件仍记录代理入口名；模型报告存在原文转述失真和未证实的环境归因。

本轮延续未发布的移动端窗口方案，在统一集成 PR #236 中修复，继续使用同一个集成包验收。四张实机参考截图用于生成一版视觉设计参考，不将真实聊天或截图提交仓库。

1. 固定任务窗口的可用高度，标题、页签、操作区保持稳定，中部单独滚动；横屏、键盘和较大字体需要设备验收
2. 子会话提供专用紧凑工具卡，按调用配对结果，参数和输出在卡内切换，长输出有界滚动，原始消息及工具请求保持原样
3. 流式未闭合协议通过只读展示解析呈现，展开状态使用消息与片段身份，工具完成及新片段到达不重置用户选择
4. 调用参数一旦包含目标名称，就展示真实包工具名；调用事件在工具执行前使用同一名称解析
5. 核对子代理报告提取与投递，强化逐字引用、指标口径和未验证推断的提示要求；模型质量仍以真实对话复核
6. 增加协议片段、流式调用、代理参数、重复工具配对与报告原文的定点回归，更新文档后推送并派发统一 Debug 与 Android Tests

范围不涉及任务调度、数据库结构、工具权限、模型选择或自动重试。设计稿为视觉参考，完成记录区分本机回归、Android CI 和真实设备验收。
