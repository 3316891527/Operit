# 采样结束和会话归属

初次聊天请求和工具续轮独立登记，分别记录每次 provider 调用及其重试序号。语音转写重发时序号可重新从 1 开始，不沿用原生音频调用的数据。`onUsageFinalized` 只确认成功的 attempt，整个采样正常结束并仍归属有效会话时才发布。失败、取消和中途补充消息造成的采样中断不覆盖已确认值；较早发出的请求也不能覆盖已经发布的较新结果。

只采用内置远程协议的上报。保留明确的 0、同一 attempt 的部分更新和完整快照撤回规则；Claude 的分段输入先合并缓存读取、缓存写入和未缓存输入，再用既有归一化规则计算总量。本地计数与 ToolPkg 自行提供的计数不显示为服务端值。收到成功确认但该 attempt 未提供可用输入时，隐藏该行，不把旧数字当作新请求的结果。

明细按显式 chatId 订阅对应实例，保留发送前估算及其百分比，只移除最近请求行与当前模型上限的比值。删除会话或清空全部消息时失效该会话的在途报告，重置聊天统计时一并清除。该诊断值只保留在进程内，不写入聊天、用量账本或备份。

新增 14 项 JVM 回归源码，覆盖重试、完成信号、取消、中途补充、语音重发、会话隔离、清空、来源和缓存分量。仅使用合成 usage，未调用实际服务；本地不编译、构建或运行测试，类型编译和远端测试以 CI 为准。
