# 完整回归清单

仅安装 Operit Debug，与 Kong 发行版并存。所有条目本轮尚未填写真机结果；云端 JVM 用例也需以本轮工作流结果为准。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| 01 | 普通短答、代码、表格及 Mermaid | 原有正文正常显示与复制 |
| 02 | 加载 dynamic_ui，读取说明并生成展示卡片 | 正文中的短引用显示为原生卡片 |
| 03 | 同条回答在段落之间生成两张卡片 | 位置正确，填写状态互不影响 |
| 04 | 原生表单输入、开关、日期和选项 | 只更新本地，不发起模型请求 |
| 05 | 购物清单、费用试算和筛选图表示例，尝试最小值、最大值及空选项 | 同一输入驱动数量、结果和图表；已勾选行不丢失 |
| 06 | 卡片本地保存后继续编辑和取消 | 正确恢复已保存值 |
| 07 | 卡片填入数据后滚远再返回、重启应用 | 恢复相同卡片状态 |
| 08 | 长消息超过分块阈值，滚动多个卡片块 | 不重复卡片身份，不重复首屏解析 |
| 09 | 切换候选回复，再切回 | 各候选卡片数据独立 |
| 10 | 删除候选、修改卡片正文或删除消息 | 不将旧数据填入其他候选或修订 |
| 11 | 创建聊天分支，在分支中修改卡片 | 带入已填写数据，后续修改与父聊天独立 |
| 12 | 清空聊天、导入覆盖及删除聊天 | 旧表单状态清理，新消息可正常保存 |
| 13 | 输入框保留草稿、附件和回复目标，再确认卡片 AI 提交 | 新增请求正常发送；草稿、附件与回复目标保留 |
| 14 | 卡片提交确认中切换聊天、候选或删除消息 | 拒绝旧身份的提交 |
| 15 | 聊天处理中连续点击 AI 提交 | 不重复发送，不绕过忙碌检查 |
| 16 | 确认工具请求，分别使用允许和禁止该工具的角色卡 | 沿用现有权限和确认机制 |
| 17 | 多个聊天并行准备卡片，交叉使用短引用 | 不能跨聊天请求解析或修改 |
| 18 | 模型流在引用中间重试或回滚，另测试取消和缺失引用 | 已接受内容不重复；不完整内容不可交互，缺失引用有提示 |
| 19 | 思考、工具结果或代码示例中出现引用及工具 XML 文本 | 不展开内部短引用；卡片文字不触发旧 XML 工具执行 |
| 20 | live 卡片更新，尝试旧版本号、结束请求后再更新 | 版本冲突或失效请求被拒绝，用户输入不被覆盖 |
| 21 | 卡片浅色、深色、自定义文字色、图片与玻璃气泡 | 文字和控件可读，现有聊天主题可继续使用 |
| 22 | 明确请求离线 HTML/CSS 卡片，点击加载再滚出屏幕 | 点击后加载，离屏销毁；作者脚本和联网被拒绝 |
| 23 | 切换设置、侧栏、附件及图标较多的页面 | 原图标正常，按名称指定的插件图标仍可见 |
| 24 | 同变体比较基线和本轮 Debug APK、查看 APK 报告 | 记录实际字节及分项；离线大资源仍不打包 |
