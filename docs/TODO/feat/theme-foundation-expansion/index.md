# 渐变、页面背景与分目标文字排版

本轮先核对既有文字描边的 JS 通道，再扩展三项基础能力。保留既有 `background` 标识与外观字段，在工作室中将其展示为全局背景；新增页面背景和独立文字目标，不改变现有主题文件类型。

## 顺序与范围

1. [描边与共享协议](01-protocol-and-stroke.md)：核对模型、校验、类型声明、明暗模式和原生消费，补齐新字段的相同链路
2. [原生渐变与页面背景](02-gradients-and-pages.md)：统一渐变参数与编辑器，页面背景覆盖主导航可到达的页面，工作室可选择目标并预览
3. [全局排版中的独立目标](03-text-targets.md)：在全局文字排版中选择通用文字角色及具体目标，覆盖模型名称并保持文字描边可用

## 交付要求

- JS、可视化、明暗模式、资源引用、保存及导入导出使用同一组字段
- 页面使用稳定标识，真实页面与预览读取同一个背景；明确背景与内容面的叠放
- 文字目标通过通用解析接入，保留现有区域排版，并说明各层覆盖顺序
- 更新 SDK 类型、示例、协议和验收说明；为新增协议边界补充回归用例

实现及核验状态见[交付与体验清单](04-verification.md)。
