# 生成中消息排队与引导

## 原有行为与目标

当前已有文本消息队列。同步上游 #1481 的当前轮引导、附件和引用队列快照、编辑恢复及按聊天隔离的草稿，将输入从接受、持久化到消费的顺序接入现有服务与视图模型。

## 实施步骤

1. 适配采样中断、当前轮输入收件箱、流修订与分段记录，核对结束、工具和取消边界。
2. 适配附件、引用、消息队列和两种输入框，保留切换聊天与异步附件的归属。
3. 审阅与 #1480/#1483 独立改动的兼容性，补充相称回归和文档。
4. 记录实际本地验证范围，提交独立 dev PR，各启动一次既有 Build 与 Android Tests。

## 范围

不引入子代理、#1485 或延迟排查；不修改数据库 schema、CI 或其他工作树。队列和附件/引用草稿不保证跨进程恢复。

## 实现结果

保留本地 `Job?` 发送接口、语音确认、A2UI 所有权检查、`MessageSendMode` 和工具计时。队列发送传递独立附件与引用快照，在异步配置和总结之后再次核对聊天代次。发送前总结成功保存后才开始发送；取消返回任务会同时取消后续实际发送。准备阶段未写入用户行就结束的任务返还队列，已写入的输入不再重复返还。

引导只中断本次模型采样，执行中的工具先完成并保存结果。助手片段、用户补充和后续助手片段按顺序保存，多条引导逐条确认持久化，部分写入失败时只返还未保存的输入。分段投影同步处理本地 sections 和工具计时，分段流支持重放、修订和结束通知，结束后释放已封存文本。

附件异步操作捕获原聊天，包括图片判重读取的附件；删除聊天后拒绝过期回调。编辑队列恢复附件和引用，当前草稿非空时提示先处理草稿。waifu、群组编排和接管回复的插件不接受本功能的当前轮引导。

#1480 与 #1483 保持独立 PR。#1483 按单条消息折叠过程，本项的中间消息仍保留独立记录，没有加入子代理协作层的跨消息折叠。

## 验证结果与边界

使用 Kotlin 2.2.21 和 JUnit 4.13.2，实际运行以下定向回归，共 63 项通过：

- 20 项收件箱、采样中断和草稿存储回归
- 8 项真实流框架、分段流生命周期和未执行工具截断回归
- 25 项分段记录、结构化消息、队列和显示模式回归
- 10 项真实协调方法在受控依赖下的流程回归，覆盖总结保存、失败、切换聊天、队列返还和取消关联

流组使用测试日志后端和资源常量，SmartString 仅省略 Compose 标记。消息组从真实 ChatMessage 提取主构造、初始化和 sections 方法，省略 Android Parcel 与归档序列化层；边界 DTO 使用真实声明，临时测试副本省略日志静态 mock。协调组逐字提取两个生产方法，历史存储、总结提供商、状态和发送任务使用受控依赖。宿主与日志保存在独立审阅目录，没有加入应用源码。

所有变更 Kotlin 使用 Kotlin 自身 PSI 检查语法。最终提交运行既有仓库整洁、本地化和文档链接校验，结果在 PR 中记录。独立 JVM 验证不覆盖完整应用类型检查、提供商网络、Room、Compose 或设备交互；本地缺少完整 Android SDK/Gradle 缓存，完整应用编译和设备验收未执行。交付时各启动一次现有 Build 和 Android Tests，受理情况与入口见 PR。

## 设备验收步骤

1. 在 Agent 与经典输入框生成回复时连续排队消息，分别带附件和引用，确认归属和顺序发送。
2. 在模型采样中和工具执行中选择“引导当前轮”，确认保留当前内容、先保存工具结果，再按顺序显示补充输入和后续回复。
3. 在引导被消费前取消或模拟失败，确认队列返还；发送前总结失败或取消后保留队列，编辑恢复后重试。
4. 切换聊天、编辑队列、异步处理图片或其他附件、删除聊天，确认草稿与过期回调不会污染另一聊天。
5. 核对重复工具调用的分段计时、代码样例工具标签、消息定位和长消息滚动。
6. 检查语音确认、A2UI 卡片、waifu、群聊及插件接管回复的既有行为。
