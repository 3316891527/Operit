# 单层滚动实现记录

主聊天由普通滚动列切换为标准 Compose LazyColumn。短回复仍作为完整条目；节点数达到 24 或节点正文总长度达到 32,000 字符时，长回复的分组标题、工具调用、结果与 Markdown 节点作为外层列表条目显示。超长纯文本按块保留全部内容，分块不切断 emoji 的代理对。

`chat/components/timeline` 按消息准备流式和静态节点，并把条目映射到完整消息索引。消息身份包含聊天、时间戳、同时间戳序号与所选回答版本。分组和卡片使用节点类型及同类型序号作为身份，减少协议元数据过滤及流式转静态时的身份变化。

`common/markdown/lazy` 提供内容块渲染接口和消息持有的卡片状态。流式收集与静态解析不随条目离屏取消，离屏只停止布局和绘制；工具、思考、details 和分组的手动展开选择由消息保存。嵌套 Markdown 渲染清除外层片段上下文，完整消息预览与导出继续使用完整渲染入口。

气泡与 Cursor 外观按消息首尾分段：标题和头像位于首块，统计与版本栏位于末块，内部块维持一致宽度和缩进，外侧圆角与留白只出现在首尾。图片背景共用 12 MiB 位图缓存，顶底装饰按首尾绘制；分块玻璃气泡内部取消重复边框和阴影。

历史定位以消息的首个内容块跳转，导航器从可见条目恢复消息索引，流式输出跟随使用 LazyListState。长按、多选、复制、收藏和编辑继续作用于完整消息。

回归代码覆盖单个大工具组、多个同时展开的分组、手动收起覆盖自动展开、流式追加保持条目键、拆分阈值、协议元数据过滤后的身份以及 emoji 文本分块。回归代码未在本地执行。
