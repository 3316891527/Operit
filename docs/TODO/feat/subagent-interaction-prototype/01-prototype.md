# 01：研究与可交互页面

此前只有 UI 自动化专用子代理能力，用户还没有使用过通用子代理系统。直接决定工具、后台调度和原生界面会缺少可体验的交互依据。

本轮先读取七份参考项目，整理执行身份、上下文、消息与结果回传的区别，再以 OperitRy 的事件卡、详情、子会话与管理入口为基准制作独立 HTML。

## 完成内容

- 页面自包含，内嵌样式、SVG 图标与脚本，可以离线打开
- 三项初始任务展示两个运行名额与排队关系
- 支持主聊天补充、单项补充、过程与子会话查看、兄弟任务切换
- 支持停止、失败与中断演示，恢复保留已有记录和未消费消息
- 报告送回和主代理汇总分别呈现，后续执行不会改写历史报告快照
- 支持新任务、角色模型、筛选、搜索、归档、深浅主题与演示重置
- 修正用户输入的 HTML 属性转义，中文组合输入期间保留输入节点
- 提供研究、使用说明、验证记录与可复现 DOM 检查脚本

## 验证与后续

23 项 DOM 交互检查通过，脚本和 CSS 可解析。真实浏览器因容器中 Chromium 启动退出而未完成，已在[验证记录](../../../prototypes/subagents/verification.md)单独写明。

用户先体验[原型](../../../prototypes/subagents/index.html)，再讨论首版范围。正式后端、持久化、共享资源隔离和 Android 原生实现另行规划。
