# 运行时、结果交接与使用边界

[返回计划](index.md)

## 任务与执行身份

`SubagentCoordinator` 是应用级任务所有者。每个任务保存父聊天、发起工具调用、提示词快照、模型池引用、工作区、角色卡与记忆空间。任务身份、每次执行身份和父工具调用身份分别保存。

`spawn_task` 从可信工具执行上下文取得调用方，不接受模型自报的父聊天或工具调用身份。同一次父工具调用不会重复派发。补充、停止、等待与继续必须匹配当前执行身份，防止迟到请求影响新执行。

每次执行使用独立的 `EnhancedAIService` 实例与输入信箱。子代理只收到任务简报、自己的历史和补充，不自动复制主聊天完整历史。任务列表、详情和报告均由真实任务状态驱动，不使用原型演示数据。

## 队列与检查点

首版限制全局同时运行 6 项、每个父聊天同时运行 3 项。其余任务按记录顺序等待名额。全局活动队列最多 128 项，每个父聊天最多 64 项未归档任务，总记录最多 4096 项。一次执行期限为 20 分钟。这些是当前实现常量。

每任务在应用文件目录的 `subagent_tasks` 下单独原子保存。输出至多每 500 毫秒保存检查点，开始、补充和终态也会写入。检查点与最终报告应用现有流修订事件，移除被撤销的采样文字。

应用进程结束后，原先排队或运行的记录标为已中断，不自动重复外部动作。继续任务保留任务身份和历史，创建新的执行身份。中断前尚未写入检查点的少量输出不能保证保留。

## 报告交接

父聊天在实际模型执行前连接信箱，模型准备结束本轮时等待仍在运行的子任务或新输入。子代理完成后将带稳定报告标记的内容入父信箱，由主代理继续校验、汇总。用户无需点击“汇总”按钮。

报告先保存到任务文件，再投递信箱。父聊天将报告以独立 `agent` 来源保存为聊天消息，同步确认后才标记已接收。重新连接时核对父聊天已保存的报告标记，处理消息已保存但任务确认前进程中断的情形。等待同时观察任务状态与信箱版本，避免遗漏用户补充或完成事件。

父聊天已结束时不自动新建主代理轮次。空闲期间继续某个任务产生的报告保存在任务中，在下一次主聊天轮次接收。活动父轮次的报告自动进入本轮。

## 取消与资源归属

用户可停止单项执行；停止主聊天会停止其活动子任务。清空或删除父聊天先停止其子执行，再删除独立任务文件。树级操作串行化，取消期间暂停为该父聊天启动队列任务。

子执行自己持有前台服务引用和专用模型租约，退出时释放。工具执行随所属请求取消；不会用取消主聊天实例的方式释放子任务。继续执行必须等旧作业清理结束。

子代理沿用父调用的角色卡工具访问规则和常规工具权限检查。记忆查询使用本次任务捕获的记忆空间；常见文件操作的工作区改动记录计入父聊天。

递归委派、共享设备 UI、共享浏览器会话和聊天／模型配置变更在内置执行器入口被限制，CLI 代理和 JS 再次调用内置工具也会经过限制。系统提示同时说明任务和资源边界。通用 shell、脚本、外部 MCP 服务和文件系统仍按现有工具权限工作；此机制不构成操作系统沙箱，也不自动创建隔离工作树。主代理应明确划分文件与资源所有权。

## 当前数据边界

任务文件独立于 Room 聊天表，没有新增 Room 子聊天行或数据库迁移。现有聊天导出包含主聊天中的报告消息，不包含完整子任务运行文件与任务配置；导入报告仍可按保存的文字显示。

任务详情展示独立历史和过程，不能据此声称已接通所有聊天导航、备份、导入导出或跨设备恢复。工具及提供方的真实取消行为、后台保活和多模型并发还需要设备验收。
