# 包内终端命令接续聊天取消

JS 包通过原生桥接线程调用同步终端入口。聊天侧已经把当前取消任务放入调用上下文，但同步入口另建无父任务的 `runBlocking`，导致取消聊天时底层终端收集器可以继续等待。

同步执行命令时显式继承调用方任务，让现有命令流收到取消，并按原命令 ID 清理排队项或运行命令。无聊天调用上下文时继续独立执行。直接聊天工具的流式入口沿用其现有调用作用域。

回归使用真实线程模拟 JS 原生桥接，覆盖提交前取消、排队期间取消、执行期间取消，以及独立调用的正常完成。命令流、订阅建立和按命令取消均使用生产实现；不依赖真实 Android 终端或时间等待。

本地检查源码范围、UTF-8、Kotlin 语法和差异；远端启动 Debug 构建与 Android Tests。设备验证需要运行新的 APK，在包内执行一个尚未完成的终端命令后取消聊天，核对对应命令退出与后续请求可继续。

本次排查发现用户强停前的主日志未保留，系统只记录强停，没有此次 ANR 转储。上述取消缺口可由源码确认；本修补不把它直接认定为当次数分钟无响应的唯一原因。诊断原始日志仅保存在设备，未提交到仓库。
