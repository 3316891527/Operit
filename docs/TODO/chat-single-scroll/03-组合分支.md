# 单层滚动与 PR #1278 的组合版

组合分支 `test/single-scroll-chat-cards-with-1278` 以单独卡片版 `28c428b0` 为基础，合入 PR #1278 的 `ff6d83b4`。两个旧测试分支保留用于对照。

## 原状与目标

单层滚动版由消息统一准备 Markdown 节点，长回复的内容块作为外层聊天列表条目显示。PR #1278 的静态消息改用结构化 section 边界解析，协议元数据不参与可见内容。如果准备入口仍解析原始字符串，就会丢失结构化工具结果的边界；如果可见块重复处理整条消息，会增加长回复的渲染开销。

组合版将静态消息的 `displaySections()` 接入消息持有的准备入口，流式消息沿用同一份节点状态和 XML 子流。气泡和 Cursor 外观中的各块共用已准备的 sections，片段渲染直接绘制节点。完整消息预览与导出仍使用完整的结构化渲染入口。

## 作用域与行为

- `ChatTimelineEntries.kt`：静态消息的 sections 由消息统一准备，结果交给单层列表拆块；协议内容仍在原始消息中供保存与后续请求使用
- `StreamMarkdownRenderer.kt`：保留结构化节点解析及独立缓存键，为 sections 入口接入内容准备与片段绘制；各可见块不重复序列化完整消息
- `CustomXmlRenderer.kt`：同时保留消息级卡片状态和 #1278 的工具结果边界处理，卡片离屏返回后复用展开选择
- 两种消息外观：列表块使用共享 sections，完整渲染使用完整消息 sections，头像、标题与统计栏继续按消息首尾显示
