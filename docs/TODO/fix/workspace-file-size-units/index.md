# 工作区文件列表的大文件大小显示

文件列表的大小格式化原先最多输出 MB，导致超过 1024 MB 的文件仍显示为上千 MB。补充 GB、TB 两档，以 1024 进位，沿用 B、KB、MB、GB、TB 标签和现有一位小数精度。截图中的 1874.2 MB 将显示为 1.8 GB；1024 MB 显示为 1.0 GB，1024 GB 显示为 1.0 TB。
