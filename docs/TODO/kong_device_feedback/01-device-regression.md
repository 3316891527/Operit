# Kong 实机回归清单

记录 APK 提交、设备、Android 版本与主题。以下均为待填写项，不代表已通过。

不同 CI 运行使用临时调试签名，未保存固定的 Kong 证书，不能保证跨轮次覆盖安装。安装提示签名冲突时，先导出 Kong 数据备份，再卸载旧 Kong 并安装新包；正式版可继续保留。同一 APK 重复安装的签名保持相同。
