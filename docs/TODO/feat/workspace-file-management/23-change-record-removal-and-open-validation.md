# 操作记录清理与打开文件校验

沿用 PR #216，补充历史记录管理和从差异页打开当前文件时的失败反馈。默认只读差异预览保持现有行为，打开方式菜单继续作为跳转动作。

## 清理范围

历史详情提供删除当前一次文件变更、清除此文件全部操作记录。汇总状态先选择具体历史才能删除单次；全部记录按文件的路径与后端定位，对话产出限定当前对话，工作区记录保留当前目录的查询范围。确认窗口显示路径、数量和作用范围，不删除或还原实际文件。

同一次批量操作中的其他文件继续保留，记录原子改写。删除后的 revision 驱动列表、统计和产出显隐刷新。只清理删除记录涉及且已无其他引用的快照；与采集操作共用互斥锁，避免误删尚未写入操作记录的快照。

## 当前文件校验

差异页打开文件、父目录与项目树条目时，在当前页面完成文件查询及必要文本读取，成功后展示查看窗口。文件已删除、权限不足、连接改变、目录类型错误、文本超限、非文本及其他读取失败显示具体原因与路径。未知失败保留原始诊断，不伪装为不存在。查询取消不显示失败，后台页不跳出窗口。

## 验证边界

补充删除持久化、共享快照、跨文件／对话范围、revision、取消和错误分类、窗口失败不跳转的回归源码。执行 Kotlin／XML 静态解析、字符串引用、差异格式、仓库卫生、本地化和文档链接检查。默认不本地编译或执行测试，远程 Build 和 Android Tests 分别派发一次并建立 PR Check 运行记录后停止查进度。

## 实施记录

菜单位于详情操作时间旁，单次删除绑定所选历史，清除文件历史列出当前作用范围内的全部轮次。确认显示路径、具体时间或条数、对话范围和实际文件不受影响。批量操作中的其他文件原子保留，GC 仅删除已无引用的候选快照；记录采集和清理共用互斥锁。删除过程中其他操作新增 revision 不取消已确认的清理请求。

打开文件复用提取后的文件链接读取层，当前页完成检查和实际文本读取后再创建窗口，避免重复读取与错误页跳转。Android 普通权限使用系统访问诊断，明确分类权限、不存在、类型、大小和连接变化，其他失败保留诊断。取消请求不显示错误。默认只读历史差异和打开方式语义保留。

同步 9 种语言的 16 个新资源键。新增 4 项 JVM 和 8 项设备回归源码，未在本地执行。静态解析覆盖 12 个 Kotlin 文件及 9 份 XML 语言资源，语法、字符串引用和差异格式检查通过；仓库卫生、本地化和文档链接门禁在提交交付阶段记录。真实构建、测试和实机效果仍以实际执行确认。
