# 当前行只读代码溯源

本轮继续沿用 PR #216，仅增加代码溯源。入口位于文本编辑器更多菜单，查看当前光标行的提交作者、时间、说明、提交哈希和历史文件路径，并可打开该文件在对应提交中的差异。

## 查询与坐标

使用当前编辑器不可变文本快照与 HEAD 文件内容比较，将未修改的当前行映射到 HEAD 行号，再使用 Git line-porcelain 读取来源。未保存的新增或修改行、首次提交前文件、HEAD 中不存在的文件明确显示未提交。LF 与 CRLF 只在比较坐标时统一，不改写文件。

Git 查询复用当前 Android／Linux／SSH 后端，绑定实际连接标识。所有命令只读，历史文件按对象大小和文本差异限额读取。按需缓存当前文件 HEAD 内容、行映射和来源记录；HEAD、编辑器版本或后端变化时不复用旧结果。关闭弹窗或切换文件取消查询并释放执行连接。

## 界面与历史差异

不增加常驻工具栏或完整 Git 操作面板。溯源弹窗显示当前行和来源提交，未提交、无仓库、不支持的文件环境和读取失败保持明确状态。提交中的文件差异复用既有单／双栏、换行和折叠查看器，根提交以空内容作为前版本，历史路径跟随 blame 元数据。
