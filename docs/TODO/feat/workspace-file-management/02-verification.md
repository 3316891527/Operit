# 工作区统一验证清单

[返回计划](index.md)

## 已完成的静态验收

检查新增与修改 Kotlin 的语法树、字符串引用、9 种语言的 50 个资源键及格式占位符、Material 图标清单、UTF-8、文档相对链接与 `git diff --check`。仓库卫生检查随最终提交执行，结果记录在交付 PR。

本地未运行 Android 编译、构建、JVM 或设备测试。语法树检查不能代替 Kotlin 类型检查，远程构建与测试的最终结论以 Actions 为准。

## 回归源码

- 路径与偏好：相对路径、根边界、Linux 主目录、非法输入、各来源隔离、JSON 往返、显式关闭自动换行、隐藏路径前缀边界
- 搜索：递归与大小写、通配符与正则、类型、大小和时间边界、隐藏、符号链接、内容读取前筛选、跳过计数、结果上限、根读取失败与取消
- 文本读取：UTF-8、UTF-16 BOM、一基行号、二进制、片段上限、未知大小超长单行的实际字节限制
- 软换行：显示行区间、逻辑行号、制表符、中日韩宽字符、组合字符与 emoji 的坐标往返、空文档和重新排版
- 文件操作：复制总量未知时的进度、本机删除链接隔离、递归取消、非递归删除失败；保留既有二进制复制、冲突、来源变化及取消回归

新增 Android 设备源码覆盖换行后的光标位置、输入法插入与撤销，以及长行之后的逻辑行号定位和输入法组合。普通 Android JVM 工作流不执行这些设备用例。

## 远程验证入口

[PR #216](https://github.com/3316891527/Operit/pull/216) 以同一功能分支面向 `dev` 交付。启动 Build 的 `assembleDebug` 和 Android Tests，并核对对应提交的运行记录已经建立。PR Check 随 PR 触发；确认启动后不轮询进度。

## 集中设备验收

1. 在小屏深浅主题中打开未绑定工作区，检查重复设置区已移除，路径与快捷位置可用，菜单可滚动；新建文件夹在当前目录生效，模板创建仍从主页进入
2. 在 Android、Linux 与系统授权目录中编辑绝对、相对、错误路径，使用边缘返回手势；多选与过滤先退出，随后逐级返回，切到终端或聊天后不拦截返回
3. 添加、删除收藏，设置与重置浏览首页，重启检查来源和路径；隐藏目录、点文件及其子项，验证显示开关和规则编辑不改文件
4. 搜索不同大小写、扩展名、正则、文件与文件夹、大小及日期边界；包含与排除隐藏项；停止和重新搜索，检查已找到结果、计数与内容行号定位
5. 打开含中文、emoji、制表符与超长行的文件；检查点击、拖动选区、复制、方向键、缩放、搜索高亮和输入法组合；关闭再启用自动换行，保存前后确认没有新增换行
6. 以大文件和大量小文件目录验证复制、同来源与跨来源剪切、删除及长按属性；记录相同数据集的耗时，验证取消、目标重名、权限错误及部分完成后的状态

设备视觉验收与性能测量尚待执行，不将静态检查或新增源码写成已通过的设备测试。

## 界面与滑选打磨验收补充

[打磨实现记录](04-browser-polish.md) 已更新。搜索框不再接近全屏，长路径、展开高级条件、输入法显示及多条结果下确认底部操作可达；圆角菜单适中且各操作有图标，检查长翻译与深浅主题。

横滑与菜单分别进入多选后都不显示顶部选择栏。滑第 1 项再滑第 4 项补选 1～4，点击切换单项；长按已选项打开批量面板，关闭后保留选择，全选后继续没有常驻栏。包含目录时分享禁用，文件、混合文件夹的复制、剪切、删除和汇总属性仍需跨来源验证。

慢速左右拖动观察条目直接跟手；有效滑选一次轻震，普通点击、短滑、取消和第二指不震动。松手与取消均归位；横滑期间尝试应用返回、进入边缘区域，释放或离页后确认系统返回恢复。Android 系统先于应用接管的边缘起手必须使用真实系统手势验收，触摸注入不能代替。

临时打开文件后没有重复返回箭头和“文件”标签，撤销、重做与搜索按钮行移除；关闭、保存及未保存确认仍可用。回归源码累计 35 项 JVM、15 项 Android 设备用例，设备用例尚未执行。
