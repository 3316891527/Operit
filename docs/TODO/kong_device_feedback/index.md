# Kong 共存版实机反馈修复

本分支基于聊天界面与 Waifu 集成提交 `257d6934`，处理首轮多人实机反馈，保留 `.kong` 共存身份、非调试 Release 配置以及关闭 R8 的构建策略。

## 运行问题

- Waifu 分句正则补齐右花括号转义；增加设备端正则回归用例，覆盖普通文本、列表小数与占位符字面量
- 聊天页离页不参与跨页淡入淡出；留存页面在隐藏时不放置，退场内容禁用触摸、焦点与无障碍语义，并限制页面绘制边界
- 手机侧栏使用当前窗口宽度的 66%；设置等侧栏导航与抽屉关闭并行，动画进度在图层阶段读取，关闭导航动画时不再保留淡入淡出延迟
- 悬浮窗发送与主界面一致，优先使用当前角色选择，不再沿用会话原先绑定的默认角色；不改变历史消息归属

## 外观与配置

在“主题和外观 → 界面”中提供玻璃预览及模糊、边缘宽度、高光、阴影、表面不透明度设置。参数默认值分别为 12dp、0.4dp、18%、4dp、24%，可以恢复默认。各玻璃组件使用同一组主题参数，数值范围限制渲染开销。

对话列表、设置分组与卡片、包管理的插件/沙盒包/Skill/MCP 列表及获取按钮可分别启用磨砂，默认关闭这些新增区域。已有侧栏、输入框和气泡玻璃开关继续生效，不增加强制覆盖所有控件的开关。设备需支持现有 Android 13 玻璃实现。

玻璃不再额外降低背景饱和度或提高对比度。透明底色仍会与背景混色，不透明度为 100% 时保留所选表面色。侧栏重新采用用户保存的自定义背景与选中颜色；包管理两个获取按钮默认使用一致的主题样式，并提供独立背景选色与恢复默认。

权限与工作流入口采用统一的双行卡片、至少 56dp 高度、12dp 间距和较轻的高光阴影。记忆库的操作按钮与菜单改用主题表面、圆角及操作图标，删除使用危险色；保留默认库不可删除及删除确认行为。

新增玻璃参数、区域开关和包管理按钮色加入现有主题读写、角色主题复制与重置路径。主题编辑先修改草稿，保存和放弃沿用现有编辑会话。

## 验证与限制

已核对 37 个改动 Kotlin 文件、37 处玻璃调用、9 份字符串 XML、23 个新增资源及主题键注册；未发现新增语法解析错误、参数残留、重复导入或差异格式问题。语法工具对既有 Composable 函数类型的解析限制已对照基线确认一致。本地未运行 Android 编译或测试；代码检查不能证明实际帧耗时或截图残留在所有设备上消失，构建与实机效果需分别验证。
