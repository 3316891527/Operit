# A2UI 常用控件显示优化

现有原生 A2UI 已支持数据绑定、表单、折叠区和主题局部色板，但输入框、选项行、按钮与折叠标题的视觉密度和形状尚未统一。待办列表是本次显示讨论的参考场景。

第一轮在现有 Compose 渲染层统一常用控件：轻底色与选中行、12dp 控件圆角、16dp 显式 Card 圆角、至少 48dp 的按钮触摸区域，以及带旋转箭头和展开读屏状态的整行折叠标题。输入和选择器的功能边界按实际轻底色校正到 3:1，避免单纯淡化描边造成难以辨识。

仅调整显示层，不修改 Express、JSON Schema、数据路径、事件或持久化合同，不添加依赖。显式 Panel 的作者样式继续生效。本轮不新增待办工具，也不将聊天卡片固定到输入框上方。
