## 行为约定

首次横滑选中当前项目。点击切换单个项目，不移动横滑锚点；再次横滑按最新可见顺序补选闭区间，再将当前项目设为锚点。排序或过滤后重新按名称查找位置，已不可见的锚点不能沿用旧下标。`..` 不参与多选。

横滑在手势结束且距离达到阈值后提交一次，不追加点击。纵向与斜向移动留给列表，已送达应用的边缘触摸同样允许滑选；横滑期间为当前条目设置系统手势排除并拦截应用返回，释放与取消后解除。长按单项打开单选菜单，多选时长按条目补入选择并打开批量面板。

不显示常驻多选栏。长按已选条目打开与单选共用外壳的面板，提供复制、剪切、属性、分享、搜索、压缩或解压、删除；页签菜单保留全选入口，返回退出多选。单项属性沿用原面板，多项属性汇总文件、文件夹与字节数，计入所选文件夹自身及子项。无法读取或未知大小不当作零，关闭面板取消统计。

多文件分享准备独立缓存并通过一次系统分享 Intent 携带所有 URI。Android、本机 Linux 与授权目录按流准备，远程沿用现有二进制读取协议；任一项失败不打开不完整的分享面板，也不清除选择。所选项包含文件夹时禁用分享，不再附加解释。压缩能力与范围搜索按[归档与路由记录](05-archives-and-file-routing.md)实现；编辑器本体的进一步改动留待后续。

## 验收重点

先横滑第 1 项，再横滑第 4 项应选中 1～4。反向区间、点击取消后再补选、排序过滤、退出重入和目录切换均应保持锚点正确。验证纵向滚动、短距离移动、长按、多指、取消与边缘手势不误选。

验证混合文件和文件夹的复制、剪切、删除与汇总属性。多个文件分享到一个系统选择器，检查每个 URI 都有临时读取授权；包含文件夹时明确禁用分享。设备交互与跨应用接收仍需实机验收。
