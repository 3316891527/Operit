## 验收边界

## 最终交互

搜索窗口宽度为当前屏宽的 88%，上限 420dp；高度上限为当前屏高的 72%，且不超过 560dp。条件与结果继续共用滚动容器，底部搜索、停止和关闭操作独立可见。长路径最多显示两行。删除读取限制提示展示与对应孤立资源，8MiB 内容读取限制和 500 项结果上限继续由搜索引擎执行。

工作区菜单保留 20dp 圆角，按内容计算宽度并限制为 184～256dp；使用 18dp 图标、较小文字和紧凑内边距，勾选状态单独显示。公共菜单容器增加尺寸和内边距参数，其他调用保留原有默认值。

菜单进入多选与直接横滑进入多选都保留；点击切换单项，横滑按可见顺序补选锚点之间的闭区间。多选时长按已选条目直接打开批量面板；长按未选条目先补入选择再打开。面板共用单选的圆角、标题、两列图标布局，当前提供复制、剪切、属性、分享、搜索、压缩或解压、删除，最新调整见[归档与路由记录](05-archives-and-file-routing.md)。关闭面板保留选择，包含文件夹时禁用分享并移除解释小字。全选后仍不显示顶部选择栏。

横滑期间内容直接读取指针位移，限制最大偏移为行宽的 40%；释放和取消使用弹簧动画归位。只有成功提交滑选才触发一次轻量 SegmentTick，点击、短滑、取消与多指不触发滑选震动。系统手势排除仅覆盖正在拖动的条目，应用返回在横滑期间消费；手势结束、取消、条目禁用或离页后解除。系统先于应用接管的边缘返回仍需设备验证，不把应用收到的边缘触摸回归视为系统手势兼容结论。

临时文件页面移除返回箭头与重复的“文件”标签，只保留实际文件标签；没有打开文件时不绘制空标签栏。系统返回和关闭文件仍处理未保存确认并回到浏览目录。撤销、重做与搜索按钮所在的独立工具行移除，格式化动作并入已有文件标签操作区；键盘快捷键继续有效。已有软换行保留，本轮编辑器目录没有新增改动。
