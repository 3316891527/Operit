# 数据与备份验收

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 从设置打开数据与备份 | 只显示合并后的入口和三个页签 |
| 2 | 检查概览并切换记忆配置 | 聊天、角色、记忆及关联数对应实际数据 |
| 3 | 切换三个页签并来回滚动 | 保留各页滚动、选择与任务状态 |
| 4 | 打开 Token 统计后返回 | 进入原统计页，返回原页签 |
| 5 | 导出快照并切换包含日志 | 使用所选日志选项，显示真实进度与输出路径 |
| 6 | 打开恢复后取消文件选择 | 不执行恢复，未选文件时确认按钮不可用 |
| 7 | 选择并确认恢复快照 | 提示覆盖数据，恢复成功后重启 |
| 8 | 调整每日备份开关和保留份数 | 设置持久保存，范围 1—100 |
| 9 | 立即备份并打开最近备份 | 显示最新记录和真实备份文件 |
| 10 | 从文件或最近记录恢复数据库 | 先确认覆盖，成功后提供重启 |
| 11 | 展开单项备份并导出所选聊天 | 原 JSON、Markdown、HTML、TXT、CSV 格式可用 |
| 12 | 导入聊天、角色卡和模型配置 | 原格式继续可读，模型密钥提示保留 |
| 13 | 导入导出记忆库 | 可选择配置及跳过、更新、创建新条目策略 |
| 14 | 打开备份文件与备份须知 | 统计、刷新和说明可用 |
| 15 | 展开角色卡与群聊统计 | 展示真实数量，失效关联可处理 |
| 16 | 搜索、全选、清除聊天选择 | 按标题、分组、角色筛选，选择数量准确 |
| 17 | 批量修改角色、角色群及分组关联 | 只更新明确选择的关联 |
| 18 | 构建记忆并限定时间范围 | 使用所选窗口与时间范围，运行时可取消 |
| 19 | 删除所选聊天或清空记录 | 二次确认，锁定聊天保留 |
| 20 | 选择并删除无绑定工作区 | 只删除选中文件夹，有绑定的工作区不显示 |
| 21 | 关闭日志写入后查看说明 | 只影响写入，原每日自动恢复策略保留 |
| 22 | 调整五项日志过滤后导出 | 保存原过滤设置，导出文件使用相应规则 |
| 23 | 清空日志并检查其他数据 | 二次确认，聊天及 Token 统计保留 |
| 24 | 切换深色、大字体及窄屏 | 卡片、抽屉和操作按钮可读可操作 |
| 25 | 经旧路由打开备份、聊天管理或日志 | 定位合并页对应页签 |

| --- | --- | --- |

| Android Debug 工作流 | 见 PR 派发记录 | assembleDebug |
| Android JVM 工作流 | 见 PR 派发记录 | Android Tests |
