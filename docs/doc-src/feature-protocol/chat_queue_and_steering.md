# 生成期间的队列与引导

Agent 和经典输入样式在生成期间点击发送，会把文字、附件和引用快照加入当前聊天的队列。
普通队列消息在当前轮结束后按入队顺序自动发送。队列暂存在 ViewModel 中，
自动发送由当前聊天界面驱动；它不是持久化的后台任务队列。

用户点击队列项的“引导当前轮”，才会把该消息提交给当前轮。按钮随后显示
“等待当前轮读取”，消息被消费后从队列移除。用户引导可以中断正在采样的模型请求，
保留已显示的思考和文字，丢弃尚未执行的工具参数，然后开始新的模型请求。
正在执行的工具不会被引导取消；完整工具结果先写入上下文，再消费引导消息。
模型准备结束时若还有引导消息，也会继续处理。

引导失败会保留队列项；取消或异常结束时尚未消费的引导恢复为普通队列项，
不因恢复而自动启动新一轮。引导前的助手输出、用户补充、引导后的助手输出
分别持久化，下一次发送和总结会读到正确的消息顺序。引导后助手消息使用现有
周期快照刷新，并在结束时保存完整内容。

编辑队列项时恢复其附件和引用；当前草稿非空时提示先处理草稿。真正发送或引导时，按目标回合的模型能力处理附件。
发送前总结必须保存成功再发送。总结失败、取消或准备阶段未保存用户消息就结束时，完整队列项会归还并暂停自动出队，可以编辑恢复后重试。
当前轮仅为压缩上下文而结束时，未消费的引导保留到总结完成后发送。waifu、群组编排和接管回复的插件不接受当前轮引导，原队列项保留。

附件和引用草稿随聊天切换保留，异步完成的附件仍属于原聊天；这些草稿不保证跨进程恢复。
部分引导已经写入用户记录时，只返还尚未保存的输入。本项不修改数据库版本，不包含子代理和历史消息编辑器折叠。

队列中没有“停止后发送”操作。独立停止按钮只停止当前轮。
