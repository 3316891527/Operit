# Markdown 扩展与编辑器体验

## 现状与目标

用户已在设备上确认八类原生 Mermaid 均可用。此轮保留图表类型和原生绘制实现，补齐功能测试文档第 14 节涉及的 Markdown 语法，并修正编辑器与 CI 问题。

## 实施范围

1. 文档加载时光标置于开头，已有会话切换保留位置，显式行号跳转继续生效。
2. 剪切、复制在剪贴板操作成功后各显示一次 OKToast，复用已有本地化资源。
3. Mermaid 核心检查改用 Bash 自带路径展开定位 Gradle 编译器，消除运行环境对 rg 的隐式依赖。
4. 在现有 Markdown 模型中补齐任务列表、嵌套列表、富文本引用、转义；保留现有流式输入和 Operit 专用 XML 内容。
5. 补齐表格对齐与竖线处理、标准链接目标和标题、相对图片位置、引用式链接、Setext 标题、脚注、定义列表、目录标记、高亮、上下标和常见 HTML 正文。
6. 更新可打开的人工验收文档与支持范围；针对解析和初始文档行为添加必要回归，修复 CI 后重新发起 Build 和 Tests，只确认启动，不轮询执行进度。

## 验证边界

用户报告的 Mermaid 真机通过与现有核心测试是不同证据。此次 Markdown 新语法、剪贴板提示与默认定位仍需在更新后的正常应用中验收，不创建或安装额外测试 App。
