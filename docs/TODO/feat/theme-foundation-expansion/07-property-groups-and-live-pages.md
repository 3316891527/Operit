# 属性分组与真实页面预览

本轮整理工作室的信息层级，并复用现有主路由组件替代分类样例。

## 实现

1. 外观页按部件外观、布局与位置、文字排版、图标和高级效果分组。消息使用消息外观、消息布局和消息文字标题，正文颜色归入文字组。分组可折叠，收起前清除焦点以提交数值输入
2. 高级效果默认折叠，部件原生渐变位于面板最后。绘图层渐变和图像模糊位于对应图层属性最后，部件级渐变位于整个图层面板末尾
3. 保留全部 66 个页面背景及各自的浅深模式、独立渐变、图片、图层和聊天背景跟随。真实预览与应用共用 AppContent、Screen.Content、页面顶栏和背景绘制
4. 52 个页面直接打开真实路由。13 个参数页面在现有页面中选择实际对象；插件配置沿包管理和包详情选择正确的配置模块。普通插件页面从当前安装插件的真实导航路由中选择。需要已有内容、账号或管理权限的页面保留原条件，未选对象时明确提供选择入口
5. 对象仅保存在当前工作室会话，不写入主题工程、脚本上下文或导出。详情页保留包名、工作流 ID、市场条目和插件模块等实际路由参数，取消选择保留原对象
6. 预览有独立导航、保存状态注册表和 ViewModelStore，生命周期跟随父窗口，退出后销毁。插件执行标识增加会话命名空间，避免与主页面的保活执行器共用；预览不更改宿主 Activity 的输入模式
7. 普通预览拦截触摸和交互语义；对象选择窗口允许使用实际页面导航，并尊重页面离开检查。进入全屏或对象选择时卸载被覆盖的预览，避免同时挂载两份真实页面
8. 聊天预览读取当前真实会话，不额外创建聊天 ViewModel。预览禁止消费共享附件和草稿、会话视图钩子、主窗口手势、附件选择请求、新聊天动画信号及待发队列；主聊天和侧栏导航入口不会转交给实际主窗口

## 运行边界与设备验收

真实页面保留业务加载逻辑，部分页面会读取数据库或请求网络，插件页面也会执行自己的初始化。独立路由和触摸拦截不隔离全局存储、业务服务或插件脚本。对象选择窗口使用真实页面，页面中已有操作仍遵循原有规则。

设备验收仍需检查浅深模式下的实际背景效果、详情对象选择、插件加载、全屏切换及关闭预览后的主聊天行为。52 个直接路由已接入，不代表全部页面已在设备逐一打开。
