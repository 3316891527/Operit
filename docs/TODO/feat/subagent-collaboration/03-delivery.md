# 交付与尚待验收的项目

[返回计划](index.md)

本次交付是 `feat/subagent-collaboration` 的原生代码与说明文档。它独立于 HTML 原型分支，采用已确认的信息层级，并调整为主代理自动派发。

## 已进行的源码核对

- 核对模型配置页签、功能模型入口及保存协调器的调用关系
- 核对具体模型名称解析、专用服务租约、配置与请求参数的快照来源
- 核对主聊天信箱接入、报告持久化确认、重连时的来源与标记去重
- 核对当前执行身份校验、排队任务开始前取消、整棵任务树停止及独立服务释放
- 核对流修订事件、角色卡权限、记忆空间和工作区改动记录的归属
- 核对主聊天两种消息样式中的报告入口、任务列表与详情的调用关系

差异空白检查使用 `git diff --check`。上述核对属于源码阅读和差异检查，不能证明 Kotlin 编译、Android 资源链接、实际模型请求或设备交互已经通过。

## 尚未执行的验收

没有运行 Android 编译、构建、单元测试或设备测试，没有手动派发 GitHub 构建和测试工作流。没有安装包含本功能的 APK，也没有本功能的原生运行截图。

后续需要在可安装版本上确认这些实际行为：

- 手机和宽屏下的模型池、提示词编辑、键盘、返回与保存错误提示
- 多个真实模型并行时主聊天保持响应，模型型号排序或配置变化不会误选其它模型
- 用户补充、任务完成、停止与继续相邻发生时，输入读取状态与执行身份一致
- 报告保存前后杀进程、切换聊天与上下文总结后，报告交接不丢失也不重复
- 每项停止、父聊天停止、清空、删除以及应用重启后的任务状态与资源释放
- XML、原生工具调用、CLI 代理和 JS 嵌套调用中的权限与共享资源限制

## 版本范围

任务与配置保存在本机，完整子任务文件没有接入现有聊天备份或导出流程。默认并发数与执行期限是首版常量，没有新增用户手动派发页面或代理身份切换。

空闲父聊天不自动启动新轮次，报告在下一轮接收。任务目录无法读取时明确报错，模型配置失效时明确拒绝执行，不静默改用其他模型。

草稿 PR 仅用于代码评审，不表示功能已经通过运行验收。
