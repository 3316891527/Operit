# 连续过程的实现与回归

## 分段与更新

`WaifuMessageProcessor` 继续借助原生 Markdown 解析器保护代码、公式、图片和插件卡片。连续的思考、工具调用与工具结果在正文分句之后合并为一个过程段，隐藏协议 XML 和空白不产生正文边界。过程内容保持原始 XML，工具名称和调用次数不参与分组规则。

服务使用的可修订流式队列从任意位置展示尚未闭合的过程。增长或重试截短的过程通过 `Revise` 更新同一个消息，保留时间戳；真正失效的重试后缀仍使用 `Retain` 撤回。过程到达时立即送出它前面仍在等待的正文，避免打字延迟遮住工具活动。失败或取消发生在同一调度轮时，也会保存已生成的过程。

消息存储将过程修订与正文追加分开，过程不进入朗读队列；正文保留逐句朗读和重试中断。过程增量最多每 100ms 写入一次消息列表，内存始终持有最新快照，完成、失败和取消沿用已有终态持久化路径保存最终内容。

仅追加的内部调用方仍等正文边界或流结束才提交过程，避免已经发送的过程前缀在后续增长中改变。应用内实时展示使用可修订入口，不受此限制。

## 无外壳展示

ChatArea 保留现有菜单、选区、复制与懒加载上下文，对 Waifu 过程调用专用渲染组件，绕过气泡、命令框、头像与 Response 标题。过程内部继续按节点懒加载，不叠加普通消息的整体过程折叠和工具组标题。

正文沿用各自聊天样式，Cursor 在每条正文消息首片段增加头像，Bubble 在 Waifu 正文显示每条消息头像。普通聊天的头像偏好和渲染入口保持原有行为。

思考标题使用“思考过程”和原文短前缀，不生成摘要；收起时由既有单行 Ellipsis 组件处理宽度，展开沿用完整 Markdown 正文。工具共用一个图标与通用行组件，展示真实名称、状态、原始参数与结果。

## 代码位置

分段器、修订流、过程边界辅助类、过程组件、正文头像及思考预览集中到 `ui/features/conversation/chat/waifu/`，对应测试同步迁移。Kotlin、JS 桥接入口和 Android instrumentation 测试引用一并调整。旧 `util.WaifuMessageProcessor` 仅保留已发布 Java 桥接 API 的转发入口，既有 QQBot 安装仍可调用；仓库内 QQBot 源码及分发脚本改用新路径。现有消息持久化格式与用户设置保持兼容。

## CI 异常传播断言修正

Android Tests 在原提交中有两项失败，均发生在失败场景的异常对象引用比较。本地聚焦运行器原先未启用 JVM 断言；加入与 Gradle 测试一致的 `-ea` 后，可以复现相同的两项失败。

协程堆栈恢复允许复制异常，并将原异常保留在因果链中。两项用例改用仓库已有的 `assertPropagatedException`，同时核对类型、消息和因果链中的原始异常；继续检查已经生成的过程完整保留。此次不修改生产流式逻辑，不关闭 CI 断言或堆栈恢复。

本地聚焦运行器补充 `-ea`，分别验证启用与未启用堆栈恢复的异常传播行为，完整 Android Tests 由修正后的分支再次派发。
