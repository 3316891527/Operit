## 验收边界

用户截图作为视觉输入使用。归档隐藏过滤影响列表展示；全部解压仍包含隐藏条目。只在真实需要解密时请求密码，密码不写入持久偏好，也不会把已有普通包改为加密包。

本地默认不执行编译、构建或测试。静态结果、远程工作流建立和设备回归执行分别记录。

## 最终交互

隐藏管理位于工作区菜单顶部，展示所有环境的手动隐藏记录，可逐项取消隐藏。系统隐藏与手动隐藏开关在管理面板中直接修改，保留原有偏好数据；删除旧的多行路径编辑框和解释资源。这里只恢复显示，不修改文件名或文件权限。

单选长按面板的搜索与压缩或解压同排，移除移动后恢复六行两列。多选移除重复移动，保留六个常规动作和底部删除；移动继续通过剪切与粘贴完成。归档类型由统一注册规则识别，外部解压直接打开目标选择流程；普通文件或混合选择保留压缩，全部选中项均为归档时提供批量解压。

归档页顶部保留返回、目录标题和添加文件，移除属性、打开方式、密码和手动刷新菜单；归档文件本身的属性在外部查看，包内文件和文件夹保留各自的属性入口。归档内使用现有 Material 3 下拉刷新组件，底部固定全部解压，进入多选后改为解压选中项。底部显示归档名称，短列表和长列表保持相同主操作位置。隐藏过滤只改变列表，不删减全部解压的内容。

解密密码不修改归档，不持久化，也不使普通包变成加密包。遇到加密内容或加密文件名需要口令时才请求，输入后重试原读取操作；损坏归档、无权限路径和路径中含有 password 字样的普通错误不进入口令流程。新建 ZIP 的字段明确标为加密密码，仍用于实际 AES 加密。

文件选择器共用工作区 Linux 安装完成标记，并在恢复前台后重新检查。未安装时隐藏 Linux 入口，不启动终端检查。源文件和目标目录列表均复用浏览隐藏规则。父目录、子目录、快捷入口和手动路径读取成功后才更新当前位置；失败、取消或过期请求保留上一次成功目录和条目。确认目标前重新校验目录可读性。目录切换重置列表滚动位置，跨目录勾选继续保留。

包内单项和多项长按复用外部圆角面板与带图标的两列操作行。第一行提供解压和属性，ZIP 第二行提供改名和删除，多选时禁用单项改名；只读归档不显示修改操作。关闭面板或属性不退出选择。

包内条目属性复用外部字段、数字与时间格式和点击复制。单项显示名称、包内目录、归档来源、类型、大小、压缩大小与修改时间，文件另显示加密状态；名称、目录和来源可点击复制。目录与多选显示文件和目录数量，后台汇总完整索引，补齐隐式目录，重叠路径只计一次，单目录不计自身，多选计入所选目录，链接只计条目而不展开。大小和压缩大小分别汇总文件条目数据量，不代表整个容器的占用；格式未提供值、负值和总量溢出均显示未知，空目录内容大小为零。
