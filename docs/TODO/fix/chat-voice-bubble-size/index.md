# 语音消息与正文气泡使用相同尺寸规则

反馈：聊天中的语音条比普通文字气泡更高、更宽。嵌入消息的语音控件原本固定至少 44dp 高，外层再添加语音专用的上下留白；折叠内容宽度为 168～228dp。普通用户文字气泡使用正文行高和上下各 12dp 的内边距，最小高度为 44dp。

将嵌入消息的播放、波形和文字切换控件按 `bodyMedium` 正文行高布局，统一外层文字与语音的内边距。普通气泡、图片背景气泡、宽布局和 Cursor 用户消息一并对齐。默认字号下，嵌入语音的折叠内容宽度收窄为 132～192dp，并随正文行高缩放，保留随时长增长的规则和转写展开行为；助手语音插件使用嵌入布局。录音面板预览使用既有独立播放器尺寸。

已核对工具命令行：外层使用消息的宽度限制，内部 Canvas 按文本和图标计算高度，没有语音条额外的 44dp 高度约束。本次调整已确认偏大的语音布局。
