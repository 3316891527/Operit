# Operit Kong 2.0.0

Operit Kong 2.0.0 汇集了 1.12.2 系列以来的主要更新。多代理协作、统一工作台和原生主题工作室，让聊天、任务执行、文件处理与个性化设置更紧密地连接在一起。

本次更新同时完善模型与语音配置、用量统计、记忆和扩展管理。已有 Kong 用户可覆盖升级；从社区版迁入的用户，请阅读末尾的安装与升级说明。

## 聊天与多代理协作

- 新增子代理协作。为帮手设置提示词，在子代理模型池中加入可用模型并填写能力后，主代理可以按任务选择帮手、模型和思考选项，分派工作并收集报告。配置入口在模型工作区的“子代理”和“功能”页。
- 聊天输入栏上方可以查看子代理任务，按状态筛选、搜索，打开目标、模型、执行过程、工具记录、报告和独立子会话；也可补充要求、停止任务及其下级、继续已有工作、归档或恢复记录。
- 支持多级任务树、代理间消息和协作等待。派发时可选择不继承主对话、继承当时可用的全部背景，或最近若干用户轮次；可配置并发、执行时限和最大深度。可选择继承范围，让不同帮手获得任务所需的背景。
- 子代理的完整会话与报告可以保存和回看，并随原生聊天备份迁移。被中断的任务保留执行记录，可查看过程并继续已有工作。
- 新增按会话管理的待发送队列。AI 回复或总结期间，可把消息与附件先加入队列，空闲后按顺序发送；可移除排队项，或放回输入框编辑。排队内容在本次运行期间保留。
- 队列中的“引导当前轮”可以把补充要求交给正在工作的 AI，在它下一次可接收输入时纳入该轮。补充前后的回复按顺序保留；当前轮不能接收时，消息继续留在队列。
- 附件菜单新增“继续生成”。已有对话且当前空闲时，可直接让 AI 根据现有历史续写，不必发送空白消息或再次输入“继续”，也不会清空输入框草稿。

## 消息、图片与原生交互

- 支持聊天内原生 A2UI 卡片，包括表单、选择、表格和图表等，并可更新卡片数据。等待型表单可把填写结果直接交回当前任务，减少来回复制和确认。
- 工具从开始执行起实时显示耗时，普通聊天、插话分段和 Waifu 模式保持一致；展开工具组可查看单项耗时，完成或取消后保留实际计时。
- 回复完成后可折叠整轮思考和工具过程；运行中的工具组保持展开，并显示尚未完成的调用。生成详情集中展示已有的 Token、缓存与耗时信息，长耗时可用分钟、小时或天显示。上下文面板分别展示本地估算与服务端确认的上一请求输入 Token，方便辨别统计口径。
- Waifu 模式连续展示思考、工具调用及结果，再衔接分段回复。折叠思考只预览开头八字，展开与复制仍保留全文；调整角色名、头像、图片和独立卡片后的衔接，并修正分段回复中的自定义表情。
- 扩充 Markdown 显示，支持高亮、上下标、定义列表、脚注等写法，宽表格可横向滚动。Mermaid 预览改为原生离线实现，支持流程、状态、类、实体关系、思维导图、时序、饼图和甘特图的语法子集；不支持的语法会明确提示。
- 图片发送前可裁剪、旋转，使用画笔、形状、箭头、马赛克和文字标注，并支持撤销、重做。编辑入口在待发图片预览中，完成后应用到附件。
- 完善应用内相册、按选择顺序添加附件、滑动多选与回滑取消；聊天图片可全屏查看。附加屏幕内容按图片发送，图片失效或加载失败时提供更明确的信息。
- 消息复制区分可读正文与 Markdown 源文，复制正文时不混入工具协议；消息菜单可直接翻译，保留原内容。文件链接可衔接工作台查看与编辑。

## 工作台与文件处理

- 工作台统一工作区、文件浏览、终端和浏览器会话。可创建或选择工作区，也可独立打开终端与浏览器；原工具箱的独立文件管理器入口归入工作台。
- 文件浏览支持路径编辑、收藏、自定义首页、过滤、递归搜索、横滑多选及按范围复制、剪切、删除和分享。复制与删除显示进度；打开文件后返回可保留原浏览位置。
- 支持 ZIP、7z、RAR、TAR 及常见压缩变体的查看和解压，可创建 ZIP、7z、TAR、TAR.GZ，ZIP 可设置 AES 密码。可编辑 ZIP 支持新增、删除和改名；需要修改归档内容时，请使用归档编辑功能。
- 编辑器完善查找替换、跳行、撤销重做、软换行、另存为、只读与外部变化检测，扩充离线语法高亮和自定义规则。软换行只改变显示，不改写文件。
- 适用的 Git 文件可查看当前行作者、来源提交及文件差异。工作区变更审阅支持路径筛选、单栏或双栏差异、逐段展开与文件定位，比较操作不会自行提交或推送。
- 对话产出可在绑定的工作区内记录，方便回看上一轮和历史文件变化；清理记录不删除当前文件。
- 静态 HTML 项目打包改由自带 Ubuntu 终端管理。准备相应模板后，可通过 `build html --help` 查看生成 Android APK 或 Windows 应用的用法；聊天记录的 HTML 导出仍保留。

## 终端与长任务

- 新增带任务 ID 的终端启动、查询和精确取消。长命令可以先启动，再查看输出尾部与当前画面，不必把一次工具调用一直挂在前台；原直接执行入口继续保留。
- 查询的等待时间与任务的总执行期限分开。一次查询等待结束不会终止任务，总期限包含排队；输出与画面代表当前快照，任务失败时仍保留可用输出。
- Ubuntu 内置 Codex 风格的 `apply_patch`，支持参数、补丁文件与标准输入，以及检查、差异预览、防覆盖选项和 JSON 输出。已有本地 Ubuntu 无需重装，打开新的本地终端会话即可准备命令。
- 改善终端键盘视口、光标和终端状态报告，适配依赖光标位置回复的交互程序。Root 单次命令按进程隔离并限制时限，修正部分 Shizuku 输出管道堵塞及取消清理问题；取消不会撤销命令已造成的修改。
- 外部 HTTP 聊天服务改由终端管理。可用 `web-chat start-server --login` 启动并打开浏览器，使用 `web-chat status`、`web-chat stop-server` 查询和停止；原保存的端口、Token 与启用状态继续沿用。

## 主题工作室与角色外观

- 主题设置整理为“主题、背景、消息、界面”四页，角色编辑集中到基础、内容、发言和绑定；常用外观、角色发言及关联资料入口更加集中。
- 新增原生主题工作室。在设计、源码和资源之间切换，选取组件并查看真实页面或全屏预览；支持撤销重做、工程草稿、素材导入及 `.oktheme` 工程交换。
- 扩充渐变、页面背景、背景模糊、玻璃效果、菜单形状与位置、系统状态栏、输入框占位文字和文字描边。动作按钮可独立设置图标与交互外观，不同组件提供各自适用的属性。
- 主题草稿按角色保存，可确认后把当前视觉主题应用到全部角色，不改动角色提示词和绑定。工作室的“保存草稿”与启用主题分开；“应用到角色”后，仍需在主题设置页保存。
- 改善主题导入导出的预览和字段保留，替换图片、字体时整理不再使用的旧资源。主题工程包、普通主题分享和完整文件快照用于不同的迁移范围。

## 模型配置与语音

- 模型配置重整为连接、参数、总结、子代理、功能五个标签。配置支持分组、排序和移组，模型选择器可按组过滤，导入保留有效分组。
- 总结设置归入模型工作区，可设置当前配置的触发与规则、复核上一份总结，并查看实际执行总结的模型；支持的功能模型可选择思考深度。总结执行模型仍由功能模型绑定决定。
- 模型列表获取提供更具体的连接、DNS 与超时反馈，切换配置会取消旧查询。改善 API Key 池在额度或限流等故障下的可用密钥选择，并保留单密钥的正常重试预算。
- 改善思考质量滑块的档位提示、粒子动画、主题颜色与最高档交互。DeepSeek 连接开启图片能力后，可通过所配置端点的 Files API 上传图片；模型连接页增加 Antigravity 登录入口，具体能力仍取决于所配置服务的支持与账户状态。
- 语音服务集中为朗读、识别、唤醒三页，管理档案、连接、语言、音色与规则，并提供试听和识别测试。已有语音档案继续沿用；后台唤醒仍使用本地唤醒资源，与在线 STT 配置分开。
- 聊天可录制、试听并发送可播放的语音条，也可使用 STT 文字输入。按模型能力处理原音频、音频识别与转写；转写保留原话及原语言，可靠的声音观察单独进入请求上下文，不混进用户可见的原话。
- 朗读按消息结构提取正文再应用清理规则，角色发言的显示清理与语音输出分开；语音通话入口移入附件菜单，与语音条和文字输入区分。

## 记忆、统计与数据

- 记忆管理重做空间总览与图谱工作台，可浏览最近记忆、选择默认空间、管理空间，在图谱或列表中筛选、编辑记忆和关系，并继续管理文档与文件夹。
- 向量模型统一跟随功能绑定，语义检索的范围与阈值更一致，工具结果可显示匹配相关度。已有空间、关系及角色绑定继续保留。
- 用量统计重做为总览、模型、配置、请求四页，可按日期、模型、配置、来源和状态筛选，追溯已有的请求明细。活动图包含日、周、月、年和累计视图及独立日历。
- 运行质量增加平均首字延迟、P95 延迟、请求均费和成功请求生成速度，并显示各项有效样本数；请求列表和详情可查看 TPS，缓存命中率与成功率增加颜色提示。
- 完善基础、分段、峰谷时段等计价规则，新增中转计费倍率，金额可显示至八位小数，并提供更清晰的费用公式。统计页统一使用选择的 Token 单位，隐藏已删除或不再展示的配置，同时保留历史用量与费用；清空用量增加延迟确认。
- “数据与备份”集中备份恢复、聊天管理和诊断日志。文件快照可携带在用图片、字体和主题资源，导入时重新关联媒体与主题脚本路径；导出时可选择是否包含日志。
- 聊天侧栏整合嵌套目录与角色入口，支持批量整理和归档。归档聊天仍可在“已归档”列表找到并恢复，不等于删除。
- 继续提供 JSON、Markdown、HTML、TXT、CSV 聊天导出；原生 JSON 发展到 v4，支持主对话与子代理树，并按消息逐条读入大记录。完整迁移协作结构时使用原生 JSON；内置 ChatGPT、ChatBox 专用导入已移除，旧专用导出需先转换为支持的格式。
- 数据与存储可按 Linux、模型、记忆、扩展、聊天和备份等类别管理占用。删除安装归档、已安装环境或模型各有不同影响；Cookie 清理也会影响对应的登录状态。

## 扩展、工具与自动化

- 扩展管理按插件、工具包、Skills 和 MCP 分类，重做详情、配置、导入和更新入口。市场显示下载进度、速度及剩余时间，创作者中心集中发布与管理；默认不再只显示精选内容。
- 内置扩展改为按需安装、更新与资源管理，不要求全部随 APK 预装。市场核对工具包声明的宿主 API 范围；禁用的扩展不能继续从详情页或直接脚本入口执行。
- 完善原生卡片与工具包开发资料及示例，改善插件页面与聊天草稿的衔接。修正 MCP 和脚本可选参数的处理，执行日志与最终结果展示更清晰，启动失败、超时及参数错误提供具体反馈。
- 工具权限由五档收拢为普通、管理员、Root 三种模式，按设备实际授权提供能力。旧无障碍与调试器模式迁入管理员偏好，相关能力仍需完成对应系统授权。
- PhoneAgent 在满足主屏和无障碍授权条件时，可以根据控件观察定位、点击与输入，展示执行阶段和点击位置；用户接管后，继续执行需要重新观察界面，避免沿用旧控件定位。
- 工作流支持复制、JSON 导入导出和更明确的失败节点诊断。Operit Editor 扩充按目标查询和修改主题、角色发言、权限及性能指标的命令，修改仍遵循宿主授权。
- 图像生成工具包扩充本地或公开链接参考图。OpenAI 图像工具支持配置相应端点的 GPT Image 2.6 GIF 参数；实际模型能力由服务端决定，并非全部图像工具都支持相同输入或动画。
- 网页读取可分别设置整次、加载与读取时限，区分网络失败和访问拦截，并可等待懒加载。网页提取与浏览器交互是不同工具；HTTP 工具的总体超时真正约束整次请求。

## 重要修复与行为调整

- 优化长历史加载、消息拆分、滚动与末尾工具卡片点击，修正部分空白气泡、内容断层和重试时重复片段。改善重新打开会话、回复候选切换、复制和恢复后的内容一致性。
- 请求错误区分发送、模型响应与本地处理等阶段，总结重试与后台通知提供更清晰的状态。达到输出限制或工具批次被截断时，不把不完整输出当作正常完成；修正取消后的收尾和连续发送衔接。
- 改善 Claude 历史工具结果顺序、Gemini 请求与模型列表处理、DeepSeek 思考字段兼容；移除 DeepSeek Responses 自带的服务端联网搜索开关，不影响通用联网工具。
- 修正系统授权目录的嵌套路径及递归复制，阻止复制进自身，并整理失败留下的不完整目标；改善 Linux 搜索路径、行号、终端键盘与部分交互程序的等待。
- 调整脚本引擎与临时执行资源的收尾、同名终端生命周期、图片失败诊断，以及日志导出与本地崩溃报告。诊断日志可筛选错误上下文和可识别的敏感内容，暂停日志写入会在后续日期恢复。
- 更新界面组件和剪贴板交互，完善从右向左布局下的图标方向适配。
- 首次欢迎页简化为“开始使用”，无需在欢迎页先完成模型或权限配置；完整用户协议可在“设置 → 关于”查看。已有引导完成状态会沿用。显示设置可选择屏幕方向变化时的重载行为。

## 安装与升级说明

- 从 `1.12.2` 系列跨到 `2.0.0` 请使用完整 APK。正式版与补丁都在 Operit Kong 独立发行仓库提供；Beta 开关只控制检查更新是否包含补丁，关闭后不会主动降级。
- 已有 Kong 正式发行版可使用完整 APK 覆盖升级。社区版与 Kong 为独立应用，请先在旧版导出备份，安装 Kong 后导入并核对；调试包与正式发行包签名不同，不能直接覆盖。
- 升级会迁移聊天结构、统计和部分设置。建议先保留旧版备份，新格式备份与迁移后的数据库不保证旧 APK 能读取；聊天导出、文件快照与数据库备份的覆盖范围也不同。
- Ubuntu、离线语音和打包模板按需准备。升级后可继续使用已准备的资源；首次使用相关离线功能前，请下载或导入所需资源。

感谢 Operit 上游项目及社区贡献者，也感谢持续试用 Kong 补丁版、提供截图和问题反馈的使用者。后续更新将沿正式版与修复版本继续迭代。
