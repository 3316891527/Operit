## 范围与最终行为

同一版本完成本轮搜索排版、批量面板、剪切移动、系统打开、文件路由及归档功能，继续使用 PR #216 集中构建与验收。保留编辑器软换行；默认打开方式持久化留待后续；后续文本编辑器基础能力见[编辑器记录](07-text-editor-basics.md)。

搜索中的“包含系统隐藏和手动隐藏”和“区分大小写”移入高级条件，默认均关闭。默认搜索不区分大小写，也不包含隐藏项。“包含文本”改为“文件中包含内容”，名称及内容两边的“可留空”均移除。单项和多项面板的搜索限制在所选文件与目录；根层从真实来源重新读取属性，保留隐藏过滤和目录链接不递归的规则。

多选面板提供复制、剪切、属性、分享、搜索、压缩或解压、删除，搜索与归档操作同排。移除面板内全选、取消选择和文件夹不可分享的解释，包含文件夹时仍禁用分享。关闭面板保留选择，返回退出多选；页签菜单保留全选入口。移动通过剪切与粘贴完成，不再提供重复的移动按钮。普通文件显示压缩，归档显示解压；全部选中项都是归档时可批量解压。

常规归档和 ZIP 容器直接进入归档页面。无后缀文件及常见代码、配置、文本文件默认进入编辑器；图片、音视频、PDF、Word、Excel 延续现有预览。HTML 默认文本，SVG 默认图片，TypeScript 与 MPEG `.ts` 沿用已有内容识别。未知类型及“打开方式”直接拉起系统应用选择器，授权目录和 Linux 来源经共享传输层准备文件。

## 归档能力

- 归档文件本身在外部查看属性，包内文件和目录各有属性入口，并支持浏览、按需打开、全部或选中解压：ZIP、7z、RAR、TAR、TAR.GZ、TAR.BZ2、TAR.XZ、TAR.ZST 与常见短后缀
- ZIP 容器路由：APK、JAR、toolpkg、AAB、XAPK、APKS、APKM 等；DOCX、XLSX 保持文档预览
- 新建压缩包：ZIP、7z、TAR、TAR.GZ；ZIP 提供快速、标准、最大级别和可选 AES 密码
- ZIP 包内修改：添加文件与目录、删除选中条目、单项改名与目录前缀改名；保留既有条目的加密状态、加密方式、时间、权限属性和注释
- 非 ZIP 归档和嵌套归档提供只读浏览及解压，操作入口只显示可执行能力
- 归档页面复用文件行点击、区间滑选和带图标的两列长按面板；条目属性复用外部字段与复制交互，后台汇总目录或多选数据；压缩与解压提供进度、取消、失败信息，解密密码在读取加密内容时按需输入，创建 ZIP 的加密密码单独标明

修改 APK、AAB、JAR 等签名容器时明确提示签名会失效。打开包内文本后，现有编辑器保存的是独立解出的文件；本轮不提供编辑缓存自动写回包内的行为。RAR 分卷、各种加密组合、非 UTF-8 名称和大规模归档仍需针对样本验收，不将格式识别视为所有变体已经通过。

## 文件访问与提交边界

每个归档会话使用独立缓存，并核对复制前后的来源属性。普通文件按需解出到独立打开缓存，关闭归档后预览与编辑器仍可读取，过期缓存按时间清理。Android、本机 Linux、远程和 SAF 授权目录共用文件传输边界。

条目路径拒绝绝对路径、上级跳转、盘符和 NUL；反斜杠统一规范化。读取索引即拒绝重复规范路径和文件占用父目录，不解压链接。新建来源检查链接及特殊文件，父目录与已选子项去重；远程目录复制前也先检查链接。

ZIP 在另一个文件中重建，原包保持只读。新建或重建完成后完整读取输出校验数据与长度，再进入发布阶段。提交前比较原始快照与当前来源的 SHA-256，并重新核对来源属性；本机使用同目录临时文件与原子替换，其他来源使用临时项、备份和重命名事务，第二次改名失败恢复原包名称。事务进入提交阶段后不可被取消打断，避免留下半次提交。

新建归档先复制为隐藏临时项，成功后再改为最终名称，目标已存在则拒绝覆盖。取消或失败清理未发布项。SAF 同目录改名直接调用文档提供器重命名；不同提供器与远程文件系统的重命名、错误和并发行为仍需实际环境验收。解压先到会话缓存再传输，目标重名拒绝覆盖；跨来源传输的多项取消可能留下已完成项，按现有传输语义报告，来源不被删除。

ZIP 重建会重新压缩条目，并非原始字节级保留；未知扩展字段、原始压缩参数与签名不作为保留承诺。默认新建格式不包括 RAR，其他格式不显示 ZIP 编辑或加密创建选项。

## 依赖与许可

固定引入 `me.zhanghai.android.libarchive:library:1.1.6`，ZIP 继续使用现有 zip4j 2.11.5。已检查实际发布 AAR 的公开方法签名与元数据：`minCompileSdk=1`，没有要求项目从 compileSdk 36 升级至 37。项目当前打包 arm64-v8a；该 AAR 的 arm64 `PT_LOAD` 对齐为 16384。元数据与 ELF 检查不代替远程编译和设备装载验证。

绑定、libarchive、bzip2、LZ4、Mbed TLS、liblzma/XZ 和 Zstandard 的许可及上游固定提交记录随应用保存在 `app/src/main/assets/licenses/libarchive-*`。原生读写、设备存储提供器和压缩过滤器仍待设备回归。
