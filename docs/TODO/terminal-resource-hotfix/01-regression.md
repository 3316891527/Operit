| 编号 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 在缺失或版本不一致的依赖环境执行配置 | 先更新索引和修复依赖，再配置 dpkg，继续安装所选软件 |

| 4 | 导入符合当前校验规则的资源 ZIP | 导入成功，显示已保存 |
| 5 | 取消删除确认 | 文件及页面状态不变 |

| 8 | 删除后重新导入终端 ZIP 并新建终端会话 | 重新准备归档并安装，创建可用会话，无需重启应用 |
| 9 | 删除已安装但没有保存归档的 Ubuntu | 删除入口可用，完成后显示未安装 |

| 14 | 删除后离开并重新打开资源页面 | 状态与磁盘一致 |
| 15 | Ubuntu 含指向共享存储的符号链接时删除 | 仅删除链接，目标文件与已导出备份保留 |
| 16 | 删除失败或资源传输失败 | 显示失败并重读真实状态，可重试 |
| 17 | 下载或导入过程中取消 | 不完整文件清理，已完成文件状态正确 |
| 18 | 安装调试 APK，检查关于页及包名 | 显示 1.12.2+3、59，包名 com.ai.assistance.operit.debug |
