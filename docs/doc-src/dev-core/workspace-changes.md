# 工作台文件变更与对话产出

工作台首页采用紧凑工作区操作、中间对话产出、下方终端与浏览器双列会话的布局。“选择工作区”不再占用独立卡片，创建和选择操作保留为顶部按钮，继续进入原有功能页。未绑定目录也可以使用终端、浏览器和对话产出。

“对话产出”只有当前对话存在成功采集的文件操作记录时才显示；没有记录时首页不组合该区域，也不保留中间空位。记录写入时通过存储 revision 刷新，切换对话重新按 chatId 读取，产出页签与页面渲染也遵守同一条件。当前记录定义包括编辑、删除、目录操作等成功文件操作，不仅是新增文件。任意 shell 或外部程序的修改不自动成为对话产出。

终端列表只展示手动会话，自动化后台会话不进入主页或页签；新增、打开和关闭继续使用既有终端管理器与终端页面。浏览器直接复用内置浏览器的全局会话、WebView、标签、书签、历史、下载和 userscript 能力。工作台和浮窗切换时转移显示容器，离开工作台不销毁浏览会话；关闭最后一个标签后返回工作台首页。

独立 HTML 打包页面、工作台入口和主题页面目标已移除。静态项目改用 [build html 命令](../feature-protocol/html_build_cli.md)，原有聊天内容导出继续使用原有弹窗。

工作台提供原生内置的“文件变更”和“对话产出”入口，创建项目继续使用已有模板选择流程。审阅页使用独立、可关闭的工作台页签，切页保留文件选择和查看设置。手机和宽屏均并排显示文件区和差异内容，打开文件后仍可直接从左侧切换文件。文件区可隐藏或拖动调整宽度；窄屏内容过宽时提供横向滚动。

“文件变更”按当前绑定目录及文件后端筛选。Git 仓库根目录大于绑定目录时，状态查询仍携带绑定范围，跨边界重命名只显示范围内的一侧。“对话产出”按实际执行文件操作的对话归属筛选，不需要绑定工作区，可以包含工作区外文件。打开记录中的文件沿用现有文件查看窗口，不改变绑定目录。历史 Linux 记录额外保存本机／SSH 连接标识，切换连接后不会将同路径的另一个文件当作原文件打开。

工作区审阅提供 Git 变更、分支变更、上一轮变更，以及保留完整历史的操作记录。上一轮按当前对话真实用户消息的时间边界选择最近一次包含已采集文件操作的请求，同一路径比较该轮第一次操作前和最后一次操作后的快照；尚无可对应的消息边界时不猜测轮次。对话产出默认展示完整操作记录，绑定工作区时也能从来源菜单进入 Git 与分支审阅。未提交变更包含暂存、工作树和未跟踪文件，支持尚无首次提交的仓库；分支对比从显式选择的分支与 HEAD 的共同祖先比较，已有 upstream 时直接使用已声明的上游。Git 查询只读，不执行暂存、提交、切分支、合并或推送。Git 需要对应 Linux 环境中的可执行程序；系统授权目录可以查看已采集的操作记录，不执行 Git。当前 Git 查询范围是一处绑定目录所在的仓库，不递归发现子仓库。

审阅页参照 Operit2 的 change_review 插件，以 32 dp 高的紧凑工具栏统一文件区开关、前后文件导航、打开方式、单双栏和查看选项。来源菜单位于左侧文件区；比较分支可以显式选择。文件列表按相对路径筛选，使用类型图标、状态色、增删统计和操作时间；项目树开关按需读取工作区目录，选中已变更文件时切回对应差异，其他文件进入已有文件查看窗口。文件名和父目录共用一条状态栏，历史操作时间使用独立紧凑菜单。窄屏也可拖动文件区边界；隐藏后按返回键恢复文件区，保持当前文件、筛选和折叠状态。正文采用 11 sp，行号与次要说明进一步缩小，普通文字使用正常字重。

文件内容和高亮结果一次性发布，准备文本期间只显示加载状态，不会误入二进制提示。页面缓存最多保留 12 个已准备文件、合计 4 Mi 个 UTF-16 字符，切换文件复用历史快照、差异和高亮；刷新、采集 revision、来源或基准变化时失效。首次查看仍需读取相应快照并准备语法高亮。差异支持单栏、双栏、UTF-16 行内强调、自动换行、未修改区域逐段展开及完整文件。旧、新文本各自从完整快照在后台执行 TextMate 分词，复用现有语法目录和编辑器主题。差异区使用紧凑单行号区、增删标记和边缘色条，双栏对齐显示前后版本，局部空缺侧单独着色；整个旧版本或新版本为空时，显示明确的新增／删除说明，让实际内容使用整幅宽度，保留用户的双栏偏好。分栏边界可以拖动，连续改动块支持向前或向后跳转，未修改区域以可点击的折叠条展示，每段可见内容显示旧、新坐标范围。切换文件保留单／双栏、自动换行和完整文件偏好。文件末尾换行差异单独显示。


文本编辑器“更多 → 代码溯源”按当前光标行查询 Git 作者、作者时间与时区、提交说明、完整哈希及历史路径和行号，可继续查看该提交中这个文件的差异。查询固定打开入口时的不可变编辑快照，不要求保存。当前快照先与 HEAD 文件比较，只把未修改的行映射到 HEAD，再查询该历史行；前面插入未保存内容不会把后面的代码归给错误行。新增、修改、首次提交前文件和 HEAD 中没有的文件显示未提交；文档末尾仅用于继续输入的空行也没有历史来源。LF 与 CRLF 只在映射时统一，不修改文件。
溯源以实际文件所在的 Android 或 Linux 后端查询仓库，冻结编辑器当前的本机或 SSH 连接。连接改变后明确报错，重新打开文件后再查；系统授权目录、不在仓库、缺少 Git 运行环境、非普通 UTF-8 文本及读取失败都保留具体原因，不显示成未提交。嵌套目录中的路径统一相对仓库根解释，Git 引号路径和原始路径分别处理，保留中文、双引号、制表符与换行文件名。
来源行沿 Git 的重命名历史显示当时的文件路径。历史差异读取完整提交对象的父列表，优先比较 blame 显式声明的父提交，否则比较第一父提交，并在界面显示比较哈希。真正的根提交以空文件为前版本；浅克隆缺少父提交时提示历史不可用，不生成虚假的整文件新增。差异窗口保留单／双栏、换行、折叠和改动块导航，完整提交说明按 UTF-8 输出。返回差异页前的来源信息不重复查询，关闭窗口、切换文件或编辑器会话取消请求并释放执行连接。
溯源按需缓存一份 HEAD 文件、一份编辑器版本映射、最多 16 行来源和一份准备好的历史差异。HEAD、文档所属会话或版本变化时重新定位；同一仓库对象不会被当前工作树内容替换。缓存随编辑器入口组合释放，读取沿用每侧 2 MiB、两侧合计 20,000 个换行、单行 8,192 字符的文本差异限额。所有 Git 命令只读，不保存编辑缓冲区，不修改工作树或暂存区，不执行提交、推送或消息回滚。

操作记录详情的时间行旁提供“管理操作记录”。选择某次历史后可以删除此次文件记录；上一轮汇总先选具体历史再删除单次。“清除此文件全部记录”查询该文件路径与后端的全部轮次，对话产出限定当前对话，工作区记录可以包含其他对话。确认窗口明确显示路径、数量和作用范围；只删除确认时列出的记录，不包含确认期间新产生的记录。删除单次后仍有其他记录时，该文件继续显示；清除最后一条产出记录后，首页和页签随 revision 更新隐藏产出入口。Git 和分支差异不提供该清理菜单。
批量文件操作的多条记录保存在同一个操作文件中，删除其中一条只原子改写余下记录。清理只涉及被删记录引用的快照，跨文件、跨对话仍有引用的内容继续保留。记录清理与文件操作采集共用互斥锁，避免删除进行中采集即将保存的同内容快照；内容读取和清理串行，统计缓存随 revision 清除。删除失败保留诊断，已经完成的记录移除仍发布 revision。记录管理不删除当前文件，不恢复历史内容，不修改聊天或 Git 状态。
从差异页的打开方式菜单或项目树打开当前文件时，先在当前页完成元数据查询和必要的文本读取，成功后才创建已有文件窗口，准备好的文本传给窗口直接使用。Android 普通权限读取通过实际系统诊断区分路径不存在与访问被拒；文件后端返回的明确权限、非文本和不存在诊断分别展示，未知错误保留原始原因。连接改变、路径已是目录、文本超出 10 MiB 等状态同样明确提示。打开失败的原因、路径和详细信息显示在当前审阅页的可关闭错误区域，不再跳到只显示错误的文件页。复制路径不要求文件存在，文件管理器检查父目录。点击打开会重新检查当前文件，历史快照的删除状态、类型和存储内容不作为当前文件存在的依据。
检查与读取遵守历史记录冻结的文件后端，读取前后及窗口创建前校验连接标识。关闭审阅页、切换文件或隐藏页面取消尚未完成的打开请求；取消不转成读取失败，也不在后台弹出文件窗口。初始只读历史差异继续保留，打开方式表示用户点击后的动作，不自动替换差异内容。

采集包装注册后的实际文件执行器，不依赖顶层代理返回的字符串或聊天渲染器。文件创建、编辑、写入、移动、删除、复制、建目录、压缩解压和下载工具在操作前后采集；只有成功结果入操作历史，中间进度不形成独立记录。包内文件调用显式携带发起会话的运行上下文，通过原生线程桥接恢复对话标识；没有对话上下文的界面操作不计入对话产出。包的会话脚本使用独立模块实例，避免异步闭包借用其他会话的文件工具。

历史写入应用私有目录 `files/workspace_changes/v1`，每次操作使用独立 JSON 原子保存，原始内容按 SHA-256 去重。多次修改同一路径在列表折叠，详情可切换各次操作，读取当时的前后快照。新记录直接保存增删行数，旧记录从原始快照生成并缓存统计，列表、汇总和详情使用同一比较语义；无法统计的二进制或超限内容显示未知标记，不把未知值当作零变更。Git 的未跟踪文件和首次提交前文件也从实际内容计数。历史查询不会读取当前文件来替代旧版本，切换绑定也不会改写记录归属。

单文件快照上限为 2 MiB；一次操作每侧最多保存 16 MiB 内容，目录扫描最多 512 条、深度 32。超限、二进制、非 UTF-8 和读取失败都有明确状态，不把未采集内容当作空文件。文本差异最多处理旧、新合计 20,000 个换行和单行 8,192 个字符。Git 传输先编码原始 stdout／stderr，再经过隐藏 shell 的行协议，保留 NUL 和特殊文件名，单次 stdout 上限为 4 MiB。文件名参数逐个做 shell 引号转义；读取符号链接显示链接本身。

没有 Git 的工作区可审阅启用此功能后成功采集的文件工具操作。外部程序、任意 shell 命令和此前没有采集的修改不生成操作历史；Git 视图可读取仓库当前的外部变更。此版不提供历史撤销。

来源和许可证记录在 `workspace/git/SOURCE.md`，移植的解析与强调逻辑保留 AGPL-3.0 许可。

回归源码覆盖特殊文件名的真实 Git 状态、首次提交前状态、跨目录重命名、二进制统计、历史文本重建、折叠展开、改动块导航与空侧坐标、末尾换行、代理字符和历史序列化。`ci/test/workspace_change_context.test.cjs` 覆盖并行对话交错调用、流式中间结果及普通界面调用，接入 Android Tests 工作流。设备回归补充视图控制与切换文件后保留查看偏好、产出显隐后布局复原、浏览器会话入口与共享 WebView 容器转移的交互源码。静态核对与远程运行记录维护在同一 PR；新增回归源码不等于已执行通过，设备交互和完整构建仍由验证结果确认。


打开方式适配 Android 已有入口：文件资源管理器打开文件所在目录，文本编辑器按文本编辑当前文件，终端新建会话并进入所在目录，复制路径只写入系统剪贴板。原版的 Visual Studio Code 通过桌面 `code -g` 打开，本版使用内置文本编辑器。终端检查文件记录的本机／SSH 后端与新会话是否一致，不对错误连接执行目录命令；已删除文件仍允许打开父目录、终端和复制路径。

编辑器空文档、空行以及文本右侧没有可选字符的位置，长按定位插入点并显示全选、粘贴；已有文本选区继续显示完整六项工具条。只读时粘贴保持禁用，普通点击、滚动、缩放和返回会正确关闭插入菜单。

本轮新增回归源码覆盖空文档粘贴、空白行全选、旧快照列表与详情统计一致、整轮首尾快照、未知统计、缓存复用与淘汰、原子文本就绪状态以及纯新增双栏展示。验证执行状态由 PR 的远程记录维护，未运行的设备源码不代表实机验收完成。

代码溯源回归源码增加 9 项 JVM 方法，覆盖真实嵌套重命名、中文与控制字符路径、浅克隆真实父列表、未保存增删改行映射、CRLF、末尾空行、超限、SHA-256、非法协议和合并父提交选择。另有 5 项设备回归源码覆盖未提交无历史操作、错误与重试、关闭及快照切换取消、打开历史再返回时保留来源和原始内容。本地没有执行编译、构建或测试；源码存在不代表执行通过。

记录清理与打开校验新增 4 项 JVM 错误分类回归源码和 8 项设备回归源码，覆盖批量记录保留、跨对话共享对象、删除后重载与统计、文件与后端范围、进行中采集互斥、实际文件不变，以及当前页错误、删除后列表刷新和离页取消。本地未执行编译、构建或测试，静态结果和远程运行记录在本轮交付中分别维护。
