# 归档读取、APK 入口、统一菜单与逐文件进度

[返回计划](index.md)

用户确认语法高亮体验满意，本轮不调整高亮。设备反馈涉及归档与包内文件反复显示处理中、APK 点击直接进入 ZIP、内外长按菜单项目不同，以及解压和删除无法看到目录内部逐文件进度。

## 实施清单

- [x] 本机归档直接读取并复用会话索引，包内文件按需提取和缓存，快速读取不闪现模态进度
- [x] 本机修改在写入前取得独立快照，提交继续校验来源和内容，读取优化不取消原有冲突保护
- [x] APK 入口显示名称、图标、包名、版本、大小和 SDK 信息，提供查看与系统安装入口
- [x] 普通文件、多选和归档内项目共用完整两列菜单，位置一致，不可用项目置灰且不可触发
- [x] 删除预先枚举真实子项，按后序逐项删除并上报当前路径和完成数量，保留取消与部分成功语义
- [x] 解压复用目录索引，上报当前文件、条目数量和字节进度；本机发布减少重复复制，其他来源继续共享传输协议
- [x] 补充有意义的回归源码、多语言提示、文档和静态核验，并准备原 PR 的提交、远程构建与测试入口

## 实现约束

首次读取需取得必要索引；ZIP 可直接使用中央目录，压缩 TAR 和固实归档仍受格式顺序读取限制，不承诺所有格式秒开。读取和打开包内文件时核对来源是否变化。缓存文件脱离归档会话后仍能由现有编辑器或预览读取。

删除先明确总条目，目录内部文件和子目录分别执行，链接不跟随；扫描阶段不显示虚构百分比。取消后保留已成功删除的事实，不开始后续条目。解压保留路径检查、密码处理、禁止越界与覆盖的约束；阶段切换明确展示，写入目标完成前不宣称任务完成。

安装动作仅由用户点击安装后调用系统安装器，安装来源授权由系统处理。界面实现沿用应用主题和现有操作进度样式，不显示底层工具实现细节。

## 验证边界

默认不在本地执行编译、构建或测试。静态核验与远程运行结果分别记录；远程运行记录建立后停止查询进度，设备体验和实际耗时仍需设备验收。

## 实现与检查记录

本机归档会话直接持有来源文件与一次解析的目录索引。ZIP 单文件读取复用中央目录和条目输入流，重复打开未修改条目复用独立缓存；缓存被编辑后重新提取到另一个文件，保留编辑器仍在使用的旧缓存。Android API 27 及以后以设备号、inode、长度和纳秒 mtime/ctime 检测读取版本；API 26 另行核对内容摘要。已只读核对 Android 8.1 的公开 StructStat 字段，不把来源优化描述为所有设备和格式均能秒开。

ZIP 修改前取得独立快照，提交前比较来源与快照内容，并在本机原子替换前再检查来源版本。普通本机解压在目标文件系统的隐藏临时目录完成，发布通过移动顶层结果避免重复复制数据；解压阶段显示内部条目，发布阶段按实际发布的子树推进条目数量。发布期间取消可能已留下完成的顶层结果，临时目录会清理，已有目标不合并覆盖。

APK 从文件列表、嵌套归档和聊天文件链接均进入同一信息入口。显示名称、图标、包名、版本、大小、最低及目标 SDK、已安装版本；查看打开内容，安装先准备 FileProvider 覆盖的共享副本，再调用系统安装器。未知来源设置由系统处理，返回后由用户再次点击安装。跨环境准备的 APK 可复用图标缓存，避免重复传输。

十二项操作按固定两列布局排列，单选、多选、包内共用同一组件。不可用操作保留置灰，点击被禁用。递归删除先扫描后序清单，逐文件、逐目录执行；非本机目录使用非递归删除协议，删除前核对目录为空。已只读核对固定 terminal 子模块版本的本机和 SSH 提供方支持空目录非递归删除；授权文档提供方的原子性仍取决于系统提供方。

本轮新增 15 项 JVM 回归源码，覆盖递归删除、归档 reader 复用、读取取消和进度计算，更新原有 7 项删除回归。与文件图标合计新增 10 项设备回归源码，覆盖本机直接读取、缓存同长度同 mtime 编辑、来源变化、发布结果、APK、缩略图、矢量资源和菜单禁用。新增提示完整提供九种语言。Kotlin 解析、XML、资源引用、占位符、文档链接和空白检查独立记录；实际执行结果由远程运行和设备验收确定。
