# 实现与验证

## 1. 工作区与终端

原先终端页单独修改 Activity 状态栏颜色，选择与创建工作区沿用另一套颜色；外层聊天操作栏层级高于工作区覆盖层，仍绘制原聊天标题。

- `WorkspaceHubScreen` 移除局部状态栏改色，系统栏继续由全局主题保持透明
- `AppContent` 在工作区打开时，先绘制不透明主题底色，再预留状态栏空间，覆盖背景图片与原聊天内容
- `MainChatControls` 切换工作台、终端标题与文字颜色，不继续显示原聊天标题
- 关闭工作台后恢复聊天背景和聊天标题

[DONE]

## 2. 对话归档

新增 `data/chat/archive` 与 `ui/features/chat/archive`。数据库从 27 升到 28，只为聊天元数据新增 `archived`，已有聊天默认未归档。

- 历史列表与主侧栏共用“归档对话”“恢复到聊天列表”操作及“已归档”筛选
- 归档保留消息、工作区、文件夹路径、角色绑定、锁定、置顶、排序和最近使用时间
- 当前打开的对话仍可查看、继续生成；归档状态不会因为查看而自动恢复
- 归档列表沿用角色、文件夹和搜索过滤；无归档时显示空状态
- 切换角色自动选会话、删除会话自动选替代会话时排除归档项，主动点击归档项仍可打开
- JSON 流式导出、备份模型、CSV 导出与导入携带归档状态；旧 JSON、CSV 缺少字段时按未归档读取

[DONE]

## 3. GitHub 与用户资料入口

市场管理页直接使用共用 `GitHubLoginDialog`，认证数据通过 `GitHubAuthPreferences` 共享，与设置页导航无依赖。

- 设置页移除账号板块和独立用户资料入口
- GitHub 账号页面移动到 `packages/market/account`，市场管理页增加固定账号入口，可登录、查看账号及退出
- 原市场管理登录、发布、评论认证继续使用原登录组件和存储；保留原导航标识
- 角色卡中的小资料图标改为整行带文字按钮，最小高度 48dp
- 用户资料保存成功后显示 Toast；新增“管理资料与记忆空间”入口承接原完整资料管理能力
- 原资料管理页移动到 `settings/profile`，保留资料、记忆空间标识、策略与锁定设置
- 从资料弹窗进入管理页时，同样检查未保存改动并允许取消

[DONE]

## 4. 用户资料弹窗

`ContentSizedTabbedDialog` 改用完整窗口作为测量宿主，在安全区域和输入法范围内居中显示内容。异步资料加载完成后仍依据完整可用空间重新计算高度，避免使用旧窗口高度导致内容截断。弹窗使用不透明主题表面色，保留编辑、预览、分页、滚动、标题与操作区，以及点外侧关闭和未保存确认。

这个组件也用于翻译等分页弹窗，因此回归包括短内容、长内容、页签切换和输入法展开。

[DONE]

## 5. 已完成的检查与待验证项

- 已完成：源码差异审查、导航与认证调用链核对、归档读写映射核对

- JVM 回归代码：新增 `ChatArchivePersistenceTest` 四项，覆盖已发布数据库迁移、实体与 JSON 备份往返、旧备份、CSV 归档及组织元数据
- 已更新联合数据库迁移回归至版本 28，CSV 兼容回归包含未提供归档列的旧格式
- 本地不执行编译、构建或测试；提交后由分支 Android Build 的 `assembleDebug` 与 Android Tests 验证
