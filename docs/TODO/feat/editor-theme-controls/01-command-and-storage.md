# 命令与保存

新增 theme targets、theme fields、theme show、theme set。参数继续通过字符串数组和单个 JSON 正文传递，不新增每个外观字段对应的脚本工具。

current 目标由调用对话确定，群聊读取角色组主题；直接调用且没有对话身份时使用应用当前激活主题。也可以用 card/group 与精确 ID 指定目标。全局头像与用户名称使用 user 目标，不能混入角色主题补丁。

theme show 返回偏好快照和 revision。theme set 必须携带同一目标的 expected_revision，在持久化事务内部检查，再只修改 changes 中的已知字段。未知字段、错误类型、越界值和显式矛盾的依赖拒绝保存。颜色、字体和消息质感遵循已有设置页的联动。

返回实际目标、保存与核验状态、发生变化的字段、读回偏好和新版本。偏好值不冒充自定义主题脚本最终渲染结果；保留现有脚本引用并注明其存在。持久化成功后读回失败时，失败结果仍保留 saved=true，避免误报完全未修改。
