# 文本编辑器选区工具条与界面反馈修正

[返回计划](index.md)

## 原有行为与目标

按同一 PR 的设备截图反馈，修正保存反馈、长按选区、查找替换、设置与顶部布局。当前长按使用系统 ActionMode，查找替换始终一起展开，设置为长对话框；标签内边距、圆角及操作按钮尺寸也未满足预期。

## 实施清单

- [x] 文件实际保存成功后显示 OKToast，保留异步保存期间的新输入状态
- [x] 从编辑菜单移除全选，长按使用应用自定义工具条，提供查找、全选、剪切、复制、粘贴与范围查找
- [x] 范围查找固定当前选区边界，查询和替换只作用于该范围，切换文件及文本变动时维护边界
- [x] 精简底部查找，按需展开替换，匹配定位同步光标，结果与三个小开关置顶，导航及替换操作置底
- [x] 设置改为独立全屏页面，分组展示并复用 WorkbenchSlider，语法高亮标签简化
- [x] 深色编辑区使用 VS Code 经典背景 #1E1E1E，浅色仍适配应用主题
- [x] 主页、工作区和文件标签共用圆角矩形，减少上下内边距，统一主题文字颜色
- [x] 撤销、重做、保存、编辑和更多增大图标与点击区域，拉开间距
- [x] 补齐多语言、必要回归源码和实现说明，静态检查后提交原分支与 PR

## 验收与交付

核对长按工具条与拖动手柄、范围边界、零宽正则、光标定位、只读及输入法组合、深浅主题、小屏标签滚动和设置返回。延续仓库约定，本地不执行编译、构建或测试；新增回归源码与执行结论分开记录。远程 Build、Android Tests 和 PR Check 记录建立后停止查询工作流进度。


## 实现说明

普通保存只有在 write_file 成功返回后显示保存成功 OKToast，失败仍走错误展示；保存期间继续输入的内容保持未保存状态。编辑菜单移除全选，原有行操作继续可用。

长按与双击选区使用应用 Compose 浮动工具条，包含查找、全选、剪切、复制、粘贴与范围查找六项，不包含翻译。移除系统 ActionMode 入口；拖动手柄时收起工具条，结束拖动后按新的选区重新定位。工具条不获取窗口输入焦点，按返回可收起而不丢失选区；只读禁用剪切和粘贴。

范围查找保存独立起止边界，匹配结果保持原文绝对偏移，禁止跨越边界。全词判定仍检查原文相邻字符，正则分组替换和范围末尾零宽匹配保持有效。光标导航不改变范围；输入和替换同步映射边界，撤销记录保存本轮圈选的前后快照，重新圈选后不恢复其他范围的旧快照。关闭搜索、退出文件或重新加载释放相应范围。范围指示开关可切回全文搜索。

查找默认只展开查询行，点击展开箭头或替换操作才显示替换输入框，展开时定位到该输入框。结果计数及紧凑的 Cc、W、.* 开关置顶，输入改为细线样式；上个、下个、替换、全部替换与小尺寸关闭按钮置底。首次查询与上下项导航同步真实光标和视口。异步替换提交前检查文件、编辑器、原文、查询选项、替换内容、活动结果和范围，避免覆盖变化后的状态；未发生内容变化的替换不制造未保存状态，空替换的零宽匹配继续前进。

设置改为独立全屏页面，带返回入口，分字体与排版、辅助显示、缩进、语法与工具、文件检测五组。字号、行距和缩进宽度复用 WorkbenchSlider 的细轨与圆形滑块，不绘制刻度。语法开关统一更名为语法高亮，仅控制既有规则。

深色编辑区及行号栏使用 #1E1E1E，主题浅深切换仍依据应用实际配色，浅色继续适配应用主题。主页、工作区和文件复用 WorkspaceNavigationTab：可见圆角矩形最小高度 28dp、上下内边距 2dp、圆角 12dp，统一使用主题正文颜色；外层保留 44dp 点击高度。文件保留图标、关闭及未保存提示，激活时仍自动滚动到可见位置。撤销、重做、保存、编辑和更多使用 44dp 按钮、24dp 图标及 2dp 按钮间距。

## 静态与回归源码

本轮增加 10 项 JVM 回归源码，覆盖范围内字面和分组替换、禁止越界、全词边界、零宽范围端点、范围前后及两端编辑。增加 7 项设备回归源码，覆盖重复文本的精确撤销、范围替换与一次撤销、中文组词、重新圈选、真实光标定位、自定义工具条状态及只读剪切粘贴限制。整个 PR 累计新增 90 项 JVM 与 39 项设备回归源码。

本地未执行编译、构建或测试。已完成 Kotlin 语法、资源与占位符、图标、UTF-8、空白及文档链接的静态检查；仓库卫生及增量翻译检查结果记录在交付说明，静态检查不替代类型检查和执行结果。Build、Android Tests 与 PR Check 对应提交的链接由 PR 维护，运行记录确认建立后停止查询进度；设备视觉和触摸验收等待构建包。
