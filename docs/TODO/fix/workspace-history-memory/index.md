## 实施边界

开发验证使用观察器排除的临时目录，没有迁移或清理用户真实历史，也没有启动子代理。2 MiB 单对象限制与跨对话引用保护继续保留。

旧操作 JSON 成功迁入新操作表后会移除源文件，旧 APK 不能读取已迁入新表的操作历史，详见兼容说明。原目录入口与内容分卷格式保持兼容。

两次应用闪退的原因尚未调查。已停止手机上的新增编译、JVM 测试和规模测量，收尾仅包含轻量审阅、文档、提交与远端工作流。中间基准中的 JVM 堆溢出不能用于解释应用闪退，最终版本规模测量未重跑。
