# 01 原生控件样式

## 原实现与修改意图

输入框和按钮大多使用 Material 默认形状；复选、单选和开关缺少统一容器与选中行提示；Expandable 的标题只有文字按钮，不直观表达展开状态。第一轮保持原有行为与主题色解析，仅集中整理这些控件的形状、间距和状态呈现。

## 实现范围

- CardControls 统一 12dp 控件圆角、轻底色输入框、选项行装饰及整行选择器；显式 Card 使用 16dp 圆角
- 下拉框、日期选择器和 Expandable 共用旋转箭头，读屏可获知已展开或已收起，长标签自然换行
- 复选、单选和开关保留整行 toggleable/selectable 角色、子控件空回调、原有禁用和回写判断
- 常用按钮最小高度为 48dp，Grid 保留等宽布局；分段和标签页形状统一，分段换行保留纵向间距
- TextField、TextArea 与 Draft 使用一致的输入底色；功能描边复用现有颜色校正函数，按合成背景保持 3:1 目标
- 进度条使用 6dp 高度和更清楚的标题间距；通用 CheckBox 不强加完成项删除线

## 验证边界

静态核对包括 Kotlin 解析诊断与基线对比、严格 UTF-8、引用的已有资源及图标、差异空白、共享输入包装参数，以及绑定、只读、禁用和变更回调的源码差异复核。独立审查发现初版未聚焦边框过淡后，已改为根据实际合成背景校正功能边界颜色。

本机语法库对两份既有目录文件的匿名 catch 参数和 open 软关键字报出与基线相同的诊断；新增控件文件与呈现文件可直接解析。此限制已记录，不能据此声称 Kotlin 编译通过。
