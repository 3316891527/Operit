# 文件类型图标、图片缩略图与 APK 原生图标

[返回计划](index.md)

文件列表的统一文档图标不利于辨认类型。本轮按用户反馈补充文件视觉标识，沿用现有列表和 Coil 2.5 图片加载能力，范围限于普通列表、搜索、归档列表和归档选择器。

## 实施清单

- [x] 比较现有依赖与开源文件图标，选取 MIT Material Icon Theme 的少量资源并保留固定来源、校验值和许可证
- [x] 常见文本与代码类型使用对应矢量图标，未知类型、目录、压缩包及多媒体使用明确的类型图标
- [x] 可见图片后台加载按尺寸采样的缩略图，APK 读取其应用图标；限制并发并复用缓存
- [x] 统一各列表图标入口，链接不自动跟随，读取错误明确显示失败状态
- [x] 补充关键类型识别和图标读取回归源码，核验资源与许可证，记录实际验证边界

## 取舍

不导入完整的编辑器图标扩展及运行时依赖，不生成全语言图标目录，不扩展图标主题设置。仅保留常见类型所需的小规模矢量资源。图片复用 Coil 的采样与内存缓存，APK 信息和列表图标复用同一读取函数。跨环境来源按已有访问协议准备本机文件；授权图片使用内容 URI。

## 验证边界

本地不执行编译、构建或测试。静态资源与源码核对、远程 JVM 执行、设备视觉和性能验收分别记录。


## 实现与体积

选取 Material Icon Theme 固定提交 `3929c5487ca03352f31cfba675b367448449094d` 的 34 个文件类型图标，转换为 Android 矢量资源。保留路径、填色、圆角矩形和 Kotlin 渐变，按各自 SVG 坐标范围设置视口及平移。矢量 XML 合计 27,487 字节，许可证 1,085 字节，来源与双 SHA-256 清单 11,261 字节，共 39,833 字节。这是仓库资源大小，不是实际 APK 增量。

普通文件列表、搜索结果、归档内容和选择器共用 32dp 图标区域。常见代码、配置、文档、压缩包和媒体使用类型图标；APK 使用应用原生图标。可解码图片由已有 Coil 2.5 按列表尺寸采样，以环境、路径、版本及尺寸区分内存缓存。两项后台并发限制传输、APK 解析和解码；离开可见行会取消请求，不阻塞目录加载。

本机图片直接读取，授权图片使用内容 URI，其他来源按现有传输协议准备缓存文件。跨环境 APK 的准备文件也供信息入口复用；缓存按来源元数据区分，并清理七天前的旧目录。链接不自动跟随，读取失败显示明确错误图标。SVG 等本轮未配置解码器的格式使用文件类型标识。

ZIP 包内图片和 APK 使用已打开会话的索引与条目缓存，未解密条目及需要顺序扫描的归档仅显示类型图标，用户打开时再读取内容。后台缩略图不更新操作进度；用户开始操作时停止后台请求，避免争用会话。

## 回归与验收

新增设备回归源码验证 34 个矢量能绘制非透明像素、Compose 渐变加载、缩略图采样及版本缓存、不跟随符号链接、真实 APK 元数据和图标、安装 URI 授权，以及菜单置灰、启用和位置稳定。远程 JVM 工作流不等于设备用例已执行，实际缩略图速度和视觉表现仍需设备验收。
