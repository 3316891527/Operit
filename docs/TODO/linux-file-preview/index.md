# 工作区文件浏览、管理与通用查看

工作区目录选择页、绑定后的工作区文件页和已有编辑器原本分散在不同入口中，绑定后首先显示预览白板，文件浏览器还需要通过底部菜单打开。本次把文件浏览提升为工作区默认内容，并让未绑定状态也能浏览、打开文件；绑定仍然负责聊天上下文、预览服务和持续协作范围。

本次先完成界面重构，再在既有文件浏览、编辑和预览能力上补齐共用操作。工具箱文件管理器是否移除保留为后续入口清理事项，不改变本轮工作区行为。

## 已确定的交互

- 单栏目录列表：点击文件夹进入目录，点击文件按类型打开现有应用内查看器或编辑器。
- 长按菜单采用两列图标与文字布局，仅保留复制、剪切、粘贴、重命名、打开方式、分享、删除。
- 文本、代码、日志、配置和 CSV 文件直接进入已有可编辑 `CodeEditor`；编辑器本身同时承担查看、选择、搜索和保存。
- Markdown、HTML 默认显示源码，可通过已有预览切换；图片、音视频、PDF、Word 和表格继续使用现有预览。
- 选择目录的“使用此文件夹”按钮与打开文件分开；临时打开文件不会替换当前聊天绑定的工作区。
- 用户查看文件使用本地文件读取、解码和播放，不调用大模型。

详细布局、按钮行为、验收标准及参考图片见 [01-interaction-design.md](01-interaction-design.md)。

## 实现范围与结构

- 在现有 `ui/features/chat/webview/workspace/` 下扩展文件浏览器、工作区管理器和选择工作区页；文件操作菜单与排序对话框拆为同一功能包下的辅助组件。
- 复用 `FileUtils` 的文本类型判断、已有 `CodeEditor`，以及图片、播放器、PDF、Word 和表格预览组件。
- 绑定后的 `WorkspaceManager` 默认显示 `FileBrowser`，预览通过顶部标签进入；导出、重命名和解绑移到顶部菜单，编辑操作显示在编辑页面上方。
- 未绑定状态通过 `WorkspaceScreen` 临时打开文件，保存按文件携带的来源环境执行，返回时恢复目录选择页，不修改聊天绑定。
- Linux 文件路径和附加仓库路径保留环境信息；搜索匹配在已有画布编辑器中高亮，行号和高亮不进入复制内容。

## 实现顺序

1. 完成可审阅设计稿和交互规范。
2. 将绑定后的默认内容改为共用文件浏览器，保留原有预览、编辑和保存。
3. 接通未绑定目录浏览、临时文件编辑、长按操作、排序和搜索高亮。
4. 复核工具箱重复入口与聊天文件链接的后续接入范围。
5. 按项目协作要求完成回归检查清单，用户明确要求后再派发 Android Build 与 Android Tests。
