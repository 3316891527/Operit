# Activity 重建保留页面与返回栈

## 实施范围

将导航路由及待处理分享、快捷方式、插件和通知请求保留在 Activity ViewModel。配置重建不重新消费原始 Intent；确认允许或明确拒绝后才结束导航请求，协程取消继续保留请求。保留当前目录与主题接口，适配上游 #1480。

## 验收目标

同进程 Activity 配置重建后保留页面、返回栈、路由实例和复杂参数；已消费请求不重放，待确认请求不丢失。进程终止后的恢复与 ANR 排查不在本次范围。

## 设备验收步骤

1. 打开多级页面，再切换屏幕方向或触发同进程 Activity 重建，核对当前页面、逐级返回和复杂详情参数。
2. 分别通过分享、快捷方式、插件路由、聊天通知打开页面，重建后确认已处理请求不会重放。
3. 在未保存页面弹出离开确认时重建，核对请求仍可继续；明确取消后不再次弹出。
4. 结束应用进程后的启动按原有入口处理，本次不保存完整导航到磁盘。
