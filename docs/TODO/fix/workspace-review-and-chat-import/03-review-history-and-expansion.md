# 记录汇总与展开保留

现场核查截图文件对应的两条 edit_file 记录：操作前后均为有效文本快照，每次实际只插入一行，因此各自 +1/-0 正确。GitHub 展示整个提交差异，而终端脚本更早完成的修改没有经过文件工具，不存在于这两次操作快照中。

记录页原先默认只展示每个文件最新一次操作，较早操作中的删除不会进入该默认比较。现在默认比较该文件第一条已记录的 before 与最后一条已记录的 after。历史菜单继续允许选择单次操作，并标明时间、工具和已保存的增删统计。汇总不修改原记录或数据库格式，只有一条记录时仍可直接删除单次记录。

页面明确记录范围：仅含文件工具保存的历史；终端和外部修改需使用工作区或分支比较。此修复不新增终端任意命令的历史采集，不能还原未保存的修改前内容。

前台 ON_RESUME 刷新会重建缓存，并暂时卸载文件详情。展开集合原先依赖 diff 对象，手动加载许可依赖缓存对象，重新读取后两者都会丢失。现在在文件详情层保存选择，按有长度边界的两侧内容 SHA-256 摘要区分比较；刷新、重新分词、切换文件及操作记录后返回均恢复同份内容的选择。内容真正变化则重新判断加载门槛，旧行索引不应用到新内容；硬上限始终生效。

通过可保存状态持有每份比较的加载许可和展开索引，不持有历史正文或分词对象。文件状态按对话、目录、环境、来源、分支基线隔离。

本地独立 JVM 编译与 25 项 Diff 专项测试通过，覆盖纯删除、替换、摘要边界、相同内容重新解析、多份比较隔离、状态序列化、规模策略及缓存。10 个修改的 Kotlin 文件经编译器 PSI 语法检查通过，9 份语言资源 XML 解析通过。高亮字段使用桩，未执行 Android UI 或存储测试。

Android 回归覆盖先删除后新增的默认汇总、删除文件及旧记录统计、删除行展示、保存恢复，以及真实审阅页暂停恢复和内容变化后的手动加载许可；设备运行结果待验收。
