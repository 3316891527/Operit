## 完成的功能

1. 子代理的 9 个工具共用一份协议定义并提供中英说明。中文目录和运行时说明选择中文，非中文选择英文；名称、参数身份、类型、必需状态和默认值一致。SystemToolPrompts 的中英文目录及注册描述使用同一入口。
2. 概览报告、任务简报、子会话和当前输出复用 MarkdownTextComposable。独立详情清除外层时间线渲染片段；型号、提示词名称和紧凑卡片摘要保持原有展示。
3. spawn_task 增加可选 fork_turns：none、all 或最近 1～64 个用户轮次，默认 none。只继承当前父轮次可用的用户输入、最终助手文字和总结；工具／思考与宿主事件排除。按请求边界发布不可变快照，父轮次在落盘前再次核验身份和开放状态。
4. 继承背景连同边界最多 200000 字符，超限或选择范围内无内容明确报错。背景 summary、子聊天、运行快照和新简报同事务写入；继续执行保留原背景，不从父对话重新取样。旧任务保留 none 和 20 分钟默认值，Room 版本仍为 30。
5. 全局并发 1～64、每聊天并发 1～全局、每执行时限 1～120 分钟；默认 6／3／20。配置页支持编辑、校验、取消和离页保存。并发修改影响后续调度，缩小限制不取消已有执行；时限在派发和继续时快照，排队不计时。工具目录、详情和超时提示显示实际值。
