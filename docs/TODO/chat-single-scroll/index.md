# 长聊天卡片的单层滚动渲染

现状：长回复采用气泡内部有高度边界的列表，形成两层滚动，改变阅读体验。
目标：聊天区域统一滚动，长回复的分组标题和内容块作为独立条目按需渲染，保持消息连续的外观及展开状态。
范围：聊天列表、Markdown 内容准备与条目渲染、消息外观分段、滚动跟随和历史定位。图片导出保留完整消息渲染入口。
分支：fix/single-scroll-chat-cards；原卡片分支和原组合分支保留。
验证：静态检查后派发 Android Build（assembleDebug）及 Android Tests；实机验证由维护者进行，不运行本地构建或测试。

步骤：
1. 移除回复内部的有边界列表，将 Markdown 准备与实际条目渲染分开。
2. 用标准 Compose LazyColumn 承载消息及内容块，保存分组和卡片的展开状态。
3. 适配连续气泡、流式跟随、历史定位与消息操作。
4. 推送测试分支并派发工作流，再建立含 PR #1278 的独立组合分支。
