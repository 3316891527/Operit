# 设计稿界面还原

本轮按用户实机截图与已评审 HTML 源码逐项修正外观，不扩展数据采集、查询、存储或计价规则。新文件和组件使用正常功能名称，不在界面或代码名称附加版本号。

## 明确差异与修正

- 原根容器受主题壁纸透明处理影响，卡片间透出背景；改为实际绘制设计稿的完整不透明背景
- 原页面继承应用粉色主色，并给趋势柱附加红绿涨跌；改为设计稿的灰黑层级、浅紫柱和青绿比较虚线
- 日期快捷项、对比、筛选收进同一双行控制区，时间粒度回到图表标题右侧下拉
- 总览费用主卡移至页签下，其他页不再重复费用大卡；整数与小数分层，并恢复四格指标
- 费用构成恢复环形图与图例，Token 恢复单条堆叠及四列明细
- 模型和请求列表使用同一面板内的分隔行；配置保留紧凑折叠头、不同层级展开区和底部操作
- 请求详情恢复固定头部和底部、滚动正文、四格 Token 及公式区域；定价字段校验保持原义
- 手机弹层全宽贴底；普通弹层仅上角 24dp 圆角、最高 92%，价格编辑上角 20dp、94% 高度
- 日期快捷项恢复双列及 9dp 行距，价格输入恢复双列与 47dp 高度，规则倍率恢复四列与 38dp 高度，开关使用 38×23dp
- 窄屏隐藏品牌副标与页签数量，保留图标空间；模型和请求金额右列最多占 44%，配置右列最多占 37%

之前确认的去掉本地估算、跟随全局明暗、下移设置及五秒清空确认继续保留。历史未记录字段仍明确未知，不以原型示例值填充；本轮不增加新的统计后端字段。提供商按实际字段展示，不将它标成没有采集的接口协议；子代理详情显示实际执行模型。运行质量中尚无周期汇总的四项保留“—”。

## 检查方式

对照 HTML 的 CSS 变量和手机宽度布局核对颜色、圆角、内外边距、字号、列表密度及组件顺序。静态检查包括 UTF-8、Kotlin 解析、资源引用/双语键、命名与源码范围。手机不执行编译和 JVM/设备测试；完成后对同一开发分支派发远端 assembleDebug 与测试，启动确认后停止查询进度。实际像素效果需使用对应 APK 的真实渲染确认，不将源码核对声称为已完成截图验收。

本轮 8 个新增或修改的 Kotlin 文件通过 UTF-8 与 tree-sitter 解析，两个新资源文件各 101 项，键集合与格式占位符一致，默认与英文资源无重复键，当前引用无缺失，差异空白检查通过。改动仅在统计界面、文字资源及本计划目录；采集、数据库、ViewModel、查询和计价生产文件没有改动。独立只读核对未发现新增的确定类型/API 阻断，此结论不替代远端编译。

源码实现与静态核对已完成。远端构建、回归结果与实机视觉效果仍分别等待确认。
