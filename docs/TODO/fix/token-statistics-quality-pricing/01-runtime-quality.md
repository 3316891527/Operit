# 运行质量与比率

总览统计整个当前筛选范围，包括日期、模型、配置、来源、状态、计价时段和搜索，不依赖请求列表的分页或排序。四项质量各有独立样本数，无最小门槛。没有有效样本显示破折号；有记录的零值不等同于未知。

- 平均首字延迟：单次非历史聚合请求的非负首字时间取算术平均；不要求已知完整耗时，已测量的失败、取消也计入。
- P95 完整耗时：单次非历史聚合请求的非负总耗时，按毫秒升序取第 `⌈0.95 × 样本数⌉` 项，不插值；不要求已知首字时间或成功状态。查询事务内用临时表保存每种毫秒值的频数，取消或结束均释放，不驻留整段历史。
- 已定价请求均费：仅采用既有计价器确认费用完整的用量事实，换算到总览目标币种；费用未知及仅部分已知不计入，已关联且已定价的实际零费用仍计入。完整定价的历史聚合按其中的请求数加权；被解除关联的配置所记零账目不是已定价样本。
- 成功请求平均 TPS：总览取各有效请求 `输出 Token 数 × 1000 ÷ (完整耗时毫秒 − 首字延迟毫秒)` 的算术平均，不是总输出除以总生成时间。仅接受 `SUCCESS`、单次非历史聚合、有用量事实、已知非负输出、已知非负首字延迟且完整耗时大于首字延迟的请求；不推测无首字的生成时间。详情调用同一公共函数 `tokenStatsOutputTokensPerSecond`。

缓存命中率仍为缓存读取 Token ÷ 三类输入 Token 总量。输入不全或分母为零不显示比率。成功率仍为成功数 ÷ 请求总数；无请求或有未记录、不可识别状态时不显示比率。无比率统一使用中性色。有比率时按原值分级：缓存 ≥90% 绿、≥50% 黄、其余红；成功 ≥95% 绿、≥70% 黄、其余红。百分比显示向下保留一位，避免舍入跨过色阶阈值。
