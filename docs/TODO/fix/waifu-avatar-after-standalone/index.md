# Waifu 独立内容后的正文头像

Waifu 会把图片等独立内容和普通正文拆成不同的显示块，正文气泡在独立块后重新开始。头像原本只分配给同一条消息的第一个回复片段，导致图片已经显示头像时，后面的文字气泡没有自己的头像。

仅在独立块之后遇到首个可显示的普通回复时补头像。保留独立块原有的头像、无气泡样式及尺寸；不改变普通模式、角色标题、消息首尾、正文分块或工具过程布局。

新增 3 项 Android 回归源码：图片后接正文各自显示头像、换行和长正文续片不占头像，以及流式正文在源关闭前获得自己的头像。用例使用真实时间线分块与头像行，不加载内容图片，不测量图片尺寸。尚未执行设备回归。
