# 子代理最终报告补写与产出保留

## 问题与范围

用户反馈的多个子任务结束在纯思考或工具结果之后，任务以缺少最终报告失败。服务层原本已有纯思考续写，因此不能仅凭警告文本断言没有重试，也不能从少量失败样本推导模型或程序的失败占比。本次修复子代理执行入口的收尾边界、报告期限和可核对的文件产出回传。

目标分支为 `dev`，工作分支为 `fix/subagent-final-report-recovery`。不改变主聊天模型或全局思考配置。

## 执行与报告边界

总期限内预留五分之一的时间用于报告，最多两分钟；默认二十分钟任务的工作窗口为十八分钟。报告阶段最多请求两轮，每轮不超过预留窗口的一半。工作阶段因内部窗口到期会先取消并等待工具结束，再进入报告；用户主动停止或父任务取消不触发新的模型请求。真正的执行异常仍按原错误结束。

服务层的子代理纯思考续写最多一次，之后由协调器补写最终报告，避免重复消耗相同思考设置。报告请求不提供原生工具定义或 XML 工具说明，实际工具执行入口也拒绝派发。收到带工具调用的报告响应视为没有报告，不能用紧随调用的结论冒充执行结果。

报告请求临时关闭允许关闭的思考；必须思考的模型只在已公布且可比较的选项中选择较短的档位。无法比较的自定义档位保留原选择，不猜测新的 ID。每次报告请求继续固定同一模型配置和型号。

工作输出、工具结果和报告请求分别持久化。新请求的流修订只作用于新请求，已保存输出作为固定前缀保留。被截止打断的思考按原 token 闭合；报告上下文去除思考和未配对的工具请求，将实际工具结果作为只读文本证据提供。跨请求用量由协调器累计，包含取消时已经收到的在途用量。工作收件箱在报告阶段关闭，未消费指令保留并在最终报告中说明。

## 文件产出证据

子代理的文件变化仍归根聊天展示。工具执行上下文新增可选的 `subagentExecutionId`，沿文件操作快照和终端事件传至文件记录，原有命令执行 ID 不变。

失败报告仅列出与本次执行 ID 一致的记录，避免混入根聊天、兄弟任务、旧执行或延迟保存的变化。同一路径按最终状态归并，创建后删除和修改后还原不算保留下来的新产出。无法唯一归属的并发记录不认领到任意子代理。

报告补写后仍无正文时，任务继续标记失败并保持可见，但将已记录文件产出一起送回主代理。文件存在不代表构建通过或全部目标完成；无法覆盖未经过记录链路的写入。旧记录的新字段默认为空，不根据时间戳反推历史归属。

## 工具参数与兼容

`spawn_task` 和 `followup_task` 新增可选 `execution_timeout_minutes`，范围为一到一百二十分钟；省略时使用全局配置。时限包含报告窗口。

`followup_task` 新增可选 `report_only`。上次因缺报告失败时默认只补报告，禁用工具并使用报告思考策略；显式传 `false` 可以恢复正常工作。旧任务的缺报告错误也能识别。其他失败或正常结束的任务继续沿用普通 followup。

两个思考字段同时省略仍沿用原设置。只要提供 `thinking_option_id`，即使档位不变，也要显式传 `enable_thinking=true`；工具定义和错误消息现在说明这两种用法。

新增任务快照字段提供默认值，已有任务、文件历史及备份继续可读。失败任务不自动归档。

## 验证

独立使用 Kotlin 2.0.21、JVM 17 和 JUnit 4.13.2 编译实际报告逻辑、协议解析、路径模型与执行来源，五类共三十三项测试通过。宿主共享存储根使用平台适配器；此验证不包含 Android 服务、真实模型 API 或设备 UI。

覆盖正常结束不额外请求、缺报告最多两轮、工作截止前等待取消完成、首轮报告超时后继续第二轮、主动停止不补写、执行异常不重跑、时间预算、参数边界、思考 token 闭合、工具结果作为证据、拒绝工具冒充报告，以及本次执行产出归属、删除、还原和来源合并。

新增思考策略和旧任务快照兼容回归交给 Android Tests。完整 Android 编译、运行中的服务取消以及真实模型在报告窗口内返回正文，仍需 Debug Build、CI 和设备验收。取得工作流启动信息后停止查询进度。

## 设备验收

- 用高思考档派发一个有明确文件产出的短任务，核对正常报告没有额外模型请求
- 用只返回思考的响应复现缺正文，核对最多两轮报告补写，且报告阶段工具调用数量不增加
- 将本次执行期限设为一分钟，派发持续工具任务，核对进入报告窗口时本次工具先停止，再基于已有记录交报告
- 补写过程中主动停止任务，核对不会继续请求模型，未消费补充指令仍可查看
- 同一根聊天同时执行两个写文件子任务，核对失败报告只列自己执行的产出；创建后删除的文件不列入保留产出
