# 提供商图标、对比入口与查询收尾

本轮基于 `b77cfcda` 的实机反馈，继续使用已还原的布局，只处理提供商图标、状态含义、对比入口和日期切换的重复查询。

## 图标与状态

总览排行、模型、配置中原有首字母方块改用应用现有的提供商 Logo 素材。模型聚合涉及多个提供商时，取该模型真实配置中请求数最多的一项；同量使用提供商与配置 ID 稳定排序。不从模型名称猜测提供商，没有素材或尚未加载时保留原尺寸空容器。

请求圆点现有映射已经满足反馈：成功为绿色，失败为红色，取消为黄色，历史状态未记录及已结束但成功未确认为灰色。保留两种未知状态的区别：空状态是历史没有记录；`COMPLETED` 是本轮确实记录到了结束，但没有成功确认。

费用的 `+ ?` 表示已知金额之外还有无法计价的贡献，可能因未定价或已定价分项缺少用量；Token 的 `+ ?` 表示已知数量之外还有缺失的数量。二者都不代表请求结果未知。本轮先核实并向用户说明，暂时保留显示方式，等待其选择。

## 对比入口

原入口已有回调，但全部时间时直接禁用。按钮改用原生 `IconButton`，由入口持有弹层状态并直接显示对比选项。全部时间时也能打开，提示先选择日期，并提供日期入口。有限日期继续支持不对比、上一周期、自定义等长起点，保留不重叠校验。补全原稿的不对比说明、对比起始日期和选择箭头。

增加两项 Compose 设备回归源码，覆盖触摸对比按钮后选择并应用上一周期，以及全部时间时转到日期选择。回归仅使用界面状态，不访问真实用户数据库。

## 查询优化范围

核对日期切换时的查询链路，消除总览与筛选目录条件相同的重复聚合；有限日期不再额外读取全范围边界。预算仅需要费用时使用费用汇总，同月且查询条件等值时复用本次结果。价格解析只在一次统计查询内按真实配置与模型复用，不建立全历史内存缓存，费用仍由现有计价器逐条计算。

本轮不更改数据库结构、采集来源、成功用量含义或价格规则。取消旧查询、清空代次保护及未知字段含义继续保留。性能收益仅说明减少的工作，不将源码推断表述为已实测的毫秒数或倍数。
