# 集中验收后的布局与图片选择调整

基于 #275 的 `056284ce0beda35c1799850852fc7ab1f29e80d1` 继续调整。用户确认 #262～#266、#271、#272 通过；#267、#269 需要长期任务观察，本轮不继续修改；#268 因正式版编辑器尚未更新而未测试；#273、#274 的功能整体通过，继续调整显示。#270、#275 仅作组合测试记录。

本轮让 Waifu 中的 emotion 与普通 Markdown 图片均靠左，显示角色名时将过程内容放到标题下方并连接正文。检查旧混合消息切换 Waifu 后过程被气泡包裹的问题，修正显示层分类，不拆写或重存历史消息。

图库的横向手势按指尖选取顺序提交。手势开始于未选图片时选择，开始于已选图片时取消；未松手回滑恢复本次区间外图片在手势前的状态。附件在复制之前排队，避免不同文件复制耗时改变顺序，同时保留草稿归属与图片内容判重。

## 验证

图库选择状态由确认按钮、复选框和指针手势共用。设备回归覆盖连续事件间尚未重组时的快速回滑，以及松手后立即反向取消。JVM 回归覆盖滑选方向、取消区间恢复、慢首项的附件顺序，以及排队期间切换会话、取消和失败。

Waifu 以可见片段确定角色名位置和气泡边界。回归覆盖名称开关、隐藏思考、流式正文接续、历史消息中的思考和独立图片，以及切换 Waifu 前后的原消息内容。用同一张本地图比较 emotion 图片、Markdown 图片和普通聊天中的位置与尺寸。

源码完成后执行本地静态检查，并在修复分支启动 Debug 构建和 Android Tests。实机验收用同一相册依次向左滑选、松手后从已选项取消、拖回缩小范围，然后确认输入框附件顺序。聊天界面验收包含角色名显示与隐藏、旧消息开关 Waifu 和两类图片的对齐。
