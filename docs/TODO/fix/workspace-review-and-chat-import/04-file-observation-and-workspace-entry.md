# 工作区文件观察与入口整理

现有操作历史仅包装指定文件工具，无法覆盖终端及外部修改；分支菜单直接枚举本地和远端缓存引用，按名称排列；绑定项目后仍保留早期网页预览和导出入口。文件浏览器首页会覆盖项目入口，Workspace 快捷入口固定到应用默认目录。

本轮继续使用 `fix/workspace-import-performance` 和 [PR #222](https://github.com/3316891527/Operit/pull/222)，目标分支为 `dev`。

## 文件观察

文件历史按绑定目录的实际状态变化采集。本地 Android 和 Linux 目录使用递归事件观察并在工具边界核对，定期检查元数据以恢复目录整体移动后的观察；SSH 和授权目录按绑定来源扫描。排除 `.git` 与历史存储自身，保留普通隐藏项目文件。符号链接保存目标文本，不递归读取链接目标。

首次观察建立基线，后续保留修改前后不可变快照。基线原子保存，重新进入时比较已保存基线和当前状态，不能恢复从未保存的历史。读取失败保留旧基线并显示错误，损坏基线不会被静默替换；清理操作记录时仍保留观察基线引用的内容。

工具作用域用于标注实际调用名，包括包工具全名。托管终端的来源覆盖真实命令生命周期，返回 runId 后继续保留，查询任务不会覆盖后台命令来源；观察归属随服务释放，运行中的终端任务仍持有自身观察。无法唯一归属时标记 `filesystem`，手动终端标记 `terminal`。文件工具的精确操作记录继续用于未绑定位置，并同步观察基线避免重复；两条采集链共用时间顺序和删除互斥锁。

事件短时合并后保存观察到的前后状态。应用未观察期间仅能恢复基线到当前状态的净变化，同一批次中修改后立即还原的中间内容不构成完整逐次写入日志。单侧原始快照继续限制为 2 MiB，超限文件保留不可展示内容的变更标识。首次观察需要与目录规模相应的读取和快照空间。

## 分支与工作区入口

分支只枚举现存引用，移除符号 HEAD；分支比较通过远端分支清单排除已删除的远端缓存，真实存在的本地分支即使 upstream 已删除仍然可选。按本地可用的分支最新提交时间倒序排列，同时间按名称稳定排序。查询失败明确报告错误，已删除的比较基线保留有效列表并提示重新选择，不自动替换所选基线。

移除绑定项目的固定网页预览页签、旧网页打包导出入口和对话切换、绑定、重命名及解绑中的自动网页服务管理。主动打开文件的图片、Markdown、HTML 预览及显式命令服务继续使用。解绑放在文件菜单的多选项下面，可用的重命名动作也放入同一菜单。

打开绑定项目时使用实际目录和环境，浏览首页设置不覆盖项目入口。编辑器返回保留浏览位置；重新请求打开工作区时回到绑定根目录。SDCard 旁的 Workspace 快捷入口指向当前绑定根目录和环境。

## 内置命令语言

`apply_patch`、`web-chat`、`build html` 的帮助编译自独立中英文资源。中文界面选择中文，其余界面统一英文。应用维护原子写入的语言文件，会话初始化导出位置，已有会话每次帮助读取最新应用语言。语言文件不可读时明确返回错误；独立运行的语言选择契约见 [终端命令说明](../../../../tools/terminal_commands/README.md)。共享 CI 的缓存输入包含语言模块和帮助资源。

## 项目入口清理后的编译修正

完整 CI 在应用 Kotlin 编译阶段发现五条错误，根因是保留的 HTML 文件预览仍访问已移除的项目预览处理器，以及旧命令弹窗仍访问已移除的状态订阅。HTML 文件预览现直接传递对话 ViewModel 的文件选择方法，继续通过既有 Activity 结果链路回传所选文件；删除已无入口的命令弹窗及专用组件和导入。后四条状态与类型错误随旧弹窗移除一并消除。
