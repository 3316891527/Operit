# 统一长按语音录制与录音期间常亮

基于本地气泡尺寸修复 `c0998bda` 继续开发。本项纳入聊天、主题和编辑器集成验收，构建及测试由同一集成分支发起。

经典与智能体输入区共用长按录音入口，短按不开始录音。长按后展示随主题变化的全屏渐变录音浮层；松手发送音频，滑入左侧取消区松手丢弃录音，滑入右侧转文字区松手转写并放入输入框编辑。已有发送钩子、原会话约束及录音文件所有权交接沿用现有实现。

用同一手势状态区分真实松手、指针取消和系统中断。切换会话、应用失去前台、返回和多指介入均取消。麦克风首次授权后需再次长按，手指已经松开时不自动开录。按住期间不因三秒静音结束，仍保留六十秒上限；达到上限后等用户松手再处理。

录音准备、录制和达到上限仍按住时临时开启常亮，结束、失败、取消或离开界面时恢复。录音中临时隐藏导航栏，在平台允许范围内设置手势排除区，并将取消和转写热区抬高到系统强制手势区上方。Android 普通应用无法彻底禁用 Home 和最近任务手势；系统打断录音时按取消处理。

实现细节、检查边界和设备验收项目见[实现记录](01-implementation.md)。设备反馈后的配置拒绝和侧滑排除修订见[录音验收修订](02-device-feedback.md)，后续视觉与触感见[中性深色与录音弧面反馈](03-surface-and-feedback.md)。
