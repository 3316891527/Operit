# 工作区修复

差异视图先检查输入规模，再决定自动准备、等待点击或拒绝加载。字符数与行数覆盖旧、新两侧，另设单行限制，禁止在后台预先准备需要确认的大型差异。长行使用适合屏幕的换行布局，避免生成超宽画布；大型文本不运行 TextMate 分词。

临时工作区进入后持续保留组合和编辑会话，关闭最后一个终端只在当前终端页返回主页。设置弹窗直接观察偏好状态。滑条绘制使用原生 SliderState 的吸附值，行距以 0.05 为步长。

压缩名称有显式后缀时原样使用；保持默认名称或与源文件同名时，补全所选格式后缀。预览名称与实际创建使用同一个函数。

自动展示范围是旧、新两侧合计 262144 字符、4000 行，单行 16384 字符；超过任一自动阈值显示加载按钮。硬上限是合计 4194304 字符、20000 行、单行 131072 字符，超过后不提供强制加载。原始快照每侧 2 MiB 的读取上限保持不变。

长逻辑行的展示切片最多 2048 个 UTF-16 单元，切点避开代理字符。差异比较使用现有依赖的线性空间 Myers 算法。

Blame 的未保存行映射与提交差异会直接准备内容，保留既有单行 8192 字符及两侧合计 20000 个换行符限制。单行预检、全文映射预检及提交差异共用独立的 Blame 检查，避免审阅页放宽手动加载上限时意外改变行归属查询的成本。原先拒绝 8193 字符行的失败用例保留，并补充恰好 8192 字符、两侧累计换行边界、二进制及与普通审阅规则独立的回归。
