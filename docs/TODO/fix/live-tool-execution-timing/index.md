# 工具执行中的实时耗时

工具开始和完成事件已经即时发布，但插话后缀与 Waifu 分段丢失计时状态，部分标题又把推进绑定到正文是否流式渲染。普通组内单项标题被隐藏，新调用没有记录时还会遮住整组时间，因此执行中显示不一致。

本次恢复工具开始后的实时计时。正文不变时秒数仍推进，后续工具继续追加；完成和取消后固定真实区间。并行组按执行区间并集统计，模型生成和用户确认等待不计入。

## 作用域

- 活动插话后缀和 Waifu 分段共享整轮计时，按全局调用位置映射段内编号
- 普通、时间线和 Waifu 标题共用刷新入口，展开工具组显示单项耗时
- 分段结构变化立即发布，普通长输出继续限制写入；纯计时不重写消息和数据库
- 页面加载恢复仍在执行的分段计时，按当前会话与页内消息匹配
- 截断作废调用保留位置，后续真实工具的计时不串给作废卡片

## 实现与验证

详细步骤见 [实时记录与呈现](01-live-timing.md)。新增的分段起点只属于运行态，定稿使用既有 sections 保存局部执行快照，不修改归档、Parcel 或数据库格式，不迁移真实用户数据。

新增 20 项回归源码，包括 18 项 JVM 和 2 项 Android；本地不运行项目编译、构建或测试。提交前检查 23 个 Kotlin 文件的 PSI 语法、严格 UTF-8、资源引用和差异空白，提交后执行仓库卫生、本地化与本轮文档链接检查。检查结果随交付回执记录。

推送后发起远端 assembleDebug 和 Android Tests，登记启动后停止轮询。仪器测试 APK 编译不等于设备执行，设备显示和原生分段的实际生命周期仍待验证。

## 验证边界

旧历史缺少计时记录时保持未知，不以零补齐。活动组允许显示已知执行区间；若定稿仍留有无记录调用，整组遵循原有严格未知规则，已知单卡快照保留。截断后的结果 FIFO 配对未在本次调整，调用位置修正只校正计时归属。
