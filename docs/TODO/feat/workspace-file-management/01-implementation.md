# 工作区文件管理实现记录

[返回计划](index.md)

## 目录浏览

原有选择页同时显示设置说明、创建模板、操作工具栏和快捷位置。现在将模板创建保留在工作区外层主页，选择页保留路径与快捷位置，文件页操作注册到页签右侧菜单。独立文件选择弹窗使用自己的菜单。菜单随页面显示状态注册、注销，终端保留原有选项。

路径栏显示来源并支持铅笔编辑。相对路径、父级段和 Linux 的 `~` 在当前来源内解析，失败显示实际读取错误。系统返回先处理弹窗或多选与过滤，再前往父目录，根目录交给已有页面导航。隐藏工作区不消费返回事件，也不显示文件弹窗。

收藏、浏览首页、点文件显示、手动隐藏规则和自动换行写入独立 DataStore。路径与来源一起保存，收藏不会改变对话绑定的工作区。隐藏只影响展示，目录规则包含子项；规则面板每行一个绝对路径，分别编辑各来源。授权目录的添加入口具有明确名称。

## 搜索

当前目录名称过滤与递归搜索分开。搜索默认递归且忽略大小写，名称支持普通文本、通配符和正则表达式，条件包含类型、大小、修改日期、隐藏项与逐行文本。先筛名称及元数据，再读取符合条件的文本。

本机使用 NIO 元数据与文件流，Linux 复用终端软挂载映射。授权目录按提供方查询真实元数据，单次搜索缓存已解析的文档 URI，避免每个子项重新从授权根定位。SSH 仍使用已连接来源的文件协议。

结果上限 500 项；内容上限每文件 8 MiB，支持 UTF-8、UTF-8 BOM 与带 BOM 的 UTF-16。二进制与超限内容单独计入跳过，无法读取单独计数。根目录无法读取时显示错误。目录链接不递归。停止保留已找到结果，离页取消任务，新搜索等待旧任务退出后复用来源缓存。内容结果打开文件并传递一基行号。

## 编辑器

新增不可变的显示行布局，将逻辑行拆为原文区间。显示行复用既有符号与单元格边界，不拆开代理对、组合字符和 emoji。行号仍使用原始逻辑行号，只在首个显示行绘制。

文字、搜索高亮、光标、选择区域、输入法组合下划线、触摸命中、方向键、选择手柄与菜单矩形共用显示行坐标。自动换行时关闭水平滚动，视口和缩放变化重新排版；底部符号栏提供持久化开关。排版不向文件插入换行，也不改变编辑历史。

## 文件操作与属性

目录复制改为单次枚举并复制，复用 256 KiB 缓冲与原有进度节流。总大小在目录完成前保持未知，单文件大小可提前确定。新目标仍拒绝覆盖，目录与文件的来源属性在复制中校验，遇到变化、失败或取消不报告完成。

批量粘贴先检查整批重名。Android 和本机 Linux 直接检查选中的目标，避免为少量文件枚举整个目标大目录；远程来源复用一次目录读取。执行各项前仍检查目标，本机同文件系统剪切使用 NIO 移动，其他来源沿用文件协议。跨来源剪切只有整项复制成功后才删除来源。

本机递归删除单次遍历，不跟随符号链接，遍历中检查取消。停止或失败保留已经完成的删除事实，并阻止开始后续项目。

属性统计复用面板首次读取的根节点，子项复用已校验父目录，减少重复权限检查和规范路径解析。目录链接不递归，无法读取和未知大小仍保持明确状态。

这些改动减少了遍历和协议调用，尚无设备性能基准，不声明固定提速比例。
