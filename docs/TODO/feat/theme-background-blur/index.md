# 全局及页面背景独立模糊

全局背景入口内的每个背景目标，在外观页增加独立的背景模糊滑块。覆盖共享全局背景及全部页面背景，按当前浅色或深色模式保存。范围为 0–30 dp，零表示关闭，与外层背景模糊的强度上限一致。

保留图层自身的模糊与两处现有渐变：图层渐变修改单个绘图层，部件渐变修改底色，两者可以叠加。此次只补背景目标的整体模糊设置。

通过可选的 Surface.backgroundBlur 字段保存背景整体模糊，默认零不导出新字段。仅允许全局和页面背景目标使用；延续现有主题模糊的 Android 12 要求。渲染使用共享装饰入口，作用于背景独立绘制容器，保持文字和控件清晰。工作室及工作台预览沿用同一渲染代码。

未设置独立背景的页面继续跟随源背景，模糊滑块暂不可用；添加独立背景后即可单独调整。这个字段本身不建立新的背景绘制，不能遮住原先继承的背景。

实施范围包括工作室入口、主题模型与校验、共享渲染、SDK 类型和协议说明。本项纳入统一集成验收，在同一提交上发起构建与测试。
