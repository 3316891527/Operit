# 数据与备份验收

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 从设置打开数据与备份 | 只显示合并后的入口和三个页签 |
| 2 | 检查概览并切换记忆配置 | 聊天、角色、记忆及关联数对应实际数据 |
| 3 | 切换三个页签并来回滚动 | 保留各页滚动、选择与任务状态 |
| 4 | 打开 Token 统计后返回 | 进入原统计页，返回原页签 |
| 5 | 导出快照并切换包含日志 | 使用所选日志选项，显示真实进度与输出路径 |
| 6 | 打开恢复后取消文件选择 | 不执行恢复，未选文件时确认按钮不可用 |
| 7 | 选择并确认恢复快照 | 提示覆盖数据，恢复成功后重启 |
| 8 | 调整每日备份开关和保留份数 | 设置持久保存，范围 1—100 |
| 9 | 立即备份并打开最近备份 | 显示最新记录和真实备份文件 |
| 10 | 从文件或最近记录恢复数据库 | 先确认覆盖，成功后提供重启 |
| 11 | 展开单项备份并导出所选聊天 | 原 JSON、Markdown、HTML、TXT、CSV 格式可用 |
| 12 | 导入聊天、角色卡和模型配置 | 原格式继续可读，模型密钥提示保留 |
| 13 | 导入导出记忆库 | 可选择配置及跳过、更新、创建新条目策略 |
| 14 | 打开备份文件与备份须知 | 统计、刷新和说明可用 |
| 15 | 展开角色卡与群聊统计 | 展示真实数量，失效关联可处理 |
| 16 | 搜索、全选、清除聊天选择 | 按标题、分组、角色筛选，选择数量准确 |
| 17 | 批量修改角色、角色群及分组关联 | 只更新明确选择的关联 |
| 18 | 构建记忆并限定时间范围 | 使用所选窗口与时间范围，运行时可取消 |
| 19 | 删除所选聊天或清空记录 | 二次确认，锁定聊天保留 |
| 20 | 选择并删除无绑定工作区 | 只删除选中文件夹，有绑定的工作区不显示 |
| 21 | 关闭日志写入后查看说明 | 只影响写入，原每日自动恢复策略保留 |
| 22 | 调整五项日志过滤后导出 | 保存原过滤设置，导出文件使用相应规则 |
| 23 | 清空日志并检查其他数据 | 二次确认，聊天及 Token 统计保留 |
| 24 | 切换深色、大字体及窄屏 | 卡片、抽屉和操作按钮可读可操作 |
| 25 | 经旧路由打开备份、聊天管理或日志 | 定位合并页对应页签 |
| 26 | 展开单项备份并查看模型配置下方 | 展开不崩溃，显示主题设置及导出、导入按钮 |
| 27 | 打开导出并切换分享码与主题文件 | 沿用底部抽屉，只有名称与作者可编辑，没有素材选择项 |
| 28 | 查看完整主题导出界面 | 只显示一条素材包含说明，没有演示状态或额外提醒 |
| 29 | 生成并复制中文名称的分享码 | 使用 zlib 压缩，复制完整单行链接，可从纯编码正文导入 |
| 30 | 导入分享码并进入预览后取消 | 颜色、字体、气泡与玻璃可预览，取消不修改配置 |
| 31 | 在分享码预览中选择有媒体的角色 | 预览使用该角色原有媒体，应用后媒体及专用调整保留 |
| 32 | 发送方或接收方使用文件字体，再分享普通参数 | 不携带文件字体选择，不关闭接收方已有文件字体 |
| 33 | 向导入框输入损坏码、截断码或未知版本 | 显示对应错误，不进入可应用状态 |
| 34 | 选择默认外观角色并应用 | 直接写入所选角色，无多余覆盖弹窗 |
| 35 | 选择已有主题的角色并点击应用 | 弹窗显示目标角色名，取消保留原主题，确认才覆盖 |
| 36 | 导入内置默认角色和非当前角色 | 写入所选 ID，不切换当前角色，不覆盖其他角色 |
| 37 | 预览后删除目标角色，再应用 | 拒绝应用并提示重新选择，不创建失效主题 |
| 38 | 导出含背景、双方气泡、头像和三类字体的主题包 | 导出 .oktheme，根目录配置完整，assets 自动编号且不含本地路径 |
| 39 | 将完整主题包导入另一个角色 | 素材复制到私有目录，预览与应用可用，角色标题保留 |
| 40 | 导出或导入含背景视频的完整主题 | 视频及透明度、模糊、静音和循环设置一起还原 |
| 41 | 导出无素材的完整主题包再导入 | 纯参数完整包可正常预览与应用 |
| 42 | 导入缺少 manifest.json 的 ZIP | 明确提示缺少配置，不修改主题 |
| 43 | 导入损坏、缺素材、空素材或新版本包 | 拒绝导入，不留下可应用的旧预览状态 |
| 44 | 导入越界路径、重复条目或超限包 | 拒绝导入，不写入缓存目录之外的位置 |
| 45 | 取消系统文件选择、保存或预览 | 不修改角色主题，释放本次临时素材 |
| 46 | 应用主题后重新进入设置并重启应用 | 角色主题及全局聊天布局持久保存，切换角色后主题范围正确 |
| 47 | 完整包替换已有素材后检查其他角色 | 只清理失去全部引用的旧文件，共用素材仍可显示 |
| 48 | 操作中重复点击或旋转设备 | 阻止重复任务，角色选择和已准备的导出继续有效 |
| 49 | 检查深色、大字体和窄屏下的主题抽屉 | 表单、角色列表、预览、底部按钮及覆盖确认可操作 |
| 50 | 检查文件快照标题及切换应用语言 | 新旧入口均不显示实验标记 |
| 51 | 打开主题设置并切换角色、页签 | 角色选择与下方页签、内容连续，头像与未保存确认可用 |
| 52 | 展开、收起单项导入导出并旋转屏幕 | ViewModel 正常创建和复用，主题导入导出入口可打开 |
| 53 | 展开单项列表并对比五种导入导出入口 | 主题行与其他行使用相同图标大小、字号、间距和按钮，无独立图标色块或竖线 |
| 54 | 在浅色、深色、大字体和键盘弹出时编辑主题名称、作者及分享码 | 圆角浅底表单、选中方式和底部主次按钮清楚可读，滚动可操作 |
| 55 | 生成分享码并滚动、选取、复制后重新导入 | 代码区显示真实字符数，复制完整正文，校验结果与原主题一致 |
| 56 | 打开角色选择、搜索、选中、返回及旋转屏幕 | 列表有头像和选中标记，返回保留主题预览，未选择时不可应用 |
| 57 | 对比导入预览并尝试默认与自定义主题角色 | 显示紧凑聊天示例，全局布局标识保留，覆盖确认与既有行为一致 |
