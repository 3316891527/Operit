# 实现记录与设备验收

## 输入与录制

经典输入区、智能体输入区的透明和非透明分支共用长按手势。保留多行输入框和既有发送、排队、停止按钮分支，语音入口短按不开始录制。长按成立后震动，继续持有原按钮的指针；浮层使用非焦点 Popup，录音显示计时与波形。

手势先在 Main 阶段等待长按，成立后才消费指针，避免预先消费首次按下导致长按检测取消。滑动超过 48dp 后按屏幕坐标判断左侧取消、右侧转文字热区，移回中央恢复发送语音；只有真实松手可以消费一次提交动作。热区未布局、系统取消、多指介入及旧录音编号的回调均不能触发新录音发送。

首次麦克风授权后提示再次长按。无当前聊天时先创建会话，等待期间松手、返回、失焦或退后台会结束手势；新会话到达时重新校验输入处理状态。发送固定原会话并沿用既有提交钩子和持久化后的文件所有权交接，异步关闭回调按录音编号隔离。

按住录音时关闭三秒静音自动结束，仍检查实际人声并保留六十秒上限。达到上限先完成文件，等待松手选择发送、取消或转写。右侧动作调用既有 STT，结果回填原会话空输入框供编辑；失败保留当前浮层供重试或取消。

## 显示与窗口

浅色主题使用白色渐变，深色主题使用黑色渐变。取消和转文字热区位于底部安全区上方，保留无障碍动作语义。旧点击录音底部面板及内容组件已移除，新文案覆盖仓库现有九种语言。

录音准备、录制以及达到上限仍按住时临时持有常亮，结束或离开时恢复原值。录音中临时隐藏导航栏，结束时恢复此前可见性和系统栏行为；热区请求系统允许的手势排除范围。Android 强制保留的 Home 和最近任务手势仍由系统处理，中断路径统一取消录音。

## 检查记录

统一集成验收中，最终十五项生产手势状态机 JUnit 回归全部通过，覆盖热区未布局、旧热区回调、系统中断、一次性交接和再次录制。

此前十一份 Kotlin 文件语法和九种语言 XML、本地化检查通过。最终修订的静态检查结果见[计划总览](index.md)。语法解析不验证 Compose 类型或运行时行为。

集成验收已重新执行生产手势的独立 Kotlin 编译与 JUnit，完整 Android 构建和测试由仓库工作流执行。以下设备验收仍待确认：

- 浅色与深色主题、窄屏、大字体和横屏的显示及触摸位置
