# 分卷快照与 Waifu 气泡对齐

本轮从 PR #252 的 230e206a 继续，修复过程之后的正文上 4 dp、下 12 dp 内边距不一致，以及隐藏角色名后头像和续行占位撑高首段的问题。过程与正文的距离仍由外部时间线控制，普通文本气泡恢复上下 12 dp，短思考与续行的行高只由右侧内容决定。

对象存储采用约 1 MiB 的追加分卷，保留 SHA-256 内容身份和全局去重。操作 JSON、观察基线和终端索引继续引用同一哈希。新对象写入有版本和长度校验的卷记录，SQLite 位置库按页读取并最多缓存 256 个位置。完整内容与新目录项先同步落盘，再用一笔事务发布卷和首个位置，恢复时只截去未提交的尾部。大于卷目标的合法对象单独封卷，单对象仍遵守既有 2 MiB 限制。

旧版独立对象采用显式、可中断的分批迁移：每个对象经摘要校验、提交新位置和回读确认后才删除原文件。索引与内容目录分开存放，删除 objects 仍表示内容已清理；部分卷删除只影响相关对象，后续写入使用新卷。沿用操作、其他对话、工作区与终端基线的引用检查，标记删除后后台进行单轮约 4 MiB 的有限压缩。

格式、提交恢复、版本归属与迁移边界见 [格式与生命周期](format.md)，性能数据与限制见 [临时目录测量](measurement.md)。
