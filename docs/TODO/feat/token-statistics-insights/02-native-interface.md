# 原生界面与来源

页面入口保持 TokenUsageStatisticsScreen，路由级 ViewModel 保留状态。基于已评审 V2 实现总览、模型、配置、请求四页，统一周期与多选筛选。日期使用快捷按钮和日历选择，取消双拖动时间轴。

总览保留费用、Token、请求、构成、结果、用途、执行模型、峰谷、预算和趋势。当前柱形与比较虚线按相同桶覆盖呈现，点击时段进入请求。模型/配置支持搜索与排序，展开进入价格或请求；已删除配置根据真实列表隐藏明细但保留总量。

设置入口在概览下方右侧，左侧为清空全部用量。确认等待真实五秒后解锁，取消始终可用。页面跟随应用主题，没有独立主题按钮和本地估算标记。配置价格编辑继续复用已有完整对话框，保留币种、按次、四类单价、高峰和长上下文。

真实来源通过协程上下文传递，在限流包装器的冷流边界捕获并恢复。子代理只按已锁定执行模型分类，思考/正文/工具不拆请求。Memory embedding 的独立 HTTP 路径不经过本轮 Tracking，不展示虚构请求。探测连接的 recordTokenUsage=false 继续排除记账并保留取消保护。

CSV 使用系统文件保存器，导出当前筛选内逐次请求，标记未知费用与原始状态，保留 BOM、RFC4180 引号和公式前缀转义。
