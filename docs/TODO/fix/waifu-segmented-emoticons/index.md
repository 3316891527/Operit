# Waifu 分段发送显示表情包

Waifu 已引导模型输出 `<emotion>分类</emotion>`，但可修订快照和只追加的分段入口都会在分句前过滤该标签。两个入口现在将完整指令交给同一个分段处理，不必等整条回复结束。

每轮读取当前角色卡或角色组的自定义表情目录，只使用仍然存在的文件。正文、独立 Markdown 图片和后续正文按原顺序入队。同一分类的同次出现在快照重算和定稿时复用选图；可修订流仍会撤回被回滚的分段。

关闭表情、缺少素材或标签未闭合时不发图。代码与转义示例不触发表情指令；表情图不让朗读把分类名当作正文。本次不改普通聊天、头像分配、图片大小或历史数据格式。

## 验证

JVM 回归源码覆盖标签语法、无素材、快照投影以及重复重算时的选图。Android 回归源码通过原生分块器覆盖跨块标签、上游未关闭时的发布、正文与图片的顺序、回滚和定稿、字面示例及普通图片。

本地仅做静态检查。远端运行 JVM 回归并编译、打包设备测试；仍需在设备上打开自定义表情和分段发送，确认表情在回复尚未结束时可见。
