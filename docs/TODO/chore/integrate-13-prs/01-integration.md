## 统一测试入口

构建时选择本分支，使用 `assembleDebug`。成功后在 Build 工作流产物 `operit-android-运行编号` 中下载 APK；Android Tests 的产物为 `operit-android-test-reports-运行编号`。工作流启动受理与入口由交付记录提供，受理不代表构建或测试通过。
