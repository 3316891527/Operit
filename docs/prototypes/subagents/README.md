# 子代理交互原型

打开 [HTML 页面](index.html) 即可体验，也可以单独保存这个文件，用现代浏览器离线打开。样式、图标和脚本均已内嵌，不需要安装依赖、启动服务或配置模型。

页面使用预设演示数据，刷新会清空本次任务与角色调整。页面内的“重置”保留当前主题和角色设置，清空任务记录。它没有连接 Operit 的实际聊天、模型、工具或数据库。

## 建议的体验顺序

1. 在主聊天点击“开始协作演示”，观察两项运行、另一项排队
2. 点开一张任务卡，在“概览与结果”“执行过程”“子会话”之间切换
3. 点击“补充指令”，发送一个要求，再看它从“等待下一轮读取”变为“已读取”
4. 停止单项任务，观察其它任务继续、排队任务取得名额
5. 在“演示控制”里完成待执行任务，然后点击“让主代理汇总”
6. 给已完成的子代理安排后续工作，查看原报告和新执行怎样同时保留

手机上详情以底部面板打开，宽屏与主聊天并列。详情中的任务选择器可以切换兄弟任务；关闭面板回到原任务卡。导航中的“子代理任务”提供搜索、筛选和归档，“角色与模型”可以调整演示角色与之后分派任务的模型。

## 交互含义

“暂停演示”冻结计时播放，便于阅读；“停止这一项”结束选中任务的当前执行。两者会显示不同的状态。手动“推进一步”会停止自动播放，并推进一次模拟执行。

子代理运行时可以接收补充，消息先排队，在下一轮读取。已完成的子代理通过“继续此任务”接收后续工作，沿用子会话并开始新执行。主聊天已汇总的报告保存快照，不会随着新执行被改写。

报告完成后显示“已送回”，主代理汇总后显示“已汇总”。本原型使用明确的汇总按钮；正式产品可以在确认唤醒策略后讨论自动汇总。原型中主聊天的补充会广播给进行中的演示任务，这只是用于体验的固定规则。

## 演示控制与范围

主聊天输入栏下方的“演示控制”可以暂停、单步推进、完成所有待执行任务，或模拟单项失败、应用中断。中断后，从任务详情选择“继续执行”。未读取的补充仍保留在该任务的演示信箱中。

- 初始并发数为 2，仅用于展示运行和排队的关系
- 角色、模型、工具次数、耗时、阶段和报告全部是演示内容
- 新建任务也使用预设阶段，不会真的阅读或修改文件
- 模拟中断只改变当前页面内存状态，刷新不恢复历史
- 页面不会发起 API 请求；下载 Markdown 由浏览器在本机生成

本轮交付只包括原型与研究记录。正式子代理的运行时、权限、持久化、资源隔离和原生 UI 需要在交互方向确定后另外设计。
