# 对话图片保存与预览修复

## 原问题

- 多选消息后的入口称为“分享”，实际主要用途是生成并保存对话图片。
- 离屏 ComposeView 按系统深浅色建立默认主题，丢失当前聊天的配色与字体。
- 缩放手势绑定在变换后的图片上，放大时拖拽位移随局部坐标缩小。

## 修改范围

- 入口、图标、预览标题及主按钮统一为“保存图片”，复用已有多语言资源；系统图片分享保留为次要操作。
- 将当前 MaterialTheme 配色、Typography、Shapes、主题偏好和深浅色传入图片生成器；纯色背景使用当前主题底色。
- 在固定预览区域检测手势，复用已有图片变换函数，按图片的适配尺寸计算拖拽边界。
- 预览主题或选项变化、对话框关闭时取消旧生成任务；取消时清理离屏视图与 composition。

## 验收路径

1. 系统浅色、应用深色及反向组合下保存图片，检查文字、卡片、边框和背景。
2. 自定义强调色、字体、角色卡主题及包含背景开关，确认预览与保存使用同一图片。
3. 长图放大后单指连续拖动，确认位移跟随手指、可查看顶部和底部；缩小回适配比例后回正。
4. 缩放中旋转窗口，或连续修改预览选项，确认图片位置与最新预览状态正确。
5. 保存至相册，并确认系统分享仍发送图片。
