# 只记录当前对话绑定的工作区

+29 的全局终端观察仍覆盖 Linux 根目录和共享存储挂载点；文件写入与后台扫描、网络操作共用锁，创建文件和短命令仍会长时间等待。本轮按明确需求缩减记录范围。

## 行为与实现

- 只有对话明确绑定的工作区才启动观察；不从终端 cwd 或工具目标自动推导绑定
- 未绑定时文件工具和终端直接执行，不创建观察任务、不打开历史存储、不扫描或采集快照
- 已绑定时只采集目录内变化；祖先目录操作裁剪到工作区交集，无关目录操作直接执行
- 删除全局终端观察根，终端只给唯一工作区观察器提供执行来源；命令完成事件不等待历史采集
- 解绑和切换对话取消旧任务并释放索引，同目录重绑先完成资源交接；在途写入和迟到命令按绑定身份校验
- 后台目录枚举、文件读取、差异计算及旧基线流式导入不持有共享操作锁；发布历史按页推进
- 写入按物理目标路径协调，无关下载、复制、解压互不排队；失效路径防止旧扫描覆盖新快照，临时快照租约防止历史清理删除在途内容
- 本机目录链接限制在绑定目录内；本地观察不跟随目录链接，远端按文件后端的逻辑目录边界采集

## 兼容与数据

保持工具参数和结果、包名、签名及旧操作历史查询。保留原数据，不清理真实历史，不再启动旧快照对象的全库后台迁移；旧内容继续按需读取。只在绑定对应目录时导入该目录的旧基线，成功后沿用既有迁移规则。此前旧操作 JSON 成功迁入新表后，旧 APK 无法读取对应记录的限制仍存在。

## 验证范围

JVM 回归源码覆盖空绑定、目录前缀、祖先交集、共享存储别名、不同后端、目标锁独立性、取消释放、旧扫描覆盖和在途快照租约。设备回归源码覆盖 12 类写入口在未绑定及目录外的同步和流式直通、暂停扫描时真实创建和编辑、终端退出时只记录绑定目录、解绑及同目录快速重绑。

设备用例使用隔离临时目录，未在手机编译或执行。远端 JVM、仪器测试编译和 Debug 构建的最终结果另行登记；静态审阅与源码解析不能代表编译或行为测试通过。

## 基线内容同步回归

远端 JVM 用例发现直接通过 Scan.put 放入的快照引用未登记租约，导致没有显式 pinBlob 的缓存行绕过内容同步检查。基线入口现在为每条含 blob 的记录登记引用，覆盖旧快照复用和旧基线导入；同步仍在基线锁外完成，失败保留本页供重试，不能发布文件或初始化标记。空扫描和仅元数据的扫描继续跳过内容锁。

保留 baselineCannotPublishBeforeContentSyncAndInitializationFlagSurvivesReopen 的失败断言，并核对同步哈希、失败后的初始化状态和重开后的引用；补充跨 128 条分页的引用保护、取消释放及无内容扫描不触发同步的回归源码。锁顺序用例改为经 put 登记引用。这些用例交由远端 JVM 回归执行。
