# 工作区交互与聊天导入内存优化

现有差异视图把单行超过 8192 字符当作整页错误；临时工作区离开页面就释放；压缩名称统一追加后缀。编辑器设置从导航栏提供的组合回调打开，滑条轨道与原生步进值分别计算。聊天 JSON 虽按会话读取，每个会话仍经过完整 JSON 树和字符串中转，保存时整批生成实体。

文件历史还缺少终端和外部修改，分支列表会保留已删除的远端缓存，绑定入口与浏览首页存在冲突。本轮补齐实际文件观察、工作区入口整理和内置命令帮助语言，同时保持既有偏好和聊天备份格式兼容，目标分支为 `dev`。

- [工作区修复](01-workspace.md)：分级加载、临时目录与文件保留、压缩名称和编辑器设置
- [聊天导入优化](02-chat-import.md)：消息级读取、有限批次保存和单会话原子替换
- [记录汇总与展开保留](03-review-history-and-expansion.md)：默认比较已记录历史，区分单次操作与整个提交，按比较内容保留展开和加载选择
- [文件观察与入口整理](04-file-observation-and-workspace-entry.md)：采集实际文件变化、分支整理、移除项目网页入口、修正绑定导航和命令帮助语言
- 验证：针对边界、兼容性及失败回滚补充回归用例，推送后发起 Debug 构建与 Android Tests
