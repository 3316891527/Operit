# 原生状态过渡与点击涟漪

按视觉扩展清单继续推进渐变后的交互能力，范围为已共用交互状态的按钮、图标按钮、独立动作按钮和导航项。

- 新增可选 `transition.durationMillis`，范围 0–1000 毫秒。默认不开启动画，显式声明后插值透明度、边框宽度和已有明确默认颜色的填色、正文色、描边色
- 同一部件的原生容器、正文及装饰共用一份动画结果。初次显示与主题、角色、明暗模式变化不做入场过渡；原生动画遵循系统时长设置，不逐帧运行 JS
- 新增可选 `ripple.enabled/color`，通过 Material3 的原生涟漪配置生效，保留现有点击、禁用、交互源和无障碍语义
- 工作室状态页用开关和时长滑条编辑，明暗模式、模式覆盖、草稿和主题归档沿用共享模型；SDK、示例、校验和回归同步更新

渐变和素材之间切换仍按原有状态直接替换，本批不承诺它们之间可插值。原生继承色没有被编造为透明色。未使用扩展的旧主题导出不增加字段。
