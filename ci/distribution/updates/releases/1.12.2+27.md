# Operit Kong 1.12.2+27

本次更新加入原生子代理协作，完善工作区变更追踪、终端执行和大聊天导入，并改进 Markdown、主题及编辑器体验。

## 子代理协作

- 支持由主代理创建独立子任务，分别选择提示词预设、模型与思考设置；子任务拥有持久会话、执行状态和报告，主聊天保持当前模型。
- 支持多层具名代理树、同一会话树内的消息通信，以及等待任务或消息时释放并发名额。可配置并发、执行时限和最大深度。
- 提供任务托盘、管理列表与详情窗口，可查看执行过程、补充要求、停止、继续、归档和恢复任务；停止与归档操作覆盖相应子树。
- JSON 聊天备份支持完整子代理会话图，包含子会话、消息、报告与任务关系。恢复或导入时，未完成执行会标记为中断，不自动重复外部操作。
- 优化子代理详情：固定窗口高度，正文与长工具输出在内部滚动；工具调用与结果使用紧凑卡片，支持参数、输出切换和完整复制，提前显示代理工具的真实名称。
- 修复未闭合工具内容可能被误当作最终报告的问题，并加强原文引用、测量口径及报告差异核对要求。

## 工作区、终端与工具

- 完善文件变化记录、变更审阅及文件导航；终端产生的文件变化可以被记录和定位，多层子代理操作统一归属根会话工作区。
- 改进未绑定工作区时的终端文件变化采集，以及文件操作、终端来源与工作区观察之间的联动。
- Shell 工具使用独立执行环境，完善超时、取消和收尾处理，减少命令卡住或影响后续执行的问题。
- 编辑器扩展通过宿主命令打开和编辑文件，统一编辑器工具与应用工作区行为。
- 网页访问明确返回超时和访问受限信息；修复浮动浏览器打开时的递归问题。

## 聊天与界面

- 大型 JSON 聊天记录按消息流式导入，分批写入并保留事务与取消处理，减少导入期间的内存占用；兼容完整子代理会话图。
- 扩展 Markdown 展示能力，Mermaid 使用原生 Canvas 渲染，改进图表预览体验。
- 稳定工具组的展开状态与剩余调用计数，减少执行过程中的状态闪动。
- 支持自定义聊天输入框占位文字，并改进主题、录音交互、编辑器滚动及玻璃效果预览。
- 同步相关上游修复，完善工具调用上下文、资源和界面联动。
