# build html 命令

在 Operit 内置 Ubuntu 终端中使用 `build html`，将已经准备好的静态 HTML 项目打包成 Android APK 或 Windows 应用。命令随应用安装并在终端初始化时更新，打包模板从应用的离线资源中安装。它直接复用应用现有的 Android 打包签名和 Windows 模板能力。

独立的 HTML 打包页面和工作台入口已移除。聊天内容原有的 Android、Windows 导出弹窗继续使用。工作台只展示工作区操作、实际对话产出，以及终端和浏览器会话。

## 常用命令

```bash
build html ./web --target apk --output ./dist --name Demo
build html ./web --target exe --output ./dist --name Demo --icon ./icon.png
```

在项目根目录执行时，也可以使用默认参数：

```bash
build html .
build --help
build --version
```

输入为项目目录。路径包含空格时按 shell 规则加引号。默认入口是项目内的 `index.html`，默认目标是 `apk`，默认输出目录是当前终端目录下的 `./dist`，默认应用名为项目目录名。输出目录可位于项目内部，扫描时会明确排除该目录；输入与输出不能是同一目录，入口也不能位于输出目录内。

这是静态网页打包命令。使用 Vite、React 等工程时，先生成网页资源，再将生成的 HTML 目录作为输入。命令不会安装 npm 依赖或编译前端工程。项目内除指定输出目录外的普通文件都会被打包，包括隐藏文件。

## 参数

- `--target apk|android|exe|windows`：`android` 等同 `apk`，`windows` 等同 `exe`
- `--output PATH`：成品目录，默认 `./dist`
- `--entry PATH`：相对项目目录的 HTML 入口，默认 `index.html`，支持嵌套路径
- `--name NAME`：应用名称及成品名称，默认项目目录名
- `--package ID`：Android 包名，默认 `com.operit.webapp`
- `--version-name VERSION`：Android 版本名称，默认 `1.0`
- `--version-code NUMBER`：Android 正整数版本号，范围 `1` 至 `2147483647`，默认 `1`
- `--icon PATH`：自定义图标，内容由对应平台的现有图标引擎处理

未知选项、重复选项、缺值、多个输入目录和不合法版本号会直接返回参数错误。应用名必须能作为单个文件名，Windows 目标额外拒绝 `CON` 等设备保留名。Android 包名和版本字段也会校验。

指定其他入口时，构建副本中的根 `index.html` 会成为跳转页，进入指定 HTML；其他资源仍按原目录保留。项目原文件不变。

## 进度与成品

命令会立即显示准备状态，随后持续输出接收文件、校验模板、写入应用信息、图标处理、打包、签名及成品传输等实际阶段。日志包含累计耗时和阶段比例，长阶段每两秒输出当前状态与已用时间，直到该阶段结束。比例表示阶段进度，不表示预计剩余时间。

Android 输出为 `输出目录/应用名.apk`。Windows 输出为 `输出目录/应用名/`，其中包含同名 EXE、DLL 和 `data` 等运行文件，分发时必须保留整个目录。

成品先在输出目录中的临时目录接收，只有成功结果和完整文件清单到齐后才原子发布。同名成品已存在时返回失败，不会覆盖；构建失败或传输中断会清理临时成品。退出码 `0` 表示成功，`1` 表示构建、传输或发布失败，`2` 表示命令参数错误。

## 环境与限制

使用前在应用的离线资源中安装 Android 或 Windows 导出模板。缺少模板时命令直接报告目标与安装入口。命令需要当前 Android 应用的本地构建服务，因此应从 Operit 内置 Ubuntu 终端运行，不支持远程 SSH 主机或独立电脑直接执行。

项目最多 `20000` 个文件、总计 `2 GiB`、项目及成品相对路径最多 `64` 层，Windows 运行目录前缀也计入成品路径。文件名使用 UTF-8，相对路径长度最多 `2048` 字节；拒绝符号链接、设备文件和越界路径。图标为非空普通文件，最大 `16 MiB`。成品传输也限制为 `20000` 个文件及 `2 GiB`，目录帧最多 `20000` 个。

传输使用 120 秒读写超时，正常构建期间的进度消息会持续刷新读取状态。构建任务在应用内排队串行处理；等待期间仍有状态日志。应用进程退出或通道断开时命令失败，需要重新打开终端后重试。
