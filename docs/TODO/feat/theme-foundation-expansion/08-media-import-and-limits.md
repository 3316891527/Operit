# JPG/JPEG 资源与精简限制提示

原实现的导入、解码与外观协议已经包含 JPG/JPEG。本轮统一格式定义，显式列出两种扩展名，覆盖大写扩展名。名称合法性与格式校验分开，避免路径问题被误报成格式不支持；不自动重命名或改变路径协议。

顶部原有红色错误栏及关闭方式保持不变。资源超限采用原英文原因加 `(含本次导入的总占用/总预算)`；不再显示文件名、原有占用、本次新增、合计或工程概况等额外字段。像素、字节和数量各自按原预算计算，例如原有 40,000,000 像素加新增 2,000,000 像素，显示 `Theme drawing assets exceed the decoded pixel budget (42,000,000/41,943,040)`。

操作失败时，复用现有底部 OKToast 提示一句本地化原因，例如“主题图片解码后的总像素超过限制”或“主题资源文件超过大小限制”。Toast 不包含用量、总预算、文件名或技术明细；预览重新求值不触发重复 Toast。

文件大小使用 MiB/KiB 简写。接近限制时若格式化会让两个不同的数值看起来相等，则显示精确字节数。受限读取无法得知完整大小时，左侧使用 `≥` 标记已观察到的下界，不把截断数据当作完整文件大小。

限额保持原值：单资源及单字体 8 MiB、SVG 512 KiB、源码及清单各 64 KiB、外观结果 128 KiB、源码与素材合计 64 MiB、资源 48 项、位图解码总计 41,943,040 像素。字体不计入位图像素预算。脚本内部资源 ZIP 文件仍限制 64 MiB 加 128 KiB、50 条目。整批导入全部校验成功后才写入工程。

验证状态：实际主题协议与资源存储源码通过独立 Kotlin 2.2.21 编译，41 项 JUnit 全部通过，其中本次新增 8 项精简提示回归，包含用户给出的 40,000,000 加 2,000,000 像素场景、工程总大小、单字体大小、单字节边界和未知完整大小。该独立编译不等于完整应用编译。

8 个 Kotlin 文件中 7 个无语法诊断，状态类的既有解析器限制与基准一致，更新后的报告错误及导入方法单独解析无诊断。10 项双语 Toast 提示均不含数字、预算分隔符或插值字段；XML、资源引用、删除旧明细资源和补丁格式检查通过，顶部原有错误栏源码保持不变。
