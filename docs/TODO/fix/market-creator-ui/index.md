# 创作者中心登录状态与布局修正

原界面在未登录时重复显示红色登录提示、条目统计和上次加载的通知数量；发布入口没有锁定样式。账号区和发布区固定占据屏幕，条目列表只有较小的独立滚动区域；流程连接线短而不明显，发布新版本显示为文字操作。

本次调整仅涉及创作者中心、市场管理共用组件和对应的列表/通知请求生命周期。市场协议维持已删除状态，发布、审核、撤回及编辑回调沿用现有流程。

## 已实现

- 未登录只显示账号登录引导和三个淡灰色发布卡片；卡片右侧显示锁并禁用点击
- 统计、通知数量、筛选和发布记录只在账号已登录且用户信息可用时显示
- 退出或切换账号时取消列表和通知请求，清空旧数据，避免迟到响应重新写入
- 三个发布卡片使用 16dp 圆角和 12dp 间隔；“需修改”仅强调数字颜色，不使用独立外框
- “全部 / 脚本 / 插件”使用较小字号、内边距和胶囊圆角，位于“我的发布”标题下
- 账号、发布、筛选、空状态、条目使用同一个 LazyColumn，整页滚动
- 提交、审核、发布三步各有节点和连接线，线段按可用宽度伸展，颜色随真实审核/上架状态变化
- 发布新版本使用圆角描边按钮；操作区支持换行，长标题和类型标记分行排列

## 验证

提交前检查 Kotlin 语法、资源 XML、缺失字符串引用、图标覆盖和差异格式。Android 编译、单元测试和 APK 构建在 PR 对应提交的 GitHub Actions 上运行。

## 手工验收路径

1. 未登录进入市场“我的”：没有红色卡片、数量或旧记录；发布卡片淡灰、显示锁，点击无动作
2. 登录：显示真实账号统计、紧凑筛选和发布记录，三个发布卡片分别进入现有发布页面
3. 滚动整页：账号和发布入口可以随列表滚出屏幕；空分类仍可切换筛选
4. 检查待审核、已通过、需修改、已撤回条目：三步流程的状态和连接线正确；版本发布仍走原回调
5. 在请求加载期间退出登录并重新进入：旧条目和通知数不再出现
