# 输入文本区域占位符

原来的聊天占位提示由原生输入框固定提供，主题工作室不能修改或隐藏。

在主题工作室的“输入文本区域”外观面板增加占位文本编辑，沿用当前浅深色模式的区域保存、预览和撤销流程。主题的 `surfaces.input.placeholder` 为可选字符串：未声明或 `null` 使用原有提示，空字符串明确隐藏提示，其余字符串原样显示。清空输入不触发无效值校验，也不删除该字段。

范围包括主题协议、工作室编辑、智能体与经典聊天输入框，以及中英文界面字符串。旧主题无需迁移，未设置占位符的主题导出时省略新增字段。

验收覆盖未设置、自定义、空字符串、浅深色独立配置和导出导入；保持工作区模式的默认提示。完成后单独提交 PR，并发起 Debug 构建和 Android Tests。

状态：实现完成。新增五项协议回归，覆盖旧主题默认值、空字符串、中文和空白文本、浅深色独立设置及区域约束。工作室选中输入区域时使用空输入预览，直接呈现占位符。验证记录随提交检查和 CI 派发补充。
