# 临时调试执行清理

旧 ScriptExecutionReceiver 在执行块内创建临时 JsEngine，但 finally 只清理临时文件，没有调用 destroy；准备参数或脚本时提前返回的部分路径也没有进入文件清理。

让整个请求准备、执行、结果落盘过程处于同一清理边界，记录本次实际创建的引擎。在 finally 中销毁它；销毁异常单独记录，不覆盖已生成的结果，也不阻断后续临时脚本、参数文件和环境文件清理。解析失败等未创建引擎的出口只清理本次声明的临时文件。

设备回归覆盖准备失败、正常结束、脚本错误、结果落盘失败与短周期计时器资源退出。此处修改的是未来调试执行的资源生命周期，不会在当前进程里盲目停止其他脚本或修改聊天记录。
