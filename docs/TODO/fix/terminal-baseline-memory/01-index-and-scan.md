# 磁盘索引与流式扫描

生产代码不再提供整份终端文件映射。TerminalObservationIndex 按观察根保存 SQLite 文件，正式基线、扫描暂存代次、不可读子树、启动期间覆盖路径和在途快照租约均落在磁盘。

文件查询使用每根最多 256 条的 LRU 缓存。扫描写入和差异读取每页最多 128 条；发布时只替换命中的子树，失败扫描不改变已发布基线。路径范围使用绑定参数和二进制范围比较，文件名中的百分号、下划线、引号与 Unicode 字符不会成为 SQL 通配符。

扫描继续遵守同长度同时间戳事件重读、目录改名、软链接不跟随、显式排除、预算耗尽标记不可用、读取失败保留旧内容及读取前后状态一致性检查。后台全盘扫描发布时保留启动事件已推进的路径，删除子树也不会被旧扫描结果复活。

[DONE] 索引、扫描接入与针对性 JVM 回归已完成。目录监听仍使用现有递归 FileObserver，系统资源成本随目录数量增长。
