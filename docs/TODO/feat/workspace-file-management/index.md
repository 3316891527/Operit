# 工作区文件管理第一版

## 目标

作为一个完整版本交付一个 PR，统一构建和验收。覆盖目录选择界面精简、路径编辑与返回、收藏与浏览首页、系统与手动隐藏、当前目录过滤、递归名称与内容搜索、大小和时间条件、编辑器软换行，以及复制、剪切、删除和属性统计优化。补齐归档浏览、压缩解压、ZIP 包内操作、统一文件路由及选中范围搜索和剪切移动。

## 实施清单

1. [x] 提取浏览状态与菜单操作，移除重复设置区块和常驻工具栏
2. [x] 路径输入跳转、系统返回逐级导航与存储环境识别
3. [x] 持久化收藏、浏览首页与手动隐藏目录，明确添加授权位置入口
4. [x] 当前目录过滤和递归搜索，支持匹配方式、大小写、类型、大小、时间与文本内容
5. [x] 编辑器默认软换行，保持原始文件内容、光标、选区与搜索定位一致
6. [x] 优化复制、剪切、删除及目录属性统计的实际热路径，保留取消和失败语义
7. [x] 补充核心逻辑回归源码、多语言资源与文档，完成静态检查
8. [x] 提供统一 PR 与远程验证入口，运行结果由 PR 交付记录维护
9. [x] 横滑进入多选与区间补选，补齐汇总属性和多文件分享

## 设计约定

- 创建模板工作区保留在外层主页；选择页的新建文件夹创建当前目录的子文件夹
- 页签右侧菜单根据当前页面切换；路径行可编辑，快捷位置保留
- 过滤只针对当前列表，搜索默认递归且不区分大小写
- 收藏、首页、隐藏规则同时保存环境和完整路径
- 手动隐藏只影响展示，不修改文件；搜索提供包含隐藏项选项
- 软换行只影响显示，不向文件插入换行符
- 文件操作以完整复制成功为跨环境剪切删除来源的前提，不以并行覆盖或忽略错误换取速度

## 验收

覆盖 Android、Linux 和系统授权目录；小屏、深浅主题；输入错误路径、搜索取消和离页；递归隐藏与文件定位；中英文、长行、制表符、选区和输入法；目录与大文件复制、剪切、删除及属性统计。执行结果单独记录，本地默认不运行编译、构建或测试。
