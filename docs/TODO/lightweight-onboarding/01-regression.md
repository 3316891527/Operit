# 单页首次使用流程回归清单

## 验收项

| 编号 | 操作 | 预期结果 | 结果 |
| --- | --- | --- | --- |
| T01 | 在没有协议确认记录的全新应用状态启动 | 只显示一张欢迎页，不显示多页宣传、权限或 API 配置引导 | |
| T02 | 不勾选协议确认框 | “同意并开始”按钮不可用 | |
| T03 | 勾选协议确认框 | 按钮可用，文案为当前语言的“同意并开始” | |
| T04 | 点击协议与隐私政策链接 | 打开完整协议阅读页，可滚动查看，不显示倒计时或确认按钮 | |
| T05 | 从完整协议阅读页返回欢迎页 | 返回后仍保留勾选状态，可继续开始 | |
| T06 | 点击“同意并开始” | 直接进入聊天主页，不出现第二页引导 | |
| T07 | 以空模型配置进入应用 | 聊天主页正常显示，不被 API Key 填写页替换 | |
| T08 | 在空模型配置下尝试发送消息 | 保留现有发送路径的配置错误处理和设置入口 | |
| T09 | 首次启动时拒绝或未授予系统权限 | 不因权限状态被送回旧权限引导；相关权限仍在实际功能使用时处理 | |
| T10 | 已有协议确认记录的覆盖安装启动 | 直接进入原主界面，不重新展示新欢迎页 | |
| T11 | 进入插件市场 | 不自动弹出市场协议或倒计时，市场内容可以直接浏览 | |
| T12 | 在市场“我的”入口主动打开市场协议 | 显示可滚动阅读的协议，只有关闭动作，不要求接受后才能使用市场 | |
| T13 | 检查首页网络可用和不可用状态 | 不请求或显示远程公告弹窗；插件安全黑名单刷新逻辑仍按原条件运行 | |
| T14 | 分别切换中文、英语、日语、韩语、西班牙语、巴西葡萄牙语、印尼语、马来语和罗马尼亚语 | 欢迎页的广告语、协议确认文案和开始按钮均有对应语言资源 | |
| T15 | 打开设置中的用户协议入口 | 显示同一份完整协议正文，不显示“人话版”、倒计时或旧确认按钮 | |
| T16 | 打开正常模型配置页 | 配置列表、模型连接测试、保存和普通设置入口继续可用；没有旧的引导专用模式 | |
