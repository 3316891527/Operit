# JPG/JPEG 资源与定量限制提示

原实现的导入、解码与外观协议已经包含 JPG/JPEG；本轮统一格式定义，显式列出两种扩展名，并补齐大写扩展名的回归。名称合法性与格式校验分开，避免路径问题被误报成格式不支持。不会自动重命名或改变路径协议。

资源超限携带预算种类、限制、当前占用、本次输入与合计。工作室和脚本加载页提供中英文提示，导入失败还显示文件名、导入前工程字节及资源数量、本次文件大小。整批资源全部通过校验和解码后才写入工程。

限制保持原值：单资源 8 MiB、SVG 512 KiB、源码及清单各 64 KiB、外观结果 128 KiB、源码与素材合计 64 MiB、资源 48 项、位图解码总计 41,943,040 像素。脚本内部资源 ZIP 的文件大小限制仍为 64 MiB 加 128 KiB，条目数仍为 50。

读取超过限制时只读取到限制加一个字节。文件提供方未报告完整大小时，显示已读大小的“至少”值，不将截断数据称作完整文件大小。像素预算在新位图分配前检查，并包括已复用的位图；像素与压缩字节分别显示。

验证状态：实际主题协议、格式/预算定义和资源存储源码通过独立 Kotlin 2.2.21 编译；14 项新增 JVM 回归与 19 项既有协议回归共 33 项 JUnit 全部通过。独立编译的类路径包含 Android API stub，测试没有调用 Android 解码方法，不能替代完整应用编译。

12 个改动或新增 Kotlin 文件中 11 个无语法诊断；工作室状态类的解析器诊断与既有写法一致，完整导入方法单独解析无诊断。18 项新增双语提示及既有导入说明、XML、占位符、资源引用和补丁格式检查通过。

新增 2 项 Android 仪器回归，覆盖实际 JPEG 编码、JPG/JPEG 大小写、归档往返及解码，并验证中英文定量提示和归档异常包装；尚未在设备执行。现有 Android Tests 工作流只运行 JVM 测试，不会执行这两项仪器回归。
