# 编辑器搜索面板展开时保持滚动稳定

文本编辑器仍在拖动或惯性滚动时展开底部搜索面板，面板动画会连续改变原生编辑视图高度。原来的 `onSizeChanged` 每帧都调用光标定位，和滚动器正在推进的浏览位置互相覆盖；搜索框唤起键盘时，底部避让更新还会再次强制定位。

尺寸变化应保留浏览位置，只做合法滚动边界约束。只有编辑器仍有焦点、没有滚动手势或滚动动画，并且光标在变化前完整可见时，才继续随键盘和视口缩小保持光标可见。键盘输入、行号跳转和搜索结果导航仍使用各自的主动定位逻辑。

修复限制在原生编辑器的视口处理，保持现有搜索面板展开动画和搜索、替换接口。新增 Android 回归覆盖带惯性的手势滚动、离屏光标、搜索框焦点与键盘避让，以及正常编辑时的光标可见性。

## 验证与交付

本地已通过两个改动 Kotlin 文件的语法检查、`git diff --check` 与原生编辑器接口签名核对。四项新增 Android 回归分别覆盖离屏光标浏览、拖动与惯性滚动中连续布局、搜索框接管焦点后的键盘避让，以及编辑光标在连续缩小视口后的可见性。输入回归还断言全文搜索范围随正常插入增长。
