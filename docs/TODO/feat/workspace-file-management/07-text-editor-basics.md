# 文本编辑器主题、布局与基础编辑能力

[返回计划](index.md)

本页记录首轮基础能力。后续长按选区、查找替换、设置页面和布局以[设备反馈修正](08-editor-interaction-feedback.md)为准。

## 目标与范围

继续在工作区迭代中完成用户确定的基础编辑器优化。编辑区跟随应用主题，主页、工作区和文件标签合并为一条紧凑导航，常用编辑动作固定位置，查找替换由底部展开。设置在菜单和设置面板共用同一份偏好。

本次保留现有语法着色实现，不新增解析器或语言规则，不实现图钉、跨重启草稿、代码格式化、代码补全、自定义语法、流畅模式或自动分页。打开文件之间保留编辑状态不等于永久固定文件。

## 验收边界

自动换行和空白标记仅改变绘制，不改变文件内容。缩进和行操作按照真实文本行执行，处理空行、最后一行、反向选区及以下一行开头结束的选区。只读模式覆盖键盘、输入法、符号栏、工具栏和搜索替换。

主题切换和设置改变不能重置文本或撤销记录。文件保存沿用现有文本编码边界；指定编码与 LF/CRLF 转换不在本次范围。外部变化检测不静默覆盖未保存内容。用户图片只作为多模态输入，不使用文件工具读取。

本地默认不执行编译、构建或测试。静态检查、回归源码和远程运行建立分别记录；远程 Build 和 Android Tests 确认建立后停止查询进度。


## 首轮实现

应用实际颜色控制画布、行号、正文、光标、选区与现有语法配色，移除按语言强制深色的旧入口。主页、工作区与文件标签使用一条紧凑导航，激活文件自动滚动到可见位置；独立文件窗口保留自己的标题和操作，避免把操作注册到被模态窗口遮挡的父导航。

撤销、重做、保存、编辑和更多操作保持固定位置。编辑菜单提供全选、复制行、剪切行、删除行、清空行、重复行、选区大小写和逐行缩进。清空行保留换行，删除最后一行同时处理其分隔符；反向选区保留方向，以后一行开头结束的选区不修改该行。移除旧格式化入口及未引用的格式化实现，工作区关闭补全调用。

底部查找替换与键盘避让共用布局空间，支持匹配计数、上下项、区分大小写、全词和正则。搜索在后台运行，正则替换支持分组引用，普通替换按原样保留美元和反斜杠。零宽匹配可以导航和插入；错误模式或替换表达式显示错误。全部替换一次撤销，后台计算完成后再次核对文件和内容，避免覆盖期间的新输入。只读时仍可查询、选择与复制，输入法、行操作、符号栏、撤销重做与替换不能修改内容。

设置支持字号、行距、软换行、不断词、行号、固定行号栏、软换行标记、空白和孤立空格显示、自动缩进、Tab 或空格、缩进宽度、参考线、快捷符号及自定义符号、双指字号缩放、现有高亮显示开关和外部变化检测。与菜单共用持久偏好，旧自动换行记录继续生效；开关或主题切换不重建文本和撤销栈。

每个打开文件持有独立文档、光标、选区、滚动、缩放与撤销栈。中文组词和提交作为一次撤销，离开文件前结束输入法组合，不让旧视图的回调写进新文件。关闭标签释放对应会话，不跨应用重启保存草稿。

文件子菜单提供另存为、重新加载、统计与关闭。另存为共用跨环境目录选择器，先写隐藏临时项再改名发布，目标同名拒绝覆盖。重新加载明确提示丢弃未保存修改，异步读取期间新增输入则再次提示。返回前台或切换文件后核对磁盘内容，外部修改和删除提供保留编辑、重新加载或另存为；读取失败与删除分开处理。指定编码及换行符转换仍留待完整读写方案处理。

## 回归与验收

本轮新增 14 项 JVM 回归源码，覆盖字面与正则匹配、大小写和 Unicode 全词边界、分组替换、非法模式、零宽插入、原始偏移、不断词及超长单词换行、Tab 坐标、偏好兼容与非法设置。新增 10 项设备回归源码，覆盖最后一行删除、清空与重复空行、反向多行缩进、大小写扩展、自动缩进、中文输入法撤销、只读与文件会话隔离。截至首轮提交，整个 PR 累计新增 80 项 JVM 与 32 项 Android 设备回归源码。

本地未执行编译、构建或测试。静态检查验证 Kotlin 语法树、资源和占位符、图标引用、UTF-8、空白与文档链接，不能替代类型检查或交互执行。Build、Android Tests 与 PR Check 的当前提交链接和建立状态由 PR 维护；Android Tests 执行 JVM 用例，不执行设备交互用例。

设备重点验收浅深主题即时切换、小屏单行标签、中文输入与撤销、文件来回切换、空行与最后一行操作、Tab 与软换行光标、只读全入口、正则错误与分组替换、键盘上方查找面板、后台返回后的外部变化，以及 Android、Linux 和授权目录中的另存为及失败提示。
