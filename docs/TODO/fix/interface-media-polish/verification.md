# 界面与媒体交互回归清单

本清单覆盖此次整批修复。代码核对、仓库自动验证和 Android 界面回归分别记录，未执行的项目不视为通过。

## 已完成的核对

- 中文协议正文未修改；八种外语正文由助手直接撰写
- 九份协议均为 22 章、121 条；编号顺序和项目反馈链接与中文原文一致，强调标记成对，无 Unicode 替换字符
- 复核八份译文中首次启动与单独同意、LGPLv3、个人信息、十四周岁以下未成年人、法定责任和争议解决条款
- 录音仍生成 WAV，转写与音频理解引用同一个原文件；只清理请求期间创建的媒体池副本
- 气泡和光标样式对语音条均使用专门解析，普通附件列表为空
- 历史媒体保留仅裁剪请求副本；原消息及原文件保留。图片显示改用附件原路径，未绑定原附件的历史池链接继续使用原格式

已完成 18 份变更 XML 的解析，九种语言新增的 45 条定义与更新的 27 条定义无重复且占位符一致；已检查变更文档的本地链接，`git diff --check` 通过。JVM 测试与 APK 构建通过仓库既有工作流派发，本地不执行 Gradle。工作流受理不等于验证通过；结果未返回前，以下 Android 回归项均待执行。

| U02 | 在主题编辑页选择、切换角色卡，打开目标选择列表并查看页尾 | 当前角色名称、列表名称和页尾名称使用主题前景色 |
| U03 | 依次切换中文、英语、日语、韩语、西班牙语、马来语、印度尼西亚语、巴西葡萄牙语和罗马尼亚语，再打开协议 | 每次显示对应语言完整正文，22 章和 121 条可滚动阅读，链接可打开 |
| U04 | 在中文和至少一种外语界面展开语言列表，再选择跟随系统 | 列表名称使用当前界面语言；跟随系统项及当前选中项正确 |
| U05 | 在 360dp 与 590dp 宽度查看记忆库，切换空间、搜索和文件夹 | 上方控制区约占可用页面高度 20%；下方图谱或列表使用其余空间；功能可访问 |
| U06 | 放大字体、切横屏并弹出键盘，操作记忆库控制区 | 控制区仍受比例约束，可滚动访问全部操作，搜索文字不被固定高度裁切 |
| U07 | 打开已有崩溃报告并切换浅深主题 | 异常原因显示红字，文字背后没有红色块；时间和日志仍可读 |
| W01 | 在 SDCard、Linux 和附加存储目录打开文本、图片和媒体文件 | 成功读取后立即选中对应标签并显示内容，环境和路径正确 |
| W02 | 重复打开同一文件，切回文件列表，再次进入工作区 | 复用已有标签，不生成重复标签；已处理的入口请求不覆盖新选中的文件 |
| W03 | 编辑文本并使用撤销、重做、搜索和格式化，切换浅深主题 | 工具栏背景、启用与禁用图标可读，编辑操作作用于当前文件 |

| W05 | 多选后刷新目录、进入文件再返回，切换目录或环境 | 同目录刷新只移除已不存在项；返回时恢复有效选择；换目录或环境清除原选择 |
| W06 | 多选文件及目录，复制后到其他目录粘贴 | 各项及目录内容完整复制，来源保留；原单文件菜单仍可用 |
| W07 | 在同环境剪切多项并粘贴 | 成功项移动并移出剪贴板；源目录不再包含已移动项 |
| W08 | 在 SDCard、Linux 与附加存储之间剪切多项 | 每项先复制成功再删除其来源；目标内容完整，失败项不会被提前删除 |

| V04 | 不配置可用音频理解模型，使用现有 STT 配置发送 | STT 使用当前应用语言转写；文字和原音频引用一起保留，文字可展开查看 |

| V06 | 录音后取消、重录、关闭面板或在请求中取消 | 未发送录音按会话生命周期清理；已发送录音保留；取消后不继续启动下一识别路径 |

| V08 | 打开升级前保存的文本型语音条和旧路径录音 | 仍按原格式显示、使用已存转写；旧文件路径不被强制迁移 |

| S03 | 在语音服务页拖动语速和音调滑块至两端并重新打开页面 | 使用统一细轨道样式且不画刻度；范围仍为 0.5–2.0，步进与保存行为保持 |
| S04 | 分别用气泡与光标样式发送请求，查看主题预览 | 请求浮点动画下移，与上一条消息分隔；预览同步位置变化 |
