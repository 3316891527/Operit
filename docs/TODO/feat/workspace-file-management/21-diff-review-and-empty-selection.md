# 空白处长按与变更审阅设备反馈

本轮继续沿用 PR #216。根据设备截图及 Operit2 的 change_review 插件源码，统一原生 Diff 的紧凑布局和数据状态。

## 编辑器

空行、空文档和末尾无可选内容处长按仍定位光标并显示全选、粘贴。已有选区保留完整菜单，普通点击、滚动、只读和输入法行为保持一致。

## 变更数据

列表与详情使用同一快照比较结果，正确展示增删行数和操作时间。核查文本被显示为二进制提示的原因，按快照种类准确展示状态。切换文件复用本页已经加载的快照、差异和高亮，刷新或来源变化时明确失效。

## 审阅布局

对照 Operit2 插件还原来源选择、左侧文件树、筛选、上一文件与下一文件、打开方式和查看模式。小屏也并排显示文件树，支持调整宽度和隐藏文件区。减少多层标题与工具栏，统一小字号和较细字重。纯新增或删除文件在双栏模式下充分使用可用空间，同时标明缺失一侧的含义。

## 交付与验收

补齐针对空白长按、快照统计和切换复用的回归源码及使用说明。执行静态解析、差异卫生、本地化和文档链接检查；远程 Build、Android Tests 与 PR Check 确认发起后停止查询进度。

实现已完成，补充 4 项 JVM 缓存与轮次回归源码、2 项编辑器设备手势回归、3 项快照统计设备回归和 1 项纯新增分栏设备回归。原有回归方法保留。

根因分别是插入菜单被非空选区条件拦截、列表没有填入快照统计、文本内容先于高亮发布造成错误提示。新记录保存统计，旧记录按实际快照计算；详情以有界缓存复用并原子发布，二进制状态只用于明确的非文本快照。

静态解析覆盖 20 个 Kotlin 文件和 9 份语言资源，语法与字符串引用检查通过。本地未执行编译、构建或测试；仓库卫生、本地化和链接门禁由交付脚本记录，完整构建与设备视觉效果仍以实际执行结果确认。
