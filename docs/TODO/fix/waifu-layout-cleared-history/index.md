# Waifu 连续板块与清理快照后的变更记录

本轮基于 PR #249 的过程层级实现继续迭代。Waifu 的过程与紧接正文共用头像和角色标题，过程在角色名下开始，正文紧随其后；独立正文仍逐句展示。单独一个思考只保留原文预览和一层展开入口。A2UI、图片、表情以及独立的代码、表格、公式和插件卡片不再套聊天气泡，组件自身的展示和交互保留，普通聊天保持既有行为。

用户直接删除 objects 目录或其中部分快照时，历史索引可以继续存在，但不存在的内容不能当作空文件生成差异。操作记录只在右侧显示“无可阅览的操作记录”，左侧与顶部不重复显示内部异常；上一轮变更继续展示仍可读取的历史。采集侧同样识别快照内容已清理，避免旧基线缺失使后续观察整体失败。

## 实施顺序

- 读取快照、记录筛选和空状态统一处理内容缺失，补充全部与部分清理回归
- 调整 Waifu 头像、角色标题、过程与后续正文的视觉关联，保持独立时间线行、卡片身份和消息所有权
- 修正单思考嵌套，给特殊内容提供无聊天外壳的入口，核对插件、A2UI、图片和 emotion 路径
- 评估按容量分块与按原文件聚合，提供存储格式、删除、迁移和实际测量边界的建议
- 运行针对性回归与源码检查，推送可审阅改动并派发 assembleDebug、Android Tests；确认启动后停止查询进度

存储方案评估见 [快照存储方案](storage-options.md)。本轮保留既有哈希内容存储，不在未验证迁移与引用回收前更换持久化方案。

## 实现与验证

快照读取将外部删除明确转换为内容已清理，保留真实 ABSENT 与其他读取失败的区别。列表只筛选两侧对象均存在的历史，详情同时处理“列出后才删除”的竞态；重新打开面板或应用恢复前台时重新核对内容，避免缓存继续展示已清理的差异。清理状态不会生成把旧文件当空文件的伪差异。

Waifu 在消息层统一头像和角色标题，依靠相邻可见行与生成身份关联过程和正文，独立正文仍逐句展示。节点仍保持原时间线键、消息所有权和懒加载，单思考保留自己的预览与展开状态；工具出现后恢复总过程入口，并保留思考卡片身份。独立特殊块绕过聊天 Surface、主题装饰、图片背景及玻璃外壳，前后正文各自闭合气泡边界。

本地聚焦回归共 133 项通过：

- 111 项 Waifu 流、分段、过程内容与布局判定，启用 JVM 断言；复用已验证的本地原生分段库，Android 依赖和消息字段容器使用测试替身
- 8 项真实过程行模型、节点身份和可见性回归，包含单思考、工具到达后卡片身份和 200 个独立懒加载调用
- 14 项快照读取和差异策略回归，其中 10 项覆盖真实临时目录中的完整清理、局部清理、读取竞态、重建、二进制、错误保留与刷新

修改的 Kotlin 文件通过 PSI 语法检查，源码通过 UTF-8 与差异空白检查。聚焦验证不覆盖完整 Compose 类型解析、Android 资源合并或设备视觉验收；完整构建和 Android Tests 交由本轮分支的 CI 执行，实际运行链接在 PR 中登记，确认启动后停止查询进度。

本轮基于 PR #249 的提交 45d088c9，交付目标为 dev。PR #249 尚未合并时，新 PR 会包含其前序提交；本轮增量以 45d088c9 为起点审阅。存储评估已经完成，持久化格式仍为 v1，没有迁移或清理用户的真实快照。
