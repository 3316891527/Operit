# 编辑器重复全量工作优化

[返回计划](index.md)

按本轮确认只优化编辑器重复的全量工作。TextMate 使用现成引擎配合适配层即可接入，不需要重写 Kotlin 版解析器；本轮暂不接入，也不调整 Canvas 绘制后端、交互或语言规则。

## 实施清单

- [x] 将全文行索引和最长行宽扫描改为不可变行树，局部修改复用其他行
- [x] 软换行按逻辑行缓存，复用未变化的子树和换行结果
- [x] 现有高亮改为按行保存跨行状态，合并后台请求并取消过期计算
- [x] 使用共享文档快照，输入不再反复复制全文或更新外层全文状态
- [x] 保存、另存为、预览、查找、撤销和组合输入保留现有语义
- [x] 增加增量边界与复用回归源码，静态检查与原 PR 的交付记录分别维护

## 验证边界

重点覆盖首尾编辑、跨行删除、末尾换行、最长行缩短、制表宽度、中文与 Emoji、软换行、跨行注释与字符串、连续输入合并、切换文件、保存中继续输入及预览读取未保存内容。本地不执行编译、构建或测试；静态结论、回归源码和远程执行结论分别记录。没有设备性能采样时不报告帧率或提升幅度。


## 实现说明

文档继续使用既有编辑缓冲区，新增不可变 AVL 行索引。每行保存文本及与制表宽度无关的单元格信息，节点汇总字符长度、行数和最长行宽。编辑只替换覆盖行和树路径，后续行偏移通过累计长度定位；撤销、重做与组合输入走同一更新入口。制表宽度变化更新汇总，不重复扫描每个字符。

软换行按行缓存相对区间，并缓存子树显示行数。未修改行和相同排版参数复用结果，行列表按索引定位，不为后续偏移变化重新创建整份行对象。首次打开以及字号、宽度等全局排版参数变化仍需计算对应布局；超长单行的局部修改仍涉及该行。

现有词法规则改为缓存每行进入和退出状态，状态相同的未修改子树直接复用。跨行字符串或块注释状态变化继续传播至稳定位置，必要时传播到文件末尾。样式保存为区间，移除每次全文分配的颜色数组。每个编辑器最多一个后台工作和一个最新待处理请求，过期工作在扫描中检查取消；发布结果校验请求序号及文档身份和版本，不依赖不同文件可能相同的版本号。

文档快照共享未修改行，完整字符串仅在需要时生成并按版本缓存。工作区输入通过会话版本通知变化，不再把全文复制进打开文件列表，也不在每次界面更新时读取全文比较。保存绑定点击时的不可变快照，在后台生成字符串和写入；保存期间输入、重新加载或切换会话均不能清除新版本的未保存标记。搜索在后台读取快照，另存为、Markdown 标题定位、预览和外部变化处理同步读取会话的实际内容。

不接入 TextMate，不改语言目录、配色、Canvas 绘制后端、手势、菜单和独立渲染线程。界面消费新的样式分类和文本快照，绘制区域及操作语义沿用现有实现。

## 回归与交付

本轮新增 15 项 JVM 回归源码，覆盖空文档与末尾换行、跨行编辑、最长行缩短、制表宽度、随机增删后的偏移及树平衡、快照不可变、局部布局复用、Unicode 边界、跨行注释与字符串传播、取消与规则切换。其中工作量回归检查预热后编辑两千行中的一行只重新处理该行，不用计时阈值代替正确性检查。

新增 6 项设备回归源码，覆盖索引与撤销重做、组合输入、制表宽度、保存版本快照、会话通知避免全文回传和重载后的编辑状态。整个 PR 累计新增 114 项 JVM 与 52 项设备回归源码。

静态检查覆盖 96 个 Kotlin 文件、147 个资源键及 9 种语言、68 个图标引用、170 个现存变更文件的 UTF-8、空白和文档链接。执行结果和远程运行链接由 PR 记录。本地没有执行编译、构建或测试，也没有测量帧率和输入延迟；回归源码与静态检查不代表运行通过。确认远程记录建立后停止查询进度。
