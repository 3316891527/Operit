# 检查与设备验收

## 本地静态检查

本轮仅执行源码审阅、JavaScript 语法检查、上游资源完整性核对及仓库静态检查。本地未执行 Android 编译、构建或自动化测试。CI Build 与 Android Tests 在交付时按协作约定发起，运行链接和最终提交 SHA 记录在 PR 中；发起后不等待或轮询最终结果。

6 个改动的 Kotlin 文件通过 PSI 语法检查，该检查不执行类型解析，不能替代 Android 编译。

`renderer.js` 与上游 `mermaid.min.js` 均通过 `node --check`。npm 归档 SHA-512 与 registry 元数据一致，打包脚本 SHA-256 与来源记录一致。提交后执行空白、仓库规范、本地 Markdown 链接和本地化检查，具体结果随 PR 交付记录。

## SVG 视口修正

初版设备反馈表明图表有裁剪，初版的“SVG 存在”断言不足。控制器改为按实际图形边界统一 SVG 视框，补充 28 项浏览器几何回归，并为现有设备测试增加完整可见断言。控制器和浏览器回归脚本的 JavaScript 语法、依赖清单与锁文件一致性已核对。当前 Ubuntu/proot 环境中的 Chromium 启动后以 SIGTRAP 退出，未获得本地浏览器通过结果；详见 [SVG 显示范围与缩放修正](03-svg-viewport.md)。

## 已补充、尚未执行的设备回归

`EnhancedCodeBlockAndroidTest` 两项覆盖空标签和长标签的右侧按钮对齐，以及流式围栏闭合时的预览切换。

`MermaidRendererAndroidTest` 两项使用真正的 Android WebView 和应用 assets，覆盖流程图、时序图、类图、状态图、ER 图、甘特图、饼图和思维导图，以及错误显示和修改源码后的再次渲染。它们属于 instrumentation 测试，普通 `testDebugUnitTest` CI 不会执行，不能计入已通过测试数。

## 设备验收

- 聊天与工作区分别检查空语言、普通语言、超长标签、复制和换行按钮位置
- 确认 `---` 的上下留白、列表附近及连续分隔线的视觉间距
- 断网打开 Mermaid，检查中文、引号、较大图表、全屏、单指拖动、双指缩放和旋转
- 对话生成中保持源码，围栏闭合后出现图表，切到源码后继续复制和查看
- 非法 Mermaid 应显示错误，含 HTML 字符的标签不能成为页面脚本，外部资源和导航应被阻止
- 大量图表的长对话滚动、离屏后重新进入、全屏关闭与退出页面后的 WebView 生命周期

## 成本与边界

内置 Mermaid 浏览器脚本约 3.6 MB 未压缩，APK 增量以实际构建产物为准。默认图表预览需要创建 WebView，设备上的首帧、内存和长对话体验仍待验收。预览区域保留固定高度并支持缩放、拖动和全屏。图表中的外部字体、网络图片和点击导航不开放。
