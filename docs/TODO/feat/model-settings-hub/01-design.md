# 页面结构与后续实现范围

## 入口层次

```text
设置/
	模型与对话/
		模型配置/
			配置详情/
				连接
				参数
		功能分配/
			单项功能编辑窗口
		上下文与总结/
			选择正在编辑的配置
			上下文长度与自动总结
			摘要结构与规则编辑窗口
			全局历史媒体保留
```

工作区首页不再长期展示某份配置的选择卡片。选择配置只发生在模型详情和总结策略编辑处；功能分配首屏直接呈现全局映射，避免列表看起来只属于当前选中配置。

设置首页将“模型与参数配置”建议更名为“模型与对话”，合并原“上下文与总结”入口。此命名属于待审阅设计，Android 导航尚未变更。

## 配置与功能

模型页使用紧凑的单列配置列表，展示分组、服务方式、模型名称、正在使用的功能数量，以及当前对话标识。点击后进入连接或参数详情。详情中的功能入口只预置筛选条件，不改变任何绑定。

功能页保留十二项 `FunctionType`。列表分组、待检查、搜索与按配置筛选只影响呈现；模型选择窗口可以查看跨分组配置，显示分组和完整模型名称。保存才更新本页的模拟映射，取消保留原绑定；查看测试示例后返回，保留尚未保存的选择。

图片、音频、视频检查只反映配置的能力开关，不能证明模型本身支持该能力。记忆向量未配置与普通配置缺失分开表达。连接与能力测试的结果在本稿中全部标明为示例。

思考开关与档位需要继续使用实际配置中的提供商规则。稿中低、中、高仅用于观察排版；正式界面必须按规则提供真实档位，不将示例选项直接写入服务请求。

## 上下文与总结的三个归属

- 上下文长度、最大长度、自动总结触发条件、补充规则、摘要结构和回顾，属于所选 `ModelConfigData`
- 执行总结使用的配置与模型，属于全局 `FunctionType.SUMMARY` 映射；从总结页修改该项也会更新功能分配
- 历史图片与音视频保留回合数，属于 `ApiPreferences` 的全局偏好，切换模型时不重置

第一次查看总结策略默认选择当前对话绑定配置；明确切换编辑对象后保留选择。模型详情可以直接进入自身的总结策略。当前对话配置与正在编辑的配置不同，会在选择器下说明。

常用设置直接展示，摘要内容与结构折叠收纳。补充规则、四个摘要板块及对话回顾进入同一个居中窗口编辑，避免主页面铺满长文本。

## 设计稿可操作范围

模型配置支持搜索、分组、添加、重命名、复制、删除、模型列表编辑、服务方式、端点、密钥输入、请求能力、常用参数、请求头和请求队列的页面内修改。正在被功能使用的模型不能直接从演示列表移除；正在使用的配置和默认配置不能直接删除。

功能分配支持完整列表、筛选、搜索、选择配置与模型、思考覆盖、保存、取消、重置、连接参数跳转以及测试状态预览。总结页支持选择配置、长度与范围校验、两种触发方式、规则与结构编辑、上一轮摘要开关、摘要标题预览和全局媒体回合数。

密钥池仅提供状态示意；完整思考规则和自定义参数编辑器尚未实现。配置文件导入导出、真实模型列表拉取、真实测试、OAuth 和本地模型服务也未接入 HTML。现有 Android 的这些能力需要在后续改造中保留，不应依据稿中简化内容删除。

## 后续 Android 改造约束

当前仍是设计审阅阶段。确认设计后再调整设置入口和工作区导航，复用现有配置、功能映射与保存协调；切换页签、配置、分组以及返回时仍需处理尚未保存的输入。

原有配置分组管理、排序、配置文件导入导出、OAuth、本地模型服务、密钥池、完整思考匹配规则、标准和自定义参数、请求队列、十二项真实功能测试以及旧入口导航均应纳入实际改造范围。保存失败需按实际错误提示处理，不将本稿的内存更新当成持久化保存。

新导航以独立组件组织。已有模型配置相关目录可以继续承担原有职责；不要将页面导航和全局功能分配逻辑塞进供应商实现文件。

离线资源只确定入口归属，资源下载、模型导入、OCR 与插件资源外置、工程模板拆包、终端预装环境均不在本轮实现范围。
