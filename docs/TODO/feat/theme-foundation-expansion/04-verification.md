# 交付与体验清单

## 已完成的接入

- 文字描边已有 `typography.stroke` 与区域 `textStyle.stroke`；本轮独立文字目标使用相同结构，保留小数宽度、明暗模式与显式零宽度关闭
- 线性与径向渐变可用于 Surface 填充和矩形、椭圆、线条绘图层；工作室共用一个渐变编辑器
- 现有背景目标显示为全局背景；66 个主路由分别具有页面背景目标，动态路由参数不作为选择器
- 全局文字排版包含 15 个 Material 文字角色和 9 个语义目标；具体模型名称接入 Classic 与 Agent，包括输入区简略名称和选择器名称
- 资源引用检查包含独立文字目标的字体；模式展开、工程草稿、撤销重做与归档沿现有共享模型保存

## 自动检查范围

新增回归覆盖旧声明字段集合、颜色停点校验、颜色与渐变互斥、字重与字体引用、未知目标、状态填充、模式覆盖、完整主题 ZIP 往返、路由参数与编辑器目录。

本地未执行构建和测试。PR 工作流负责候选的资源编译和 Android JVM 检查，最终结果在 PR 中记录。设备视觉、触控及原生视图场景仍待体验。

## 设备体验顺序

1. 在全局背景设置图片或渐变；为包管理、市场、设置和聊天分别设置另一组背景，切换页面确认隔离；清除某页设置后恢复全局背景
2. 浅深模式分别设置线性和径向渐变，调整颜色停点、方向、中心与半径；给输入容器和绘图层使用渐变，确认原生填色没有盖住渐变
3. 全局文字排版选择模型名称，改变颜色、字体、字重、字号、行高、字距和描边，分别查看 Classic 与 Agent；再修改一个正文角色和设置项标题
4. 保存制作草稿、退出重进、应用到角色并保存；导出 `.oktheme` 后重新导入，确认背景、字体、渐变及文字描边均保留

## 边界

页面背景位于主导航的内容画布中，页面顶栏、卡片、编辑区和 WebView/终端等原生视图仍有自己的绘制内容；这项能力不重排页面，也不改写第三方页面的内部像素。预览使用共享背景渲染器和固定页面样例，不执行实际页面业务。

文字角色通过共用文字封装匹配当前 Material 排版；具体位置使用稳定语义目标，未标记或不使用共用封装的第三方文字不会自动获得独立目标。缩放在基础文字样式上叠加，颜色、字体和字重按目标覆盖；零字距保留既有语义。

当前新增目标全集和 JS 示例见[扩展说明](../../../doc-src/feature-protocol/theme_foundation_extensions.md)。旧主题不使用新字段时不增加这些字段，新主题使用扩展时需要包含本轮能力的应用版本。

首轮 CI 发现页面预览焦点修饰器缺少导入，已补齐。页面背景同时使用独立的页面预览场景，场景选择可以正常在页面与聊天、组件和导航之间切换。
