# 记忆检索相关性与诊断（#1320）

## 已处理
- 工具查询和仓库查询统一使用默认相关性阈值 0.025，调用方仍可显式指定 `threshold=0`
- 向量检索启用时按余弦相似度筛选，默认最低 0.5；在记忆搜索设置中可调，未启用向量检索的会话不受此门槛影响
- 每个关键词最多融合 50 个语义候选；无文件夹范围时最多从索引取 50 个近邻，有文件夹范围时先检索全索引再按文件夹过滤，避免目标文件夹的记忆被其他文件夹的近邻挤掉
- 图传播只影响当前文件夹和时间范围内的记忆；最终结果再次校验范围
- `Tools.Memory.query` 的结构化结果增加总分与关键词、标签、逆包含、语义、图传播分项；`*` 列表和按标题读取没有相关性分数
- 声明 `getByTitle` 的结构化结果/文档分块字符串返回类型；说明 `*` 对普通记忆只返回预览；候选不足日志同时记录当前条数与最低条数

## 验证
自动用例覆盖语义相似度门槛、候选上限、有范围搜索时的索引读取、图传播后最终范围过滤、评分结果序列化和无评分结果。
仓库工作流运行 Android Build 与 Android Tests；结果以对应提交的实际运行记录为准。
