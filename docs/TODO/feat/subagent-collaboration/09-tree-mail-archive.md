# 多层树、通信、等待与会话图

[返回计划](index.md)

本批完成用户授权的能力清单：具名多层树、同根代理通信、等待协调、完整 JSON 会话图、子树生命周期、运行状态和回归准备。继续使用本方移动端窗口；旧插件兼容、用途级工具范围和预算配置不在此次范围。

## 数据与调度

任务快照增加根聊天、直接父任务、名称、路径、深度、排队时间、等待目标与持久邮箱。Room 保持版本 30；旧单层快照按原父聊天恢复为根的直接子节点，兼容回归已实际执行。

主代理为第 0 层，最大子层默认 3，可配置 1～8。节点名使用 1～48 个英文字母、数字、下划线或连字符，同级唯一。全局和每根树共享并发限制；WAITING 状态不占采样名额，恢复前重新排队取得名额。终态但仍清理的作业保留名额，避免新请求提前占用尚未释放的资源。等待关系检查环；同一代理不允许并行进入两次等待。

wait_agents 使用 tree 或 mailbox，单次 0～30000 毫秒。先观察已有输入和可运行工作，再决定是否等待，返回 mailbox、idle 或 timed_out。父代理结束轮次时等待全部后代或信箱输入；子代理也连接同一套父轮次入口。

## 通信与生命周期

send_agent_message 按同根任务 ID 或完整路径寻址，main 或 / 为主聊天。可信发送者来自执行上下文；调用身份用于去重。消息先持久化再投信箱，每条最多 10000 字符，每个持有节点最多 64 条未消费和 1024 条总记录。

wake=true 明确唤醒空闲且未归档的子代理，重新验证原模型和思考选择；默认只留邮件。空闲主聊天不自动启动。子代理消费时，将消息、助手分段和消费确认一起提交。主聊天保留先写消息再确认的既有流程，重连通过稳定标记恢复确认，不能把它描述为同一事务。

根代理可控制全树，中间代理只控制后代。同根其他分支可观察、通信和等待。停止覆盖目标与后代，取消后等待全部作业清理；重叠清理使用引用计数门禁，取消调用方也必须等资源释放后才打开门。门禁覆盖终态保存和服务释放。归档／恢复要求整个目标子树空闲，事务保存整组状态；删除按叶到根处理，再清理 A2UI 状态。

## 完整 JSON 图备份

逻辑备份格式为 4。带任务的根聊天和全部子聊天在同一 Room 快照读取，包含真实消息、回答变体、运行记录、报告、未消费补充和邮件。写文件时逐条输出消息与任务，避免额外创建整图编码字符串；图本身仍需驻留内存，导入前按主子消息与任务文本总计 32000000 字符校验。

图导入始终创建新根，重新分配聊天、任务、执行、报告、邮件、补充与应用侧调用身份。校验完整父子关系、路径、深度、邮箱归属、等待环、执行所有权、简报和消息／变体身份。协作工具参数与报告标记同步重映射，保留工具开标签的 call_id 配对，提供方协议负载原样保留。活动执行标为中断并产生报告，不自动重新运行。

既有普通聊天旧档继续可读；孤立子聊天不能作为普通聊天导入。CSV、Markdown 与 HTML 保持原有展示导出。模型配置、凭据、工作区文件及外部资源不随会话图迁移，继续前必须具备原模型引用。

## 窗口与权限

托盘显示运行、排队、等待和报告计数；卡片显示路径和本树排队序号，详情显示深度、等待目标或协作消息，过程页显示消息方向与消费状态。任务管理支持路径搜索。工具返回对应树字段、排队序号和未读计数；11 个工具共用中英协议定义。

子代理继承调用方角色卡与常规权限，所选模型的工具模式仍生效；共享设备 UI、浏览器和聊天／模型修改继续在目录与执行端受限。此次开放的是有深度和同根身份约束的协作工具。真实工具过程保存在子会话，meta 仅在显示层过滤。
