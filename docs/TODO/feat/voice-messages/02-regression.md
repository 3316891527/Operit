# 语音条验证与完整设备验收

本地仅执行源码与资源静态检查；没有运行 Android 编译、构建或单元测试。15 个新增 JVM 用例等待仓库 Android Tests 执行。设备结果未填写即未验收。

## 静态与云端记录

- 首轮 Kotlin 静态语法：23 个文件通过；EnhancedAIService 和 MessageProcessingDelegate 在基线同样触发解析器限制，交由云端 Kotlin 编译
- 资源：28 个中英文键的 XML、键集合、占位符和源码引用一致，本轮新增 9 个
- 本轮 UI 静态语法：7 个 Kotlin 文件通过，面板、波形及播放器的实际布局待设备验收
- 图标：使用同一提交的 terminal 源码检查，Material 图标引用已覆盖
- Git：git diff --check 通过
- 云端：工作分支派发 Android Build 的 assembleDebug 和 Android Tests，派发受理与最终通过分别记录
- 首轮云端：[Android Build](https://github.com/3316891527/Operit/actions/runs/40040100428) 与 [Android Tests](https://github.com/3316891527/Operit/actions/runs/40040103254) 均因发送协调器两处返回类型不匹配而编译失败，单元测试尚未执行
- 本次修正：模型绑定解析失败和配置无效时显式返回 null，与 Job? 返回契约一致；后续云端及设备结果待确认

| 9 | 首次权限同意 | 首次录制并允许麦克风权限 | 开始录音，无重复权限请求 |
| 10 | 权限拒绝 | 拒绝麦克风权限后重试 | 提示需要权限，不发送空消息 |
| 11 | 实际音量波形 | 依次说话、停顿、提高音量 | 波形随真实录音变化 |
| 12 | 全程静音 | 打开后保持安静超过三秒 | 自动结束并提示无人声，不发送 |
| 13 | 说完静音 | 讲话后安静超过三秒 | 结束录制并进入转写确认 |
| 14 | 短暂停顿 | 讲话间停顿不足三秒再讲话 | 持续录音，静音计时重新开始 |
| 15 | 持续讲话 | 持续讲话超过三秒 | 继续录制，不固定三秒截断 |
| 16 | 手动完成 | 录到人声后点击说完了 | 停止录制，转写后进入确认 |
| 17 | 最长录音 | 持续录音至一分钟 | 到上限停止并进入确认 |
| 18 | 录音关闭 | 录制中点击右侧关闭或返回 | 关闭并释放麦克风，未发送文件清理 |
| 19 | 面板滑动关闭 | 通过底部面板关闭手势退出 | 结束会话，不在后台继续录制 |
| 20 | 本地 NCNN | 选择并准备原本地 STT 后录普通话 | 当前本地服务转写并显示结果 |
| 21 | OpenAI STT | 选择有效在线 STT 后录普通话 | 使用当前端点和模型得到转写 |
| 22 | Deepgram STT | 选择有效 Deepgram 后录普通话 | 识别文字正常，不显示原始 JSON |
| 23 | 识别服务缺失 | 本地模型缺失或在线配置不可用 | 显示识别失败，不能发送，可重试 |
| 24 | 网络失败重试 | 转写中断网，恢复后点重试 | 保留录音，重试成功可发送 |
| 25 | 空识别结果 | 使用返回空文字的有效服务响应 | 提示未识别文字，不发送 |
| 26 | 共享识别占用 | 已有语音任务时尝试转写 | 提示服务忙，不打断已有识别 |
| 27 | 确认试听 | 转写成功后播放、暂停、播完重播 | 声音与录音一致，时长与波形显示 |
| 28 | 重新录制 | 确认页重录第二句话 | 旧未发送录音清理，只保留新结果 |
| 29 | 确认取消 | 确认页关闭后重开录音 | 不发送旧内容，开始新录音 |
| 30 | 单独发送 | 确认页点击发送 | 只保存一条语音消息，面板保存后关闭 |
| 31 | 重复点击发送 | 保存过程中多次点击发送和重录 | 只发送一次，重录被禁用 |
| 32 | 保存期间取消 | 发送后在保存完成前关闭面板 | 未保存任务取消后清理；已保存录音保留 |
| 33 | 工作区对话 | 绑定工作区后发送语音 | 语音条正常渲染，模型仍有工作区信息 |
| 34 | 模型文字请求 | 用无音频理解能力的文字模型接收语音 | 模型依据转写回复，不要求音频能力 |
| 35 | 历史继续对话 | 发送语音后再发文字并重新生成回复 | 历史语音以转写参与请求 |
| 36 | 上下文窗口 | 比较相同文字和语音转写的窗口统计 | 不把 WAV 路径和波形当作语音正文统计 |
| 37 | Bubble 展示 | 在气泡样式和图片气泡样式查看语音 | 显示播放器，能够展开及收起文字 |
| 38 | Cursor 展示 | 切换 Cursor 消息样式 | 显示播放器及转写 |
| 39 | 重进聊天 | 退出后重新打开已发送语音所在聊天 | 仍能播放并查看转写 |
| 40 | 多条播放 | 连续点两条语音的播放按钮 | 上一条停止，只播放当前语音 |
| 41 | 后台生命周期 | 录音、转写及播放中分别切后台 | 录音面板关闭并清理，播放停止 |
| 42 | 聊天切换 | 录音或转写中切换聊天 | 关闭旧面板，不发到另一个聊天 |
| 43 | 特殊转写文字 | 转写含中文、引号、小于号和实体文字 | 显示及模型请求文字不损坏 |
| 44 | 媒体清理 | 在数据存储中清理语音所在音频池 | 占用统计覆盖录音，清理后提示不可播放 |
| 45 | 输入提交钩子 | 分别阻止提交、修改转写后允许提交 | 阻止时不发送，修改后模型收到新文字 |
| 46 | 发送准备失败 | 让输入处理钩子或消息准备抛出错误 | 结束处理状态并显示错误，允许后续重试 |
| 47 | 初次聊天 | 无当前聊天时点击麦克风 | 自动新建聊天后开始录音，发送归入新聊天 |
| 48 | 短语音气泡 | 关闭宽气泡后发送约三秒语音 | 紧凑单行语音条，不占满整行，不出现重复底色 |
| 49 | 宽气泡开关 | 切换宽气泡开关后查看短语音 | 两种布局均保持短条，各自头像和宽度边界正常 |
| 50 | 长语音气泡 | 查看接近六十秒语音 | 宽度仅有限增加，简短时长与播放入口完整 |
| 51 | 展开与收起 | 点文字展开长转写，再点收起 | 文字换行且不溢出宿主，收起恢复短条 |
| 52 | 实时波形可见 | 小声、正常、大声交替录音 | 粗波形随真实音量明显变化，轻声也能辨认 |
| 53 | 静音状态 | 录音后停顿观察状态灯和波形 | 状态灯提示正在录音，静音无虚构起伏，三秒后结束 |
| 54 | 主题与图片气泡 | 明暗主题及普通、图片、玻璃气泡分别查看语音 | 沿用宿主文字色与背景，边距紧凑且可读 |
| 55 | Cursor 紧凑卡片 | 切换 Cursor 样式查看短语音 | 语音卡片随内容收紧，普通文本卡片布局正常 |
| 56 | 大字体与窄窗口 | 增大系统字体并缩窄窗口打开面板 | 内容可滚动，关闭、完成和确认按钮可访问 |
| 57 | 面板操作状态 | 依次录音完成、转写失败重试、重录和发送 | 主次按钮与状态一致，发送中不能重复提交或重录 |
