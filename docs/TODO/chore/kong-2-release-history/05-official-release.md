# 2.0.0 正式发行

维护者在初次准备 PR 后明确授权：调整面向用户的日志，合并本轮全部开放 PR，集成 dev 并同步 main，正式发布 Operit Kong 2.0.0。此授权取代先前只准备、不合并和不发行的限制。名称、图标、应用身份和外部存储目录沿用现状。

## 本轮变更

从用户正文删除未定位故障调查段、发行过程说明和不帮助用户决策的实现细节，保留安装、签名、备份、导入格式和按需资源说明。既有长运行文件访问及显示调查记录继续保留在维护证据中，删除公开说明不表示已经修复。

拟集成 #282 统计运行质量与计费、#283 工具实时计时、#284 明确 API 迁移与图标，以及 #285 正式历史接入；终端配套 #4 保留其源提交并合并。用户正文补入实际集成后可见的统计、计时和布局改进，不列内部警告数量。

正式版本设置为 2.0.0 / versionCode 88，高于当前 +31 / 87。跨基础版本使用完整 APK，previous_tag 留空。继续使用固定 Kong 包名与签名及统一发行仓库；资源由同次签名构建生成和核对，migration 与分支清理关闭。

## 执行与核查

先读取各 PR 当前头、合并门禁和已启动验证结果，再依赖顺序合入 dev，保存来源提交祖先关系；通过独立同步 PR 合入 main，确认树一致。发行工作流选择 :app:verifyCiPreviewRelease、publish_release=true、release_notes 留空，读取仓内 2.0.0.md。

本机不执行编译、构建或测试。远端启动后按既有约定仅登记一次，不持续轮询；启动不等于公开成功，公开状态以正式 Release 与附件为准。

最终提交、合并、运行和公开结果登记在发行回执。
