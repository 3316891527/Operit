# 插件文字主题色、复制预览自动滚动与 A2UI 即时渲染

## 问题与目标

插件详情的半透明卡片没有提供与容器匹配的内容色，变量名和工具名可能继承错误前景色。聊天复制预览的按钮仍按格式显示“复制纯文本”等文案，长按拖动选区到底部时也不会带动内部文本视口滚动。A2UI 编译成功后只排队到轮次结束，长时间工具任务期间卡片无法及时出现。

修复目标是让插件名称使用正确的主题前景色，保留复制预览的格式选择、选区和滚动状态并恢复非消费式边缘自动滚动；A2UI 工具结果返回实际编译文档，同时在成功的流式工具调用完成前将同一文档写入助手消息，使现有 A2UI renderer 当场渲染。表单等待继续沿用它当前的即时发布和提交语义。

## 作用域

- 修复插件详情环境变量标题、变量名、包工具名、MCP 工具名和子包名称的前景色继承。
- 静态盘点应用 Kotlin 源码中的 Compose `Text` 调用，区分主题继承、语义色、专用深色/媒体表面与硬编码主题色问题；修正审计确认的问题并记录结果。
- 复制预览统一显示本地化的“全部复制”，仍复制当前选中格式的完整文本；在只读 `TextFieldState` 上实现不消费原生选区事件的边缘滚动。
- A2UI `prepare` 和 `revise` 返回 surface ID 已完成绑定的编译 JSON；流式工具调用在返回工具结果前立即发布对应 A2UI 围栏，更新工具说明和引导。
- 增加工具流输出、边缘滚动计算和文案资源回归检查。
