## 实现步骤

1. 用独立的 Kotlin 模型解析常用流程图、子图、状态图、类图、ER 图、思维导图、时序图、饼图和甘特图；未知语法明确报错。
2. 用原生文字测量建立节点尺寸，分层安排节点和子图，计算带箭头的连线及完整绘制范围。
3. 用 Android Canvas 绘制节点、文字、连线和图表；首次布局及尺寸变化时适配全图，单指拖动、双指缩放和按钮使用统一变换。
4. 清理 Mermaid WebView、离线网页、第三方 JavaScript 和 Playwright 检查，用解析、布局、视口及设备绘图检查替换。
5. 更新文档与 PR，按协作约定为最终提交发起 Build 和 Tests，核对 SHA 后不轮询工作流进度。

本次属于内部显示实现替换，继续使用同一 Mermaid 源码及操作入口。原生语法支持范围与不支持项必须如实记录，不宣称覆盖完整 Mermaid 语言。设备效果必须以原生绘图验证，先前 SVG/浏览器结果不作为验收依据。
