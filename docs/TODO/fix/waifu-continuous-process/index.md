# Waifu 连续过程分段

Waifu 之前将每个受保护的 XML block 直接变成消息，连续工具调用因此反复出现头像、气泡和命令框。此次将连续的思考、工具调用与结果作为一个持续增长的过程段，只在可见正文出现时结束；正文继续逐句发送并分别显示头像。

过程段在气泡式和命令框式聊天中使用无消息外壳的渲染入口。思考收起时显示原文开头的单行省略预览，展开保留完整内容；工具使用统一图标和现有通用组件。过程增长时保留消息身份与用户展开状态，取消、失败与重试时保留最新有效快照。

## 作用域

- 将分段、流式更新、过程展示及对应测试整理到 `ui/features/conversation/chat/waifu/`
- 修改服务侧分段消息修订、过程朗读过滤和 ChatArea 渲染入口
- 扩展思考折叠标题与必要的过程渲染上下文，保持普通聊天行为

本轮沿用现有 ChatMessage 持久化格式，不新增用户设置。已确认开发基线与远端 dev 的代码树一致，当前不调整正式发行版本。
