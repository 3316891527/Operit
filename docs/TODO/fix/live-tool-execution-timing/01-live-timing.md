# 实时记录与呈现

## 消息投影

整轮使用同一个计时状态，活动分段记录全局调用起点。界面独立订阅后映射为局部编号，不按工具名称补齐，也不为每次计时更新重建消息。插话正文流继续复用原派生流；无流定稿冻结 sections，解除 holder 并归零起点，回答版本切换同样清除起点。 [DONE]

Waifu Store 的 Append、Preview 和 Revise 绑定同轮记录，修订前段后按保留前缀重新投影后缀。工具结构变化立即发布，不等待 100 ms 的普通长输出限流。正常、失败、显式取消和直接 Job 取消均固定单工具快照。 [DONE]

会话重载与分页的公共显示窗口入口恢复页内仍活动的计时记录，保留数据库中的收藏状态，不追加页外消息、不额外写数据库。自动撤回共用该入口。 [DONE]

## 执行中的显示

当前进程中已开始且没有结束记录的区间持续推进，已完成和停止记录保持固定。普通 Bubble、Cursor、Timeline 与 Waifu 无外壳入口明确传递计时活动状态，普通和 Waifu 使用同一刷新函数。正文是静态片段也能计时。 [DONE]

增加尚未执行或仍在生成的新调用不会隐藏已有时间。工具组按区间并集汇总，展开后显示各单项计时。历史无记录保持未知，不重启旧进程未完成计时。 [DONE]

截断修复保留整批作废工具正文，因此在该分支按 canonical ToolCall 数预留位置，两条警告设置路径都覆盖；不生成伪执行记录。 [DONE]

## 回归与交付

新增 20 项回归源码，包括 18 项 JVM 和 2 项 Android，覆盖正文不变时的开始、增长和完成，静态 Markdown、同名工具、多次插话、修订回滚、终态保存、页面恢复、排队和部分调用、并行并集及取消后冻结。 [DONE]

静态检查不替代 Kotlin 类型检查、项目编译或测试执行。远端构建、JVM 测试、仪器 APK 编译与设备显示结果分别记录，工作流登记后不轮询。设备验收仍待完成。
